# Private frozen six-way Room check

Reuse `scripts/check-inkwave-respawn-exclusion.mjs --sixway` against the
preserved normal six-way build. This mode pins input/content hashes, retains
the original two-context WebSocket + production Worker/RoomDurableObject
harness, and bounds execution to60Hz and the requested cases. Default and
baseline modes keep their original cadence/case selection.

```sh
PLAYWRIGHT_MODULE=/workspace/actions/node_modules/playwright/index.js \
WS_MODULE=/workspace/actions/node_modules/ws/index.js \
node scripts/check-inkwave-respawn-exclusion.mjs /workspace/inkwave-six-site \
  /workspace/inkwave-room-evidence/new-run --sixway
```

The output directory must not exist. The source build remains frozen7c; this
new QA/tool head does not automatically qualify under an admission profile.

Both teams walk and jump into the actual opposing barrier4.2, then leave their
own pads. Keyboard-controller state and native `Game._frame` drive movement.
The owner, actual relay-carried snapshots and real interpolated proxy must
reach the protected edge. Jump cases additionally require positive airborne
height on all three paths.

Both teams then use actual native death/countdown, press-to-launch and supported
landing, followed by a fresh native Roller attack. The check captures actual
GPU-rendered idle landing and attack frames, displayed drum vertices/bones,
canonical state, real owned births, relay projectile events, received ghost
births and native CPU/GPU paint. Read-only observers wrap `_push`, the actual
`ghostProjectile` admission, and paint; the native methods still perform all
work. Ghost admission directly appends to `list`, so `_push` alone cannot
measure it. Partial case evidence is saved before later assertions.

These are two local browser contexts and a real local production Room with a
platform upgrade shim. Initial ingress/exit positions use native `spawnAt`;
death uses native `splat`; bots are frozen; render checkpoints use a controlled
observer camera. Frames are manually scheduled and rendering is skipped between
the selected captures. This is not continuous rendered-arc, hardware pacing,
physical-input, public/deployed relay, mixed-client, WebKit/mobile or retail
acceptance. No stage collision, input/physics/timer, weapon geometry or runtime
source is replaced. The known pooled same-seed muzzle-sheet failure remains in
the separate source/emitted/browser tests and is not waived by these passes.

Review identities and results are recorded separately under
`/workspace/inkwave-room-evidence`; original failed observation logs and all
earlier frozen integration evidence remain preserved.
