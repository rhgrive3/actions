## 実装とレビュー

8種類を個別に修正し、別担当が画像とコードをレビューした後、各実装担当が指摘を受けて修正した。統合画像も別途レビューし、必要な再修正を実施した。

| 髪型 | 主な変更 | 対応したレビュー |
| --- | --- | --- |
| Tide | 後ろ髪を広い束にし、前髪を頭に沿う平たい流れに変更 | 浮いた前髪のアーチ、角張った分け目、後頭部の根元 |
| Spike | 短く後ろへ流れる束と前髪に変更 | 四角く途切れる後頭部の根元、独立して見える束 |
| Twin | 対になる束と分け目を整理し、毛先と帽子下を調整 | 前髪根元の隙間、帽子への貫通、鋭い分け目 |
| Bob | あご付近の束を短くし、帽子下に専用の根元を用意 | 鉤状の毛先、帽子から四角く出る根元 |
| Pony | 短く立ち上がる束と帽子下の前髪を調整 | 先端の角張り、帽子のつばへの干渉 |
| Crest | 前へ折れる大きな束に変更 | 頭皮から浮く根元、帽子下の長い鉤状の毛束 |
| Knot | 頭頂の束をまとめ、顔横と帽子下を調整 | お団子下の空洞、長すぎる側毛、浮いた根元 |
| Swoop | 側面に流れる大きな束に変更 | 側頭部の交差、後頭部の突き出た根元 |

髪の近距離・ゲーム用メッシュを細分化し、頭頂の細かい溝と強い暗部を抑えた。立体吸盤は縁の分割を増やして高さを下げた。ポニーの毛先のみ、丸い先端へ入る前の細りを緩めた。イカ形態の先端と帽子の分割数は髪とは別の設定にした。

## 2026-10-30 の再検討: 頭頂部の尖りと髪型の一体化

前回の候補に対する指摘を受け、[スプラトゥーン3公式サイトのギア画像](https://www.nintendo.com/jp/switch/av5ja/assets/images/index/pc/style/img_gear1.png) と、[Inkipedia のスプラトゥーン3髪型一覧](https://splatoonwiki.org/wiki/Hairstyle) に掲載されたゲーム画像を確認した。前回参考にした任天堂ファッションページの画像には旧作のものが含まれるため、スプラトゥーン3の直接の証拠には扱わない。

共通の `capOffset` は頭頂部でも後方の厚みを方角に応じて加えていたため、頂点の周囲に尖りができていた。この差を頭頂部に向けて消し、同一のパッチ適用済み描画条件で頂点の尖りが減ることを確認した。別担当も画像と計算式をレビューした。帽子の形状もこの厚みを参照するため、帽子3種類の静止した後ろ姿も確認したが、帽子自体の頂点に残る方角依存や、全角度・動作中の干渉は未解決である。

各髪型は個別に再試作し、別担当による画像レビューと再修正を行った。束を太くした試作では根元の継ぎ目と毛先の塊が残り、一体メッシュの試作では平板・ヘルメット状の形や独立した髪の動きの喪失が生じた。これらの試作は実装候補として採用していない。今回メインの髪型形状に追加で取り込んだ修正は、上記の共通の頭頂部のみである。前回から残る根元・毛先・吸盤の問題は解消しておらず、商用品質の達成、本家との一致、実機での見え方は確認できていない。

パッチ適用済みビルド、パッチ互換性、起動予算の静的チェックを通過。既存の髪スプリング、画面外復帰、ジオメトリ、モーション、髪キャッシュに関するテスト計20件を通過した。これらは画像の品質、プレイ中の毛束の干渉、端末の性能、本家との実機比較を保証するものではない。

## 2026-10-31 追加修正

前回の試作が要求を満たしていなかったため、スプラトゥーン3の公式画像とゲーム内の髪型資料を改めて比較し、髪型ごとに形状を作り直して別担当がレビューした。以下はそれぞれパッチ適用後のローカル描画で確認した変更であり、すべての角度や実機動作の一致を示すものではない。

- Tide: 頭頂部・前髪・後ろの幅広い束を接続した面にし、丸い毛先と吸盤の模様を加えた。帽子ありも幅広い束に変更。耳付近に細い境界が残る。
- Spike: 重なり合っていた束を、頭頂部と一体の丸い3つの盛り上がりに変更。帽子なしの盛り上がりは骨でわずかに動く。
- Twin: 左右の長い束の根元を頭頂部と接続し、帽子ありも対応。顔横の短い束には細い境界が残る。
- Bob: 頭頂部から顔横にかけて広い連続面にし、後頭部の細い束を整理。顔横の先端と後ろの角はまだやや鋭い。
- Pony: 3本の幅を持たせた束と顔横の毛に変更し、帽子ありの毛先と留め具を調整。顔横の根元には境界が残る。
- Crest: 頭頂部と前へ折れる束をつなぎ、3つの吸盤模様を追加。帽子下の毛先も短く丸い形に変更。動作時に細い光の筋が残る。
- Knot: 頭頂部と結び目・顔横をつなげ、帽子下はなだらかな後頭部に変更。帽子をかぶると結び目の特徴は弱くなる。
- Swoop: 流れる前髪から顔横を一体の面にし、面の一部を髪の骨で動かす。帽子のつば付近に細い暗い線が残る。

8種類を作業ツリーに反映。各実装はパッチ適用後の公開版で描画を確認した。Blender はローカルの造形・検証に使用し、ゲームの実行時依存には加えていない。

ユーザー提供の眉の画像を参考に、内側を細く外側へ向かって幅を持たせる形に変更。既存の4種類それぞれの位置・角度の違いは保持し、髪色に近くなるよう色も調整した。髪型や帽子によって眉の一部が隠れる。

最終結合版（ビルド `beec1cb23854`）は、8髪型×帽子4種類×3 LOD の96ケースで全属性の有限値、インデックス範囲、スキンウェイトと骨数を検査した。32の髪型・帽子の組み合わせを用いた120フレームのローカル擬似動作では骨が有限で、重み付けされた髪が動くことを確認し、描画画像をレビューした。連続再生での全接触、実際の対戦、端末性能や本家実機との一致を証明するものではない。顔・髪の関連テスト35件とパッチ互換性を通過し、最後の眉色調整を含むビルドと起動予算チェックも通過した。

高品質・ゲーム用LOD・帽子なしの髪メッシュの三角形数（この追加修正の直前 → 最終版）は、Tide 10,732 → 8,792、Spike 8,256 → 6,480、Twin 8,836 → 9,464、Bob 9,440 → 4,036、Pony 8,524 → 7,488、Crest 4,520 → 5,320、Knot 4,900 → 5,248、Swoop 7,272 → 3,024。三角形数はフレームレートそのものではなく、実機の GPU 時間・メモリ・対戦中の負荷は未測定。

ユーザーの追加指摘に合わせ、眉の外端の丸い膨らみを抑えて外端が緩く斜めに収まるよう調整。既定の眉は外側の高さもわずかに下げた。パッチ適用後の正面・斜めと複数の眉／帽子の描画を確認し、共有スイープ関数の既定動作の等価性と顔関連の既存テストを実行した。

眉外端の調整では端面の分割を増やしたため、上記の2026-10-31比較値からゲーム用LODの各髪メッシュに96三角形増加する。最終結果は Tide 8,888、Spike 6,576、Twin 9,560、Bob 4,132、Pony 7,584、Crest 5,416、Knot 5,344、Swoop 3,120。96通りのメッシュ検査を再実施し、すべて通過した。
