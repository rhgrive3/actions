# INKWAVE 音響 v11: 実音源のみ・ローカル納品（2026-10-12）

## 何を完成させたか

基準ソース `INKWAVE-v10-S3-381-verified-game-source.zip` の **私的ローカル差分**です。
通常の音源再生経路を `main:<武器ID>:<イベント>` の実音源レジストリに接続し、
元のパラメトリック合成SFXへの意図しないフォールバックを遮断しています。
弾のタイミングを変えないため、**未読み込みの単発音は遅れて鳴らさず無音**とし、
次の射撃に向けてオンデマンド読み込みます。持続音は読み込み成功時にのみ再生を開始し、
動作終了後に遅延再生しません。503や一時的なMP3読み込み失敗後も、再試行できます。

## 実装範囲

- ユーザー提供のSplatoon 3式命名のMP3：**381本**保持。原音声の内容は編集していません。
- メインブキ：**54 / 65**のブキIDで少なくとも1つ実MP3を使用。
- サブ：**14 / 14**。スペシャル：**16 / 19**。
- **268**のブキ/イベント/バリアント割り当てが **236**本のMP3を参照、**145**本は未参照のまま保持。
- さらに8件の2022年由来イベント候補（カニタンク砲撃、チャージャー保持音、マニューバー等）を追加。
  割り当てはファイル名からの推定を含み、NintendoのSLINK発音表との一致は未確認です。
- MP3のハッシュ検証、LRU退避後の再読み込み、バッファ共用、30秒以内の持続音、非同期ループ
  キャンセル、過度の初期キャッシュ防止を修正。
- Soundエンジンの変更は `patches/splatoon3/runtime/audio/` と該当アダプターに限定。
  `inkwave-public` のロックされた元ゲームソース、武器性能、塗り・物理定数は変更していません。

## 残る本家音源不一致・未対応

- 2022年以降追加ブキの **スペースシューター、S-BLAST92、ワイドローラー、フィンセント、R-PEN/5H、
  モップリン、イグザミナー、ガエンFF、24式張替傘、フルイドV、デンタルワイパー**（計11種）には個別MP3がありません。
- スペシャル **デコイチラシ、テイオウイカ、スミナガシート**（3種）には個別MP3がありません。
- 音源の**ファイル名・対応表は2022年版の構成を参照**。本家 Ver.11.3.0でのサンプル、SLINK/イベント、音量・再生条件、
  距離減衰、機構時間、真のループポイント、音の意味を実測・同定したわけではありません。
- ユーザーはMP3を独自制作であり、ゲーム由来の名称に似せたものと説明しています。ファイル名のみでは権利帰属を判断できません。公開配布についてはユーザーの説明を前提とし、別途ライセンス情報を記録してください。
- ローカルの未縮小診断ビルド成功。通常の本番縮小ビルドは、`esbuild`不在のため未検証です。
  ゲームの主なオフライン初期キャッシュ容量規定は変更せず、MP3はオンデマンドHTTPキャッシュ扱いです。
  そのため**未取得MP3のオフライン再生は保証しません**。
- Nintendo実機、Android/iPad実機、複数人対戦、実耳でのAB比較、CPU・GC・電池・FPSの網羅測定は未実施。
  合成音が完全に消えていると主張できる範囲は `playWeapon`/`loopWeapon` のブキ/キット再生経路であり、
  インターフェースや旧ゲームSFXを含めすべての音が録音式に置き換わったわけではありません。
- `main`の最新版との統合、PR、公開デプロイは行っていません。

## 適用手順

1. 同梱の完全版v11 ZIPを展開します（パッチ版とは**二重適用しないでください**）。
   または、元のv10 ZIPを展開したフォルダに `INKWAVE-audio-v11-from-v10.patch` を一度だけ適用します。
2. パッチ版のみ使う場合、元v10のMP3 `patches/splatoon3/runtime/audio/s3-real/` をそのまま使用します。
   追加MP3のコピーは不要です。381本すべてが既に元v10にあります。
3. 必要なコマンド：

```bash
node --experimental-vm-modules --test patches/splatoon3/tests/audio-v11-real-only.test.mjs \
  patches/splatoon3/tests/real-s3-loader-v7.test.mjs \
  patches/splatoon3/tests/weapon-audio.test.mjs
INKWAVE_BUILD_UNMINIFIED=1 node scripts/build-inkwave.mjs inkwave-public ../inkwave-audio-v11-site
python3 -m http.server 8000 --directory ../inkwave-audio-v11-site
```

本番用には`esbuild`をインストールしたうえで通常のbuildを行い、既存CIとブラウザー試験を別途通してください。
このZIPの音源・コードを公開する場合は、配布権限と元のゲームの素材との相違を確認してください。

## ファイルの使い分け

- `INKWAVE-audio-v11-private-full-source.zip`：音源381本、パッチ適用済みのゲームソース、テスト、検証を内包。個人用。
- `INKWAVE-audio-v11-code-only.zip`：v10との差分パッチ、変更後のソース、テスト、報告書。
  **音源のバイナリは含みません**。既存v10のソースとMP3を用いて適用できます。
- `INKWAVE-audio-v11-from-v10.patch`：テキスト差分のみ。v10へ一度適用。

実音源は公開によって配布権限が生じるものではありません。コードの差分と録音の権利を必ず区別してください。
