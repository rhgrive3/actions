# INKWAVE 実機GPU負荷診断（ブラウザGPUタイマー非対応向け）

**適用:** INKWAVEの設定で「Debug profiler」を明示的にONにした場合のみ。通常プレイ時の画質・動的解像度・通信・当たり判定・描画内容を変更しない。

## なぜGPU msが出ないのか

実機ログの `gpu: "unsupported"`、`gpuPaint: "unsupported"`、`gpuSamples: 0` は、GPU計測に必要な WebGL2 拡張 `EXT_disjoint_timer_query_webgl2` が、そのブラウザのWebGLコンテキストで取得できなかったことを意味する。GPUが遊休だった、GPU所要時間が0msだった、という意味ではない。

`gpuCommandsMs` は対応環境でも非同期取得であり、GPUの画面表示・OSのコンポジター・VSync待ち全体ではない。未確定値は `null`、未測定のGPU最大時間も `null` にする。時間の捏造や `gl.finish()` による停止は行わない。

## 実機で試す手順（合計4回、各6秒）

1. 本家と比較したい**同じ練習場・同じブキ・同じ位置とカメラ方向**で Debug profiler をONにする。
2. 上部の描画解像度から **「診断 60%」** を選択する。自動解像度調整を診断中のみ止める。
3. **「① 待機6秒」** を押して触らず測る。続いて **「② 連射6秒」** を押し、なるべく一定方向へ撃ち続ける。
4. 描画解像度を **「診断 100%」** に切り替え、同じ待機6秒・連射6秒を繰り返す。品質設定、ブキ、ステージ、端末の向き、発射方向は変えない。
5. 既存の **Copy trace** でJSONをコピー。最後に **「標準（自動）」** に戻すか、Debug profilerをOFFにする。どちらも元の描画スケールと動的解像度制御を復元する。

低解像度で元々60FPS付近に張り付いていると改善が天井で見えない場合がある。照準の動かし方、インクの残り、影、ボット・通信状態、端末の熱/電池制御も揃える。診断中にアプリをバックグラウンドへ移した場合、その測定は無効になる。

## ログを見る場所

`shooterAB.resolutionSweep`:
- `completed: 4`、`status: "compared"`: 60%/100% × 待機/連射の4条件が取得でき、条件不一致警告がない。
- `status: "incomplete"`: 未計測の組合せがある。 `status: "conditions-differ"`: ステージ・武器・画質などが途中で変わった、描画スケールが固定できない、または実描画バッファが大きくなっていない。
- `phases.fire.highMinusLowFrameGapP50Ms`: 100%にした際の中央値フレーム間隔の増加（ms）。
- `phases.fire.highMinusLowGameWorkMeanMs`: 同じ比較でのゲーム処理時間の増加（ms）。
- `sensitivity: "resolution-sensitive"`: **画素数に依存する描画・合成負荷を疑う根拠**。GPU実測ではなく、GPU断定でもない。
- `sensitivity: "no-clear-resolution-dependence"`: この条件では差が小さい。GPUが軽いことの証明ではない。
- `directlyMeasuredGPU: false`: 解像度による推論とGPUコマンド時間の直接測定を混同しない。

`gpu: "unsupported"` の端末では、GPU時間や使用率（%）はわからない。厳密なGPUコマンド時間やハードウェアカウンターが必要なら、実機のGPUプロファイラ等の別途計測を行う。

## 診断結果を受けた次の検証

連射時に100%が明確に遅く、ゲーム処理時間の増加は小さい場合、レンダーターゲット・ポストエフェクト・インク描画の画素負荷を、**画質・当たり判定・通信を変えないA/B修正**で検証する。解像度の影響が小さい場合、CPUメインスレッドと、画素数に依存しないGPU/コンポジター/フレーム制御を別々に追う。単一試行で原因確定とはしない。

## 計測の安全性

- 既存の6秒のうち最初の1秒をウォームアップとして除外し、各試行最大1000フレームだけ保持する。
- ライブのゲーム処理や射撃・通信をスキップしない。診断操作がなければ新しい固定解像度は使わない。
- 非同期GPUクエリが後から解決した場合だけ停止済みキャプチャのGPU欄を補完する。CPU欄は取得時点のまま、4MiB等の容量上限は維持する。
- 自動ログ送信なし。端末実機の計測値は利用者が明示的にコピーした場合のみ共有される。
