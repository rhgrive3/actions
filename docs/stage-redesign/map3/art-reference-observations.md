# MAP3 実ステージ造形・素材の視覚参照

調査日: 2026-10-31 UTC。対象: 通常公開ステージ Tidewater Plaza / Kelpline Terminal の実装に使う、独自の橋・手すり・装飾・素材設計。地形設計の根拠と計測限界は [reference-observations.md](reference-observations.md) と [source-audit.md](source-audit.md) を継続する。本書の色・細部は独自デザインの提案であり、本家のアセット・ロゴ・配置を複製する指示ではない。

## 視認方法と版の扱い

- 下表の7点は画像本体をブラウザで開き、返されたスクリーンショットの画素を実際に視認した。Web画像検索の `ImageDisplayed` テキストや自動説明だけを視認と数えていない。
- 静止画の画角内で見える構造、色の分配、素材の見え、装飾の置き方だけを記録する。動画は再生していない。隠れた床、通行可否、塗り可否、衝突、正確な寸法・高さ、操作速度は、この調査から確定しない。
- ファイル履歴の日付は投稿日時であり、撮影ビルド番号ではない。発売前宣伝素材と実プレイ画像を分け、全画像でルールは未特定とする。ブキ・ギア・操作条件を揃えた比較ではない。
- 参考画像をゲームへ組み込んでいない。画像の複製を成果物として同梱したとも主張しない。公開ページと実際に開いた画像URLを記録する。
- 画像検索はSplatoon 2の2017年マンタ画像をSplatoon 3として説明し、Shipshapeの追加を10.0.0として説明する結果も返した。それらの自動説明は採用しない。下記のページ来歴と任天堂一次資料で年代を分けた。

## 直接観察した造形

**A1 Crableg**: 画角は下から見上げる建設現場で、床全域は見えない。黄色の三角トラスと管状手すり、赤茶のリブ付き貨物面、緑の格子面、暗い梁下面が、淡い建築外壁・青いガラスの背景から分かれて見える。安全色が梁や手すりなどの用途に沿って反復する。小さいボルトの厳密な形や床の通行条件は読めない。

**A2 Hammerhead**: 見下ろし画角に、白灰色の縦溝パネル、四周を枠で囲む青い保守パネル、継ぎ目のボルト列、赤い作業籠と床外側の三角ブレースが見える。広い灰色床には細い暗色目地・排水溝・黄色の端線がある。床の上と下面を同じ色の箱で終わらせず、端部の細い層と支持材が構成を説明する。

**A3 Shipshape**: 低解像度の遠景なので細かな粗さやボルト配置は判定しない。白灰色の床板、暗い垂直壁、緑の格子状部、赤い縁材が近景を分節する。背景の大きな白青・桃色の塔や貨物面は、戦闘域の小さい物体より大きな色面で場所を示す。複数の段床が見えるが、陰の全接続や各素材のルールは未確認。

**A4 Hagglefish**: 明るい灰色の舗装を基本に、木製の坂・縁、薄い黄橙の端線、黒い手すりを組み合わせる。商品箱、折りたたみ式に見える屋根、日傘、電柱と案内、木製売店が、小さなまとまりとして置かれる。上空に細い旗・灯りのケーブルが横切る。広い歩行面と売店周囲の情報密度が異なり、全床に同じ細密模様があるわけではない。

**A5 Manta**: 手前に緑の床、左に黒い外枠の青い不透明パネル、右に木目の柱と太い黒金属の根元が見える。白い船体、細い赤茶の手すり、綱・金具、端の黒黄線が役割別に分かれる。海と床の境界、手すりの透け、不透明パネルの遮蔽の違いは見える。ただし見た目から本家の弾・イカの通過条件は決めない。

**A6 Flounder**: 上部が大きく写った遠景。白い建物面、暗い基壇・縁、露出した濃色配管、枠のある金網フェンス、少量の緑が見える。窓、屋上柵、配管の反復が建物の用途を説明する。橋下や低所は画面の下端で切れているため、見えないルートや支柱配置の証拠にはしない。

**A7 MakoMart**: 天井の暗色三角トラスと白い線照明が上部に反復し、床は白灰色、坂は淡い木質、棚・カバーの側面は暗色で構成される。商品パッケージや小札の細部は主に垂直面へ集まり、枠の橙色、細い青色縁、黒黄の端材がまとまりを作る。赤橙・青緑のインクが広い面に乗っても、床とカバーの輪郭が追える。

## 独自ステージへの翻訳

これは参考画像の色を抽出して再現する作業ではない。以下の色・素材名・置き方はINKWAVE向けの設計判断である。

| 用途 | Tidewater Plaza | Kelpline Terminal | 実装で確かめる意味 |
|---|---|---|---|
| 主な塗り床 | 暖かい明灰色の石舗装。低コントラストの大判目地 | 薄い灰緑の作業床・淡い鋼板。継ぎ目は控えめ | インク色と人物の輪郭を優先し、全面の細密ノイズを避ける |
| 垂直量塊 | 暗い石基壇、クリーム色の壁、限定した焼物色 | 濃い青緑・炭色の鋼殻、淡い保守パネル | 床と壁を明度・目地方向で区別する |
| 橋の特徴 | 銅色または深い青緑の桁、石端材、暖色の裏面梁 | 重い端桁、短い斜めブレース、鋲のある接合板 | 橋は厚み・支承・下面を持ち、渡れる床と通り抜ける空間を説明する |
| 端部 | 低彩度の真鍮・砂色の細い縁。危険箇所だけ明確な帯 | 黄土色の安全線、濃色の管状柵、局所的な黒黄表示 | 全端を派手にせず、即死水際・回復低所・通常段差を区別する |
| 装飾 | 売店、日よけ、植栽基壇、地域案内の小群 | 保守箱、配管束、巻取機、荷役番号、ドック器具の小群 | まとまりに用途と支持を持たせ、ランダムな小物散布をしない |
| 遠景ランドマーク | 街区の庇・時計または公共案内の独自輪郭 | 港の信号桁・貨物設備の独自輪郭 | 戦闘域の視線を遮らず、2ステージの第一印象を分ける |

### 橋を最後まで作る

1. 主床と同じ幅の巨大な箱へ色を付けるだけで終わらせない。歩行面、端材、桁、下面、支持へ役割を分ける。上路の接続先が見える構図を優先する。
2. 装飾桁は既存のsolid範囲に収めるか、衝突と一致させる。低路へ突き出す見える鋼材を無衝突で追加すると、身体やカメラが貫通する誤読を生む。
3. 実体のある欄干と、runtimeでイカ・弾・カメラを通すgrate/railを区別する。穴のある見た目と一枚のsolid衝突を無説明に組み合わせない。
4. 接続口と意図的な降下口を装飾柵で塞がない。地形・coverの規定された可通幅、tower、ranked目標、スポーンからの最初の見通しを守る。
5. 4.2 WU / 3.0 WUなどの提案上の下面高さを、下面ディテール追加後もそのまま通行保証としない。実Actorとカメラで再確認する。

### 商用水準を目指す時のレビュー基準

素材数や小物数を増やすだけで完成判定しない。同じ形の角箱が何十個も違う色で並ぶ状態、浮いた手すり、見えない衝突、床を隠す過密な模様、人物と同じ強さの装飾、暗すぎる下路、支えのない長い床を実ビューで探す。両陣営のスポーン、中央の上路と下路、橋下面、水際、塗りが広がった戦闘状態を別々に見る。

静止画の美術比較は操作・戦績・公平性の検証を代替しない。実行結果は [runtime-art-review.md](runtime-art-review.md) に、対象ファイル・画像・状態・残課題を分けて追記する。
