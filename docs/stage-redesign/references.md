# スプラトゥーン3 地形・動線の調査メモ

調査日: 2026-10-31。事実と提案は区別し、ステージ形状を複製せず、移動・塗り・射線の関係を設計に転用する。本文中「中」は二次資料による構造記述で、対象ルールや版の確認を要する。「高」は公式がその事実を明記することを指し、設計効果の実証ではない。

## 任天堂の公式資料

- **高: 経路と拠点の選択肢。** Ver. 8.0.0（2024-05-30、米国日付）で、タラポートショッピングパークとマサバ海峡大橋は全ルールで中央へ至るルートと戦略的な地点の選択肢を増やすよう地形を変更した。ほかの複数ステージも変更している。[Nintendo Support 更新履歴 Ver. 8.0.0](https://en-americas-support.nintendo.com/app/answers/detail/a_id/61257/~/splatoon-3-update-history)
- **高: 地形を後から変更する実例。** Ver. 5.1.0（2023-10-17、米国日付）はマヒマヒリゾート＆スパの全ルールの地形を変更した。公式のこの項目自体は変更形状や効果を詳述しない。[Nintendo Support 更新履歴 Ver. 5.1.0](https://en-americas-support.nintendo.com/app/answers/detail/a_id/61257/~/splatoon-3-update-history)
- **高: 公表された立体構造。** 任天堂はゴンズイ地区を、歩道橋が上を通る立体的ステージとして紹介した。ただし2021年の発売前紹介であり、現行版の正確な配置図ではない。[Nintendo UK 公式紹介](https://www.nintendo.com/en-gb/News/2021/September/Fresh-Splatoon-3-deets-revealed-in-latest-Nintendo-Direct--2045101.html)

## 複数の実例（Inkipedia は非公式、記述と版・ルールに注意）

- **タカアシ経済特区、ナワバリの記述（中）:** 塗れる下層の地面が大きな金網橋の全長の下にあり、下側から中央の橋に向かうインクレールや、橋の途中の塗れる足場がある。ガチエリアではその金網の下がエリアで遮蔽物のブロックを追加。上と下を同じ平面の描画に潰せない事例。ただし敵陣へのアクセスは金網橋に依存する、と同資料にあり、すべての区間が複数独立ルートとは言えない。[Crableg Capital](https://splatoonwiki.org/wiki/Crableg_Capital)
- **ナメロウ金属、Ver. 6.1.0以降の記述（中）:** 中央の高い足場群を金網が結び、ガチエリアは中央の金網の下。改修では金網の一部を坂に置換し、坂・遮蔽物を増やし、中央を広げたと記述される。上層接続と下層目的地に加え、素材・遮蔽・接続を同時に調整した例。公開資料の記述であり、優劣は未検証。[Mincemeat Metalworks](https://splatoonwiki.org/wiki/Mincemeat_Metalworks)
- **ゴンズイ地区（中）:** 橋が上下の層を分けると記述される。ガチエリアは橋の中央部が取り除かれ、別の通行・射線関係になる。ステージ名だけで全ルール共通の接続とは扱わない。[Eeltail Alley](https://splatoonwiki.org/wiki/Eeltail_Alley)
- **チョウザメ造船（中）:** 中央の橋の下に小さな金網エリアと遮蔽物があり、橋の周囲には高低差がある。跳ね橋の上下により通行可能性が変わる、と記述される。動く橋は必須要件ではなく、上下で重なる空間の例。[Sturgeon Shipyard](https://splatoonwiki.org/wiki/Sturgeon_Shipyard)
- **マヒマヒリゾート＆スパ、Ver. 5.1.0以降（中）:** 二次資料は中央の拡張、中央への島の追加、塗れる柱による高台アクセス、金網の追加を記載する。公式は地形変更自体を確認できるが、各詳細は二次資料に依存する。[Mahi-Mahi Resort](https://splatoonwiki.org/wiki/Mahi-Mahi_Resort)
- **金網の性質（中）:** インクが付かず、ヒト状態で歩け、イカ／タコ状態で通過し、インク弾も通るという説明がある。射撃・爆風・ボムなど全攻撃の扱いを一律に仮定せず、対象動作を個別に確かめる。[Grate](https://splatoonwiki.org/wiki/Grate)

## 転用する設計案（上記事実からの推論・未検証）

1. 進行方向と横断方向を変えた **地上の塗れる通路と高架の通路** を中央付近で上下に交差させる。見た目だけの橋でなく、地上も連続し通行・塗装可能とする。上と下は別ノードにし、交差位置のみで接続した扱いにしない。坂・塗れる壁・短い降下を明示的な接続点として配置する。
2. 開始側から中央へ、地上の入口と高架への登り口を別に用意し、途中の合流点や退路を設ける。単に分岐してすぐ同じ狭い入口に収束するだけでなく、プレイヤーが異なる地点に到達する選択肢を試す。両陣営の移動時間、選択肢、復帰経路を検証し、効果を決めつけない。
3. 金網の上は立って通れるが泳げず、射線も通る区間にする。隣に塗れる着地点を用意して、泳ぐと落下する挙動・上下のインクの到達・塗装結果を視覚的に分かるようにする。接続や判定が本家と一致するかは実機比較が必要。
4. 中央と接近路に背の異なる遮蔽物を分散し、長い射線を時々遮る一方、入口と上下の出会う地点は視認できるよう試す。高台からの射線、下層の逃げ場、遮蔽物の裏の塗り、カメラの圧迫を両陣営から検証する。
5. 上層の下の衝突・塗り・表示は独立した面で扱い、同一 X/Z に上下の移動可能面が同時に存在できるか確認する。地上・上層それぞれの歩行、ジャンプ、降下、射撃、塗装、復帰と上下貫通をブラウザで試す。見下ろし図だけでは上下の誤接続や空中への塗りは判断できない。
