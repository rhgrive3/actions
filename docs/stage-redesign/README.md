# 2ステージの立体構造：設計書

**最新案：[MAP3 — 分離した立体地形設計・同縮尺図・面積検算・3D閲覧モデル](map3/README.md)。このページ以下は初期案、[map2/](map2/README.md) は高さの偏りを監査した前案です。現行ゲームの途中実装とは別です。**

旧資料の「1 WUを1 mと扱う」表記にはSI単位との較正根拠がありません。最新案ではWU / WU²を用い、ネイティブ・現行・提案を同じ方法で再計測しています。

このフォルダーは、現行ゲームとは別に作成した再設計の資料です。Tidewater Plaza と Kelpline Terminal の2ステージについて、平面だけでなく上下に重なる床・入口・着地点・塗り・ルールを設計します。既存のステージにあるテラスをそのまま増やす案ではありません。

- [Tidewater Plaza：海辺の段状街区](tidewater.md)（[層ごとの平面図](tidewater-plan.png)）
- [Kelpline Terminal：二層の荷役水路](kelpline.md)（[層ごとの平面図](kelpline-plan.png)）
- [本家の調査と出典](references.md)

両図面は、移動可能な床を高さごとに分け、同じ X/Z でも「上層」と「下層」を別の経路として扱います。金網は床に重ねず区間を置き換え、イカと弾が抜けた先に何があるかも明記します。どちらも180度回転対称を基本とします。

図中の長さは INKWAVE の 1 ワールド単位を 1 m と扱った設計値です。ネイティブステージの設定座標との比較には使えますが、本家実機の現実寸法を確定するものではありません。外接面積、塗れる床の概算、実際のプレイ可能面積は別物です。

この資料では、**計画した形と設計上の意図**、**既存コードから確認できる制約**、**未検証の挙動やバランス**を分けています。設計数値の提示は、対戦での完成や実機との一致を証明しません。製品へ反映する前に、各文書の検証条件に従って独立したブロックアウトを作り、両陣営・各ルール・複数の武器を確認します。
