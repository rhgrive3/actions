## Tidewater

上層は y=3.2 の L 字が2つで合計 736（格子64を含む）。下層と同じ XZ に重なるのは最大 736、下層面積の 7.1%。柱・壁・階段の占有やキャラクターの寸法は含まず、実際の上下通行面積ではない。上層同士は直接つながらない。

主な問題は、下層が y=0 と1.2に約82%集中し、高さがほぼ Z 方向の帯で切り替わること。独立した上層も両側の y=3.2 に限られ、中央の立体的な高低差や中間テラスが不足する。壁上面に乗れるかは未指定。

## Kelpline

下層の基本床 10,152 はすべて y=0。y=3.2 の上層は通常床 2,144 と格子 152、合計 2,296。これらは下層と同じ XZ にあり、上下に重なる水平投影は最大 2,296、下層面積の22.6%。壁・階段占有や実際の通行は未考慮。スポーン床は y=2.6、階段は途中の高さを持つが、床を置換する。

主な問題は、高さが下層0と上層3.2に集中し、階段の途中以外に中間の独立した地形がないこと。上層は中央から |Z|=42 の範囲内に集まり、両基地側の各30 WUには上層がない。単純な2階建てを越える地形構成の検討が必要。
