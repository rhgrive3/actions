# スペシャル・サブの追加修正（2026-10-17）

比較対象は Splatoon 3 Ver.11.3.0 の通常対戦。第1弾 [PR #1553](https://github.com/rhgrive3/actions/pull/1553) の main `f75aefae5c7e08cf23a8369cc606a1080a826b5c` を基準に、公開根拠がある残差を修正した。カニタンクの性能値と上流 `inkwave-public/` は変更しない。

## 弾の発生と通常操作

[ウルトラショット個別Wiki](https://wikiwiki.jp/splatoon3mix/ブキ/スペシャルウェポン/ウルトラショット) の4Fごとの球発生に対し、以前は3球とも同時に描画・飛行・通信していた。単一の native projectile list と既存 delay を使用し、0・4・8Fでそれぞれ発生するよう修正。遅延中は当たり判定・塗り・送信を行わず、既に発生した球は使用者の死亡後も飛行を続ける。未発生の球は死亡・新lifeで取り消し、clearとpool再利用で状態を残さない。同一射撃の最大ダメージ共有は第1弾のまま保持する。

発動中の Actor は専用移動処理だけを通っていたため、通常の潜伏・浮上・壁登り経路を使用できなかった。通常 Actor.update へ委譲し、メイン・サブ・マニューバーのスライドを抑止して、ZRはスペシャル発射に使用する。資源・接地・姿・時計・finishを二重更新しない。

4Fは有志検証値。最初の発射時点の照準・銃口を後続球にも保持する既存校正は残る。Wikiの潜伏速度「約1.82」は330Fの移動距離からの推測で、正確な減速率・重量との関係は要検証。通常中量1.92との近似比を既存の潜伏速度に適用し、歩行の抽出値と潜伏の暫定較正を別metadataに記録した。

## ショクワンダーの装甲

[個別Wiki](https://wikiwiki.jp/splatoon3mix/ブキ/スペシャルウェポン/ショクワンダー) と[システム詳細仕様](https://wikiwiki.jp/splatoon3mix/システム詳細仕様) が示す30HP装甲、耐久0後の破壊猶予20F、100を超える単発攻撃の貫通上限80、床到着で解除・壁到着後18Fを接続した。20Fを「すべての移動後に残る時間」とは解釈しない。壁上の攻撃・イカ化・ジャンプで解除し、同じ移動中に壊れた装甲は復活しない。

サブ軽減を適用した後で装甲へ渡し、貫通分にサブ軽減や別の装甲を二重適用しない。第1弾の同一射撃最大ダメージの増分とも整合させる。通常スポーン装甲・イカロール装甲の既存プールは別に保持する。

これらはコミュニティの検証値。固定1130 Hook抽出表で省略されている継承値を、抽出済みの値とは表記しない。引寄せ速度・到達snap・斜面の床壁分類・壁保持姿勢の原作一致は引き続き未確認。

## 作動後のゲージ

[スペシャル総覧の使用後のゲージ回復](https://wikiwiki.jp/splatoon3mix/ブキ/スペシャルウェポン#a6ebc309) と各個別ページ、固定1130値を区別して接続した。キャラクターの使用モーション終了と、塗りで再充填できる時刻は一致しない。

| 対象 | ロックの起点と終了 |
|---|---|
| マルチミサイル | 発動から600F。弾の消滅・使用者の死亡で短縮しない |
| デコイチラシ | 発動から635F。個々のデコイを全破壊しても短縮しない |
| ホップソナー | 投げた時点から360F。装置破壊で早期解除。残る波の寿命と別 |
| スミナガシート | 作動から300F。シートの総寿命や仮置き680Fとは別 |
| グレートバリア | 実際の点火から外殻の破壊・消滅まで。既存のHP・時間減少・ギア延長を使用 |
| アメフラシ | 投擲要求ではなく実雲生成から、当該cloudの実duration。既存の時計1本を使用 |
| エナジースタンド | 第1弾の設置から600F／先行消滅で解除を維持 |

塗り・両逆境強化・ガチルールのホスト／受信側ポイント・ナイス送信の全経路と使用可否へ共通判定を適用。ロック中に受信したポイントを解除後へ後払いしない。死亡・復活でも継続する。remote・ghostの表示用装置はローカルの時計を所有しない。ホコ取得は文書化された解除例外として、実際の取得処理へ接続した。
