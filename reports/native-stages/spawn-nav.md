# Native spawn-layer navigation

Native graph pruning now starts at both actual source-supported spawn layers and retains the directed reachable union. Previously the original graph selected the largest undirected component regardless of pad height. On Manta, it kept 5,487 lower-hull nodes and mapped both verified Y 8 GroundRoof pads to Y −4.08. The local ranked selector then chose an unrelated 47-cell hull strip.

The repair lives only in `runtime/native-nav.mjs`. It runs after every candidate node and physical edge is built, so separately reviewed wall-climb transitions can be included before pruning. Each seed needs the source down-ray support within 0.15 units of its pad, a nearby source-height candidate, continuous exact floor samples and capsule clearance from pad to node. The valid mask is exactly the directed union from those two seeds. No source mesh, collision, pad, flight velocity or traversal edge is edited; legacy `_prune` remains unchanged.

The real pinned source fixtures for Scorch, Hagglefish, Inkblot, Mako, Brinewater, Undertow, Sturgeon, Museum and Manta pass support-height, directed-union and unchanged source-buffer SHA assertions. Both source pads retain actual source-height nearest nodes. All four ordinary legacy map node/edge graphs and validity masks match their unadapted source exactly. The original five stages' complete CPU integration passes (support, body collision, paint/masks, existing painted-wall attach/enemy release, grounded 30/60/120 movement, navigation, local objective calibration, initial launch and BotBrain paint goals).

A real Chromium probe, holding `/workspace/actions/.ci-scratch/native-stage-browser.lock`, uses an actual Manta Turf match with eight actors and seven bots. Actual pads retain source triangles 17766 and 17768 at Y 8. Candidate lower-hull collision/support is preserved; none is falsely retained as playable navigation. The source minimap has 33,901 live paint pixels at 207×298. Both teams launch and move using existing actors. Native→Tidewater returns its original 4,158 candidates / 4,154 valid nodes with identical graph fingerprint and no page errors. Source screenshots remain private. The renderer is SwiftShader; this proves runtime integration, not hardware FPS or native console semantics.

The negative source evidence is kept: Manta's ordinary walk/jump/drop graph has separate upper deck components (737 valid nodes, 712 paintable), and verified wall-climb transitions are required before claiming common playable routes. Strict Brinewater full-slot bot landing-to-objective qualification is assigned separately; this change does not claim to repair a missing physical route. A supported landing alone does not establish an objective route.

Numeric evidence and the exact private build identity are in `spawn-nav-verification.json`. Comparison version is Splatoon 3 11.3.0 identity metadata only; extracted geometry date/units, native collision, climb/paint masks, placements, ranked routes and hardware performance remain unverified. `version1130Verified` remains false.
