# Archived Shipshape resume code

This WIP branch saves author-written checkers, analysis helpers and historical patches. It is not a Ready stage or an accepted common change. Product changes remain on their separate Draft PRs.

`manifest.json` records each original ignored path, exact byte length and SHA-256. To reuse a checker, restore its bytes to its original `.ci-scratch` path in the owner worktree; relative imports and local asset locations depend on that path. Confirm its intended artifact and prerequisites before execution. Historical combat overlays, executed diagnostic variants, v1/v2 patches and the old PR description preserve prior work; they are not instructions to replace current accepted runtime or to claim a current pass. In particular, the v1 refill patch's own-painted stance condition was rejected and narrowed in v2.

The files contain code and sparse scalar fixture/contact markers. They do not contain original mesh buffers, textures, screenshots, full ink grids, captured traces or test logs. Their local source/evidence readers require separately retained private ignored files. Source and evidence must remain private. The detailed private checkpoint is summarized in `../shipshape-REMOTE-RESUME.md` rather than copied here.

No build, source qualification or browser run was performed for this archival snapshot. Its alternate-index commit preserves both live owner/common HEADs, working trees and original indexes.
