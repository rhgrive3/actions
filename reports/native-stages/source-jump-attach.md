# Ordinary source wall jump attachment

The candidate adds an explicit `wallJumpAttach:true` navigation policy for an
ordinary grounded jump into a continuously paintable source facade. It uses
the existing bot move, fire, transform and jump inputs. The source wall's
unchanged fixed-spine straight-climb screen still rejects this contour.
No stage definition is activated by this shared change.

The original Shipshape export has a 0.15-unit wall contour that a grounded
wide squid capsule cannot approach closely enough to attach. An ordinary
human jump allows the existing controller to attach above it. Qualification
requires original paintable lower and upper supports, a clear supported
approach, actual original paintable wall intervals, visible ordinary shooting
points, an original capsule sweep at every installed gameplay `STEP`, and a
natural supported landing. Explicit NoPaint intervals, masked holes, suspended
departures and obstructed capsules remain rejected. Typed dispatch prevents
plain climb from consuming Surge, approach or jump-attachment edges.

The executor paints through actual ordinary weapon inputs, plants naturally
at its supported departure, issues one human jump, transforms into swimming
form, and follows the existing wall/ledge controller. Arrival requires
grounded original source foot support. It never writes actor pose, velocity,
ink ownership or jump serial. The accepted ranked traversal marker preserves
these inputs through the installed ranked wrapper.
