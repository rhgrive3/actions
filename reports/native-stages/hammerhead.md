This stage selects the revised `Vss_Kaisou04` display export. The older `Vss_Kaisou03` is not selected. The stage definition is discovered by the native-stage build catalog, so the public build exposes it in the match menu and fetches pinned source assets on first use. Source assets and generated derivatives remain in ignored local directories.
