# インク表面の質感：反射の線と乾かない艶（見た目のみ）

公開版 `inkwave-public/src/world/inkShading.js` の床・壁インクのシェーダー定数を変更した。塗り判定・所有・移動・射撃・カメラ・インク色・形状は変えていない。

観察した本家の特徴：

1. 塗られてから時間が経ったはずの広いインク面も艶があり、マットに乾いた面が見当たらない。
2. 白いハイライトは周囲（空・明るい物）の**反射**で、ゆるい大きなうねりに沿った細い波線として、限られた範囲に出る。日陰のインクにも出る。
3. 線と線の間のインクは、ほぼ均一なチーム色。粒状のきらめきや、面全体を覆う白っぽいもやは無い。
4. 太陽方向を向いても、ぼやけた大きな光の塊は無い。

## 変更前の INKWAVE との差と原因

| 差 | 原因（実ゲーム画面で成分を一つずつ消して特定） | 変更 |
| --- | --- | --- |
| 太陽側に大きなぼやけた白い塊 | 透明コートの下の顔料層の鏡面反射（粗さ0.26、強さ30%、F90 0.35）が広いローブで太陽を映していた。ブルーム・コートの粗さ・空の映り込みは主因ではなかった | 顔料層の鏡面反射を3%、F90 0.02 に下げ、艶はコートだけが担う |
| 乾くとマット（約6秒で粗さ0.06の半艶） | 乾燥の設計 | 乾いた後のコート粗さ 0.06→0.034（濡れ 0.028→0.026） |
| 細かい粒状のきらめき | ゲル法線（1 m 周期、細かいさざ波と窪み）を画素相当のミップで読んでいた | ミップを3段粗く読み、配置を床で約4.7倍に広げ（0.75→0.16、うねり約1.5 m）、傾きを1.6倍。細かい成分は消え、大きなうねりだけ残る |
| 白い反射の線が無い（空は淡く均一に映るだけ） | 空の反射を全体に一律1.25倍、グレージングの F90 0.3 | 空の平均輝度に対し 1.55〜1.65 倍を越える狭い帯（雲の縁）だけを白く6倍で映す。雲の中心と青空は淡いまま。F90 0.3→0.45 |

追加のテクスチャ参照・テクスチャ・描画パスは無い。シェーダー内の演算は内積・`smoothstep` が数個増える程度。

## 未確認・残る差

- **本家の実機・同条件の比較は未実施**。参照は1枚の公式静止画で、ステージ・空・カメラ・時刻が INKWAVE の画面と違う。数値は見た目の合わせ込みで、本家の値ではない。
- 本家の反射には周囲の建物・箱も映る。INKWAVE の環境マップは空だけなので、物の映り込みは無い（画面空間反射などは負荷の条件から入れていない）。
- 本家のインクが乾いて質感が変わらないかは、静止画1枚からの推定。塗った直後の波紋・明るさの変化（INKWAVE の約4秒の濡れ表現）は残した。
- 反射の帯は雲の縁を線にする様式化で、物理的な反射の再現ではない。曇り・夕方などの空のテーマ、原典ステージ、練習場、低画質（texlib 無し）の代替経路での見え方は今回撮影していない。
- 実 iPad・WebKit・実 GPU での見た目と負荷は未確認。
