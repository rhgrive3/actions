# #1434 same-native renderer input diagnosis

Two independent contexts of the unchanged frozen native build reproduced a strict pixel failure: one green channel at `(270,128)` (bottom-origin) changed from 60 to 59. Both contexts passed eight-living-actor, PlayerController + seven BotBrains, fixed scale, paint/projectile workload, enabled PWA and live audio/music-worker checks.

The new observation captured full precision Character/material uniforms, camera/world/projection matrices, actual sorted mesh draw order, material properties, geometry draw ranges and GL shader-source diagnostic hashes. All serialized start/end states and measured per-frame workloads are equal. Standard JSON can collapse signed zero and nonfinite values; the next collector explicitly tags them. The exact pixel gate remains rejected. This narrows the remaining search to unobserved upload bytes, textures, GPU-only targets or driver/pass behavior; it does not establish GPU nondeterminism as the cause.

A read-only SHA-256 upload-source collector is now prepared in `scripts/lib/inkwave-render-input-receipts.mjs`, with five passing regressions covering typed-view offsets, single-byte/float changes, signed-zero/nonfinite serialization, explicit GPU-only unknowns and read-framebuffer/pack-alignment restoration after errors. The next same-native probe preserves the original RNG fixture and additionally records bootstrap stream counts and exact geometry/index/instance/bone/texture source hashes. The subsequent exact-input probe rejected the initial GTAO-noise hypothesis: this medium-quality fixture has AO disabled. See performance-native-input for that correction and performance-native-actual-draw for the later actual GL input comparison.

A six-frame CPU profile gives new implementation evidence: 199.8 ms of sampled `Game._frame` descendant time, including Three submission, HUD tank drawing, motion FK and matrix updates. Endpoint hash/capture work was excluded from that attribution. Samples can include native/GPU waits, and the machine uses software WebGL; these are not iPad, Range or device FPS results. Physical acceptance for #1757/#1671 and native offscreen core-cost reduction for #845 remain pending. G0-unmeasured quality features remain disabled (#1565).

Raw PNG/RGBA, CPU profiles and the expanded state report are linked by path and SHA-256 in [performance-native-state.json](performance-native-state.json).
