# 傘表示とスペシャル操作の照合（2026-10-13）

対象: 公開版 `inkwave-public/` の配信アダプタ。基準は Splatoon 3 11.3.0、ギアAP0（個別のAP検証は各テストに明記）。数値修正PR1252と最新mainの双方を保持して統合。Wikiの説明と公開パラメータを照合し、操作の存在だけで一致と判定しない。

## 傘の不具合

- 手元の開いた布が武器の小さい外観寸法のまま。布のみ拡大し、グリップ・柄・銃口の取り付けは保持した。キャンプ2.8倍、その他2倍の開口は見える盾としての較正値で、実機ピクセル一致の測定値ではない。
- パージ時に手元の布を隠す一方、世界の布メッシュが存在しなかった。同じキャッシュ済みの布・骨の形状を世界側で描画する。飛行方向・位置・寿命・HPと表示を同期し、イカ化・サブ使用・ランナーresetから飛行を独立させた。
- パージを止める/消す時に個別マテリアルを破棄し、共有ジオメトリは保持。遠景でも閉じた静的傘で開いた傘を置き換えない。
- キャンプ/パラ/24式を実際のActor・Runner・Characterで開き、飛ばし、reset・clearで確認。スパイは従来どおりパージ不可。
- 実機寸法・弾との当たり判定形状、通信相手のパージ表現、坂への追従は未確認。この修正をそれらの完了に読み替えない。

## 検証の区分

実際の配信アダプタを通したロジックと、実際のキャラクター/メッシュで回帰テストを行う。`scripts/check-inkwave-brella-controls.mjs` はビルドされたモジュールでWebGLピクセル差・飛行表示・消去を確認し、PNGとJSONを保存するCIゲート。ローカルではブラウザの取得が失敗した。GitHub Actions run 38339795179 の catalog shard（06c1ba637ab29522916a816d1058d4eff3dce52a）ではWebGLの開口・パージ・reset後の移動・消去が通過。実機比較とは区別する。

未公開のデフォルトや本家との実機比較が不足しているため、全19種の完全一致は認定しない。操作の不具合を直したこと、公開値の照合、実機完全一致は別々に記録する。

### 追加検証と実行環境の切断

関連27ファイルの追加検証で、旧即時充電/無操作吸引/8デコイ/無標的ミサイル発射のfixtureが残っていることを確認。装甲破壊後の汎用25%軽減の重複、クイックボムの25直撃→35爆風に対して通信上限が25だった問題、シールドへの接触爆発の防御経路も検出した。

追補ではcustom装甲を独立したHP所有者とし、Burstの通信上限を35にして両段階を通す。ソース表のBomb_DirectHitはNiceBall_Armor 1.5、Shield 2.0、Chariot 1.0。盾の手前側から爆風の遮蔽を問い合わせる。旧fixtureは実際のR離し/充電済み/吸引ZR保持条件へ変更し、二段階/各JSONの再送/対物倍率の検証を保つ。

この追補の再検証中に実行環境が409 environment_offlineになった。追補は未検証であり、前段で通過した56件/60件などを追補後の通過件数に読み替えない。総合CIとWebGLはキュー待ち。完全再現は未完了、mainには未反映。

### 通信停止・実地接地・総合再検証

キューインキの相手側は発動後の経過時間で吸引判定を伸ばし続けていた。既存のnative firing flagをVacの物理ZRレベルに割り当て、snapshotの押下/離し/イカをreplicaに反映。離すと表示・吸引候補・敵への減速を止め、再開時はinhaleAgeをゼロから伸ばす。実NetMatchのpack→JSON→受信→sample→applyRemoteで、無入力（残存firingTを含む）、保持、離し、再押下、イカ化を検証。charge/damage所有者は変更しない。遅延中の既存提案のserial/peer/attack/dedup条件を保持。

実Physicsの接地でスタンドをnormal方向へ0.03上げると、ServeAreaHeightDown=0の受け取り判定に対して同じ床のActorが下側になる。地面接触のpositionは面上に置き、壁に触れる飛行だけオフセットする。配信browser probeの実床/実throw→実drinkと、JSON takeoverの本来の残存時間で再確認した。

Source parityの古いfixtureにも、二段階Burst 25→35、TorpedoのBombH軽減（Burst/FizzyのBombLと区別）、400FシールドHP自然減衰、30F後のNice armor、50% Mist/60F初回drain/ジャンプ低下、投擲接地スタンドを反映。反例（過大hit、重複JSON、raw装甲、退出/死/装備変更、再送、期限切れ）を維持した。ブキ別の塗り試験は各戦場をclearし、Runner resetをまたいで存続する前ブキの傘を持ち越さない。
