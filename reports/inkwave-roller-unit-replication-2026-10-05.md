# Immutable Roller unit replication

New main Weapons/Ballistics infers a ghost's Roller unit from its final launch-speed magnitude. PR536's sourced forward-velocity inheritance is added after the local unit is selected. At forward4 WU/s a vertical lower unit therefore changes from the local field collider .1→.55 over2F to the receiver's inferred .1→.75 over3F. The authoritative local attack remains correct, but remote contact/lifetime can differ.

The packet now records the index into the pinned `WideSwingUnitGroupParam.Unit` or `VerticalSwingUnitGroupParam.Unit` array at birth. These are group-record indices (horizontal0..1, vertical0..2); the five vertical bullets have indices0,1,1,2,2. The index is finalized before `_push` publishes the projectile and is cleared on pool reuse. No velocity subtraction, receive-time actor pose, or charge inference is used for new packets.

Wire compatibility: preserve fields0..29, insert unit at30, retain owner tick and event sequence as the last two fields (31/32). New complete packets have33 fields. Non-Roller packets use-1. New packets require a safe integer within the raw mode-specific unit table, a valid birth mode, and a known weapon; malformed packets are rejected before allocation and projectile/event identity advancement. Direct ghost entry applies the same validation. New packet birth mode owns table selection.

Legacy27/30/32-field packets retain the existing inference fallback. This keeps older senders readable; their moving-unit ambiguity is not claimed fixed. Old receivers likewise cannot use the new discriminator, so exact moving-unit fidelity requires the updated receiver. Existing velocity precision correction, the first30 fields, and footer interpretation remain unchanged.
