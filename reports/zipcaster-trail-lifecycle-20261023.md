# Kraken Royale / Zipcaster / Ultra Stamp special lane

## Result
One independent lifecycle fix is ready as a patch candidate, not visually accepted: Zipcaster's active pull ribbon is now ended when its special track retires. Baseline endTrack only ends `t.d.ribbons` and `t.d.recs`; Zipcaster stores its ribbon in `t.d.trail`, registers neither, and had no end handler. If a pull is interrupted by death, recall, expiry, replacement or actor removal, the idle frame branch never executes. RibbonPool only retires empty records when `ended` is true, so a dead empty record occupied the pool until eviction. The fix adds a Zipcaster-only end handler and clears the owned reference. It does not change visual shapes, motion curves, gameplay clocks, model geometry, materials, audio or other special directors.

Patch: zipcaster-trail-lifecycle.patch. Candidate: source/patches/splatoon3/runtime/special-vfx.mjs. Baseline authenticated source: /tmp/core-public-354536-0537/source at frozen head 354536b365ae54bac71c9ce2970a5c5f322c1304.
