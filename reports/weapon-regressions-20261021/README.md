# INKWAVE: reported weapon regressions (2026-10-21 JST)

Base: `a43276d8` (includes the concurrently merged roller holding/grip fix #1715). Public INKWAVE (`inkwave-public` plus production adapters), pinned gameplay reference S3 11.3.0, no gear unless a test explicitly applies AP 57. Source model exports and the 2022 audio archive have independent versions.

| Report | Cause and resulting correction |
| --- | --- |
| Dry squid slopes upward | Both native and loaded-source presentation applied a fixed 0.52 rad (~30°) dry pitch. Remove that offset; retain airborne travel pitch, source bone animation and jump ownership. |
| Charger paint too narrow | The finite-flight owner alone multiplied `SplashPaintParam.WidthHalf` by 0.2 while retaining full-scale depth, range and nearest paint. Restore the common distance scale in immediate and falling paint. |
| Scope cannot fire again | Legacy `charger_scope` omitted `rechargeDelay`; its first release set cooldown to undefined and the next update made it NaN. Supply missing normal-Charger recovery/admission endpoints without replacing its optics or kit. Three full-charge cycles tested at 30/60/120 Hz. |
| Charger charge/full-hit audio | Alias the legacy scope to its actual Splatterscope bank, preload charge/ready/full-shot before START, and preserve fired charge metadata in the asynchronous finite-flight contact. Resetting the trigger no longer converts a full hit to the normal damage recording. |
| Barrel Splatling sound | Use the existing original Standard Shot, Motor and MotorFire assets at recorded speed; native oscillator controls previously transposed charge/stream motor recordings up to 2.5x. Loops choose a stable original variant. |
| Roller too large | Export mesh coordinates had been treated as gameplay distance coordinates despite a different player stature. Normalize the source player's measured 1.72259927 height to the host 1.36 height, factor 0.7895057. All five families and their skins inherit the conversion, including frame, caps, muzzle and hinge. Normal drum becomes 2.0299743 instead of 2.5712. Contact/hand tests remain required. |
| Blaster critical at ~25 damage | A reduced body graze or delayed splash outside the synchronous `_blastBurst` scope looked like a full direct hit. Require the admitted damage to reach that weapon's direct-damage endpoint before choosing the critical recording. |
| Weapon visible during bomb throw | Native hiding covered only the second Dualie. Stow both main pivots during sub aim and recovery for all families; restore each original visibility on recovery, cancellation, reset and equipment change. |
| Burst Bomb origin/range disagrees with preview | Catalogue live objects spawned at actor centre +1.35, bypassing native hand sampling; native arc used a different launch/gravity law. Both now sample the same hand release and use identical AP/movement inheritance, gravity, drag, 60 Hz integration and first-contact test. Restore bomb-family gravity/drag calibration rather than unbounded no-drag flight. |
| Trizooka | Remove the invented 2.6° divergent fan; all three globs follow the common axis and their orbit. Grow orbit from the muzzle to the supplied radius over 10F, and use volley time for phase despite 4F staggered births. Activation uses 20F +15F first-shot windup, repeats remain 55F. |
