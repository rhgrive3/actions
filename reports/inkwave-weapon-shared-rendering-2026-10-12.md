## Rendering contract and cost

The shared optional `glass` geometry is never merged into opaque body/ink channels. It stays the same 256-triangle mesh at near and far LOD. One singleton physical material uses base opacity .22 with a bounded grazing-angle alpha increase up to .68, FrontSide, depth test on, depth write off, ordinary transparent sorting and no shadow casting. Transmission is zero: no screen-space refraction pass. One additional nonempty beauty draw per visible Ballpoint is expected (the native AO gate also issues a zero-count API call), with fewer total model triangles after deleting the pseudo-shell bars/rings and oversized fill. Shared material and geometry survive Actor disposal and are reused after switching weapons; no per-frame geometry/material allocation is added.

## Visual refinement and measured status

The first candidate fcb859b956b8ff451943f91daea91ee1be43c9f4 used a straight 64-triangle sleeve. Its actual production shader rendered transparent pixels on black/white backgrounds ([15,17,19], [214,216,218]), and its internal tubes became visible. However, the shell outline was too weak on white, while the old broad black front cone obscured the reference's clear shoulder. Shader pixel success alone was not accepted as visual success.

The revised candidate extends the clear sleeve over the rounded front shoulder and retains only the small opaque tip. An inexpensive view-angle alpha term gives the silhouette more reflection without a transmission pass, duplicate surface, outline draw or texture. ## Corrected completion boundary and valid environment (2026-10-12)

The historical `renderer.render()` plus `gl.finish()` timings above are submission/queue wall times, not completed rendering. Chromium's WebGL `finish()` implementation calls `ContextGL()->Flush()`; the baseline with no shell also changed from a few milliseconds to hundreds after its queue filled. Neither the favorable nor unfavorable old run proves the shell's completed-render cost. The 18f062 diagnostic crowd job timed out before the full ABBA completed and is retained as incomplete. General CI at 18f062 also had a held-touch input assertion failure; it is not all-green.

Completion diagnostic PR1295, head 71b0f142193e93a55c419963e14585145ed75dac, run 38251164380, uses the real high-quality post stack, eight Actors and 600×600 output. Immediate synchronous one-pixel readback of the final default framebuffer and a pixel-pack-buffer read queued before an asynchronously polled fence agree on the completed-output boundary. All 60 warm-up/observation frames return valid opaque pixels with GL error zero, no context loss and restored shared geometry ranges. Readback dominates the 0.87–1.46 second SwiftShader wall time while submission takes a few milliseconds. These three observations per mode are mechanism checks, not a performance acceptance test or real-device FPS estimate.

An earlier fence-then-default-read experiment returned transparent black after an asynchronous wait because this renderer does not preserve the drawing buffer. Its preceding five immediate reads and screenshot were valid. The failed raw artifact is retained; completion measurement now reads synchronously before yielding, or queues the PBO read before the fence. Compile/preparation, warm-up, measured output, screenshots and host collection are separate intervals.
