# ウルトラショットのモデルと持ち方

基準は main `67f708b650b1af788206a4c0e9e3dd879bfa3e44`。公開版に適用する `patches/splatoon3/runtime/special-motion.mjs` のウルトラショット専用モデル・構えを修正した。ほかのスペシャルのモデル・構えは変更していない。

## 問題と変更

以前は、短い簡略モデルを身体の中央寄りに持ち、銃口はインク色の平面でふさがって見えた。左右の手は設定した点に届いていたが、その点が本家の持ち手に対応している根拠は不足していた。

任天堂の公式画像を見比べ、長い銀色の蛇腹状の胴、六角の黄色いカラー、膨らんだ緑の前部、赤い縁と暗い奥行きのある砲口、銀の縦リブを持つ後部、大きな丸いカプセルとホースを作り直した。右手は低い後部の引き金グリップ、左手は高く前方にある斜めグリップを持ち、砲身を右肩・顔の脇へ配置する。

手と持ち手の誤差だけでは合格にしない。描画されたグリップの形、実際の指の穴と握る方向、肩・顔との位置関係を、正面・左右の斜め・側面・背面・機器単体の画像で確認した。

## 発射位置への影響

このゲームでは見えるモデルの砲口が、実際の発射位置にも使われる。古い発射位置だけを残す試作では、弾が修正後の砲口から約0.34 world単位離れて出たため採用しなかった。最終版は新しい砲口から実際に発射し、そこから照準点へ向かう既存の計算を使う。銃口と弾を別々に見せる代替軌道は追加していない。

そのため発射位置・初期方向と、結果として当たる場所・塗る場所は変わる。比較用の移動射撃では発射位置が0.408、対応する塗り位置が最大0.522 world単位移動した。威力、弾速の大きさ、発射数・間隔、消費、寿命、半径、ダメージ集約、通信形式は維持する。壁で砲口が遮られた場合の既存の発射位置補正も残す。[発射基準の監査](anchor-audit.md)に変更と維持する契約を分けて記録した。

## 検証と境界

実際のソース骨格・Actor・Physics・Projectiles・通信シリアライザーを使い、30/60/120Hz、照準の上下・旋回、移動・反動、初回姿勢前・解除後、壁際を検査する。形状は実メッシュへのレイ交差でも調べ、暗い砲口の奥行き、六角カラー、別々のグリップと指の向きを確認する。

新規の形状・持ち方2件と発射契約6件はソースおよび最終配信物で各8/8成功。既存の専用姿勢・厳密比較12件と、当たり判定・発射・泳ぎ・演出の回帰53件も成功。通常ビルド、入力互換性、起動サイズ予算を確認した。モデルは従来と同じ5メッシュ、10,588三角形で、ジオメトリは共有する。モデル生成時のゲーム用乱数の追加消費も検査した。最終識別子とログは [validation.json](validation.json) に記録する。

原典は発売前の公式画像を含み、正確な版・ギア・入力・寸法・関節曲線は不明。肩への厳密な接触、全状態での本家との一致は認定していない。カプセルが発射ごとに減る表示と、従来の小さい排莢モデルは今回未修正。ロゴ、質感、細部の形も引き続き近似である。
