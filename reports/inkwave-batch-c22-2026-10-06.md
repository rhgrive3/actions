Integration corrections preserve main's separate Bucket/Blaster guide. A missing
Shooter/Splatling guide clears the inline translate so existing `--gx/--gy` CSS
applies; a dirty presence bit handles a centre-aligned guide after a weapon switch.
Blaster's live 13F field remains owned by its installed per-family guide. The
unchanged main death-camera installer is housed in the existing rendering module,
with a compatibility export, keeping the existing core preload ceiling of 131.
Numeric status is generated by the canonical synchronizer, including inherited
main #819/#820 fields; no new tuning is introduced by that regeneration.

Overlap exclusions: #736 is already owned by #670; #654 is already implemented
by the actual #536 platform-input diff. Both were removed and their C claims
released. #305/#365/#369/#506/#798 remain outside this publication while source
acceptance or repair is pending. Ordinary builtin subagents were not used.

The final integration verifies the shared Slosher/Roller collision solver,
Storm/resource return paths, Splatling/Charger startups, remote life/credit,
touch/gyro ownership, guides, startup and Practice Range isolation. Broad source,
emitted/browser, network, Range and rendering checks run on the exact published
source and the native GitHub candidate through `validate-inkwave-update.yml`.
Queued or old-head runs are not passing evidence.

Limitations: source/VM and emitted/browser regressions establish INKWAVE behavior,
not Switch parity. No physical iOS/controller/gyro measurement or Nintendo pixel
comparison is claimed. Published/derived values retain their existing uncertainty
labels. The inherited main #795 pooled-projectile owner retainer is a separate
recorded finding, not represented as repaired by this batch.
