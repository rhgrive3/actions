## Classification of the previously reported 24 failures

These are pre-existing test-contract/fixture defects, not new damage or protocol regressions caused by enemy exclusion. Original logs stay in `reports/respawn-exclusion-20261023/` as lossless gzip; the new evidence branch also preserves fresh old-test reproductions on fixed 07a and 9cee emitted builds (both 31 pass / 24 fail).

* **23 Slam assertions:** the old universal claim that a pad-side defender must receive less than maximum damage is geometrically false. The 23 native layouts have radius 2.5. A real-Physics Slam probe at the old legal origin produces defender distance 2.3, inside the existing legacy near band 3.2; damage is 180. With exclusion, origin radius becomes 2.9 and distance 2.7, still legitimately 180. Tidewater radius 4.2 instead changes distance 4.0 to 4.4 and damage 77.5 to 70: the origin moves, the damage function does not change. These probes isolate pad geometry on a native floor slab; they are not actual native-map gameplay paths. The fully installed current gameplay profile has its own larger sourced near band and is tested separately; spawn collision is not an attack immunity rule.
* **One 23-vs-26 packet assertion:** adoption at column 23, Surge presentation at 24, and tagged hit authority at 25 already existed before this change. The original columns 0–22 remain fixed. A post-death life legitimately publishes an explicit Surge `end` watermark. The test now checks all of those meanings, the armor clock payload through launch/landing/expiry, and the existing invulnerability flags/proxy-only authority. Its manually constructed sample also used obsolete `lockT`; the real pose guard requires `lock`. This was hidden behind the first length failure and is repaired in the fixture, not by weakening runtime admission.

The raw source's constrained fixture passes the old 33 tests because it has only five enabled layouts and omits the complete networking adapters; the emitted registry adds 23 native layouts and the production row has 26 columns. Earlier mixed-root runs used emitted layouts with the source controls fixture. Updated tests use production composition, native capsule resolution and both emitted selectors (`INKWAVE_BUILT_SITE`, `INKWAVE_CONTROLS_SITE`) so source and emitted assertions actually exercise the intended code.
