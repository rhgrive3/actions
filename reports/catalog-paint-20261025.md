# 2026-10-25 ヒッセンの水平射程・塗り先端の追加確認

## 結論

不具合報告 #14 の「水平に撃ったときの飛距離」について、**弾の中心が床に触れる距離と、相手へダメージを与えられる距離を区別して再測定した**。

修正後の INKWAVE では、静止・同じ高さ・水平照準の条件で、立っている相手の中心が **12.0 world unit（以下 WU）** 離れていても **62 ダメージ**が入り、**12.1 WU** では当たらない。限界は約 **12.09452 WU = 2.41890 ライン**だった。公開検証 Wiki の Ver.11.3.0 の正面有効射程 **2.4 ライン**と、表示されている小数 1 桁の精度では整合する。[S1][S2]

中央先頭弾の床接触位置 **10.70240 WU = 2.14048 ライン**だけを公表有効射程から引いて、「約 0.26 ライン短い」と判断してはいけない。対人衝突には弾の半径と相手の当たり判定が含まれる。今回の修正で確認できるのは、低い描画リム位置に左右される物理発射高さを安定させたことと、上記条件で公表射程の目安に達することまでである。

**Switch 実機で照準角度・対象形状・原点を合わせた比較は未実施。** 公開表の精度より細かい完全一致や、あらゆる照準角度での一致を主張する結果ではない。

公開資料から、照準角度を厳密に 0 度と固定し、対象カプセルと原点まで再現できる実機トレースは得られていない。そのため、比較結果は「公表値の目安・丸め精度と整合」と表現する。

## INKWAVE 側の測定条件

- 対象 runtime: `a6eed592486cdbba099f611f046c578620271e7f`。その後の追加はテストと本報告のみで、速度や重力の追加調整はしていない。
- 武器: `s3-slosher-diffusion`、source actor `WeaponSlosherDiffusion`、通常ルール、地上発射、移動速度 0、水平照準 `aimDir = (0, 0, 1)`。
- 水平なのは照準方向。source の `AddSpawnSpeedYRateByXZ = 0.1` は維持するため、初速の Y 成分は 0 ではない。中央先頭弾は `(0, 7.3374, 73.374)` WU/秒。
- 発射側の足元を `(0, 0, 0)` とし、平面床上で測る。新しい身体基準の発射点は `(0, 1.05, 0.3)`。前方 0.3 は後述する距離に含まれており、再加算しない。
- 相手は同じ床の `(0, 0, distance)` に静止するヒト状態。現行 profile の対人カプセル半径 0.35、高さ 1.65 を使用。地形用の身体半径やイカ状態の判定を流用しない。
- `source-fixture.mjs` の `fullRuntime / productionComposition / realProjectiles` と、`paint-authority-fixture.mjs` の実地形衝突・CPU 塗りを使用。描画は無効にしても物理・塗りの実装は維持。
- ダメージ測定では実際の発射 runner、9 glob の時差出現、地形衝突、カプセル衝突、source ダメージ計算を通す。最後の `applyHit` 呼び出しだけを記録し、無敵時間や死亡・リスポーン状態を測定に混入させない。
- 限界値は距離 8～15 WU の区間を 24 回二分探索。数値の細かさは本シミュレーション内部の境界を表すもので、実機精度を意味しない。

## 中心の床接触と対人射程

| 指標 | 旧低リムの初弾条件 | 修正後の身体基準 | 意味 |
| --- | ---: | ---: | --- |
| 発射点 Y | 0.7438473827 | 1.05 | 足元からの高さ |
| 発射点 Z | 0.5274308613 | 0.3 | 足元から前方への位置 |
| 中央先頭弾の床接触 Z | 10.54894162 | 10.70239768 | 弾の**中心**が床接触で退場する位置 |
| 床接触までの固定ステップ | 13 F | 14 F | 境界はステップ内で連続判定 |
| 対人 62 ダメージ限界・相手中心 Z | 11.94106191 | 12.09451836 | 実衝突と source ダメージによる判定 |
| 同・ライン換算 | 2.38821238 | 2.41890367 | 距離 / 5 |
| 相手中心 Z = 12.0 | miss | 62 ダメージ | 境界近傍の具体的な改善 |
| 相手中心 Z = 12.1 | miss | miss | 無制限に射程を増やしていない |

旧条件は、修正前に実 Character で取得した中央初弾のリム位置を固定して再生したもの。旧コードのすべての姿勢・各時差弾の出現位置を再現した比較ではない。

公表 2.4 ラインは 12 WU に相当する。修正後の対人限界との差は **+0.09452 WU = +0.01890 ライン**で、小数 1 桁へ丸めると同じ 2.4 となる。これに対して中心の接地位置との差を計算すると、当たり判定の広がりを丸ごと取り落とす。[S1][S2]

### なぜ中心より遠い相手に届くか

中央先頭弾の source の対人半径は、5 F 後に **1.07** となる。最終的な接地直前の弾中心 Y は **0.07**。ヒトカプセルの下側球の中心 Y は **0.35**なので、接地直前に残る水平到達分は、同じ形状の幾何計算でも説明できる。[S5]

```text
水平到達分 = sqrt((弾半径 1.07 + 相手半径 0.35)^2 - (0.35 - 0.07)^2)
           ≒ 1.39212068 WU

相手中心までの到達距離 ≒ 中心接地 Z 10.70239768 + 1.39212068
                     ≒ 12.09451836 WU
```

これは実 collision の二分探索結果と一致する。仮に「相手の手前側表面」までの距離を用いるなら、相手中心からさらに半径 0.35 を引く必要がある。発射点基準・足元基準・的の中心基準・表面基準を混ぜると、比較に数十分の 1 ラインの差が生じる。

同じ高さ・水平条件では、source のダメージ低下開始落差 1.5 に達しないため、限界付近でも 62 ダメージであり、微小ダメージだけのカス当たりではない。レティクルの反応距離 2.3 ラインも、この対人限界とは別に比較する必要がある。[S1][S5]

### 上向き照準は別に扱う

追加の角度確認では、同じ身体基準・相手・地形で、照準を上へ 5 度向けると約 **2.57434 ライン**、10 度で約 **2.65239 ライン**まで 62 ダメージが届いた。公開 Wiki は有効射程に多少の上向き射撃を含み得る定義なので、**水平条件が 2.4 に丸まることだけで角度を含む本家の全挙動が一致したとは判断しない**。[S2]

この角度別結果に対応する条件付き実機トレースは得られていない。今回、これを埋めるための任意の弾速・重力調整はしていない。

## 塗りの最前端

同じ水平照準・静止・平面床で全 9 glob と落下滴を 2 秒進め、実 CPU 所有格子を読み戻した。格子は 0.25 WU 四方。固定乱数値を 0.1 / 0.3 / 0.5 / 0.7 / 0.9 とした 5 条件を個別に測定した。

| 指標 | 旧低リム条件 | 身体基準へ修正後 |
| --- | ---: | ---: |
| 所有セルの最前端中心 Z、5 条件すべて | 14.125 WU | 14.125 WU |
| ライン換算 | 2.825 | 2.825 |
| 中央線近傍 `abs(X) <= 0.25` でも同じ最前端か | 同じ | 同じ |

最前端セルの幅が 0.25 WU あるため、これは格子中心の値であって、滑らかな塗り境界を 0.001 単位で確定したものではない。ここでの「5 条件の平均」は乱数分布を独立に多数試行した統計平均でもない。

Wiki の塗り射程 2.6 ラインは 13 WU。単発の最前セルをそのまま比較した差は **+1.125 WU = +0.225 ライン**で、今回の測定は不足側ではない。ただし Wiki は横に歩きながら撃った際の平均的な距離を採用するため、単発最前端とは測定方法が違う。[S1][S2]

よって、残る確認対象は**塗り形状・格子化・測定条件の差**であり、「中心の弾が 2.14 ラインで床に触れるから、塗りも有効射程も短すぎる」という判断にはならない。この数値差を打ち消すための塗り半径倍率は追加していない。

## 回帰確認

`patches/splatoon3/tests/catalog-20261025-paint-regressions.test.mjs` に、実際の対人衝突を使う回帰を追加した。

- 同じ高さで水平発射し、相手中心 12.0 WU に 62 ダメージ、12.1 WU にはダメージなし。
- Projectile 更新の 30 / 60 / 120 Hz すべてで同じ結果。
- 既存テストで、実 Character による初弾・遅延弾の 9 glob すべてが、同じ 3 つのフレーム間隔で高さ 1.05 から発射されることも確認。

実行:

```sh
node --experimental-vm-modules --experimental-global-webcrypto --test patches/splatoon3/tests/catalog-20261025-paint-regressions.test.mjs
```
