# Roller repeated-contact cadence (#839)

This is a separate delta after the PR790 #558 admission port and its WeakSet retirement correction. It does not reimplement that owner or include the independent Super Jump HP change. Start comment: https://github.com/rhgrive3/actions/issues/839#issuecomment-6023855750.

The actual composed native Roller path on c1b9cf4e recorded hits at fixed ticks1/32/62/93, yielding31/30/31-frame intervals from its strict greater-than0.5s test. The explicit S3 Roller profile interval is now0.4s. Both the Actor and native Boss-contact branches consume that same interval with a tiny floating-point boundary allowance. A stored timestamp of zero is retained instead of being replaced by the old truthy fallback. The first eligible contact remains immediate; successful repeated contacts occur24 fixed ticks apart. Damage125, body/contact geometry, cover selection, movement and knockback are untouched.

A search-indexed excerpt of the [published parameter table](https://splatoonwiki.org/wiki/User%3AXarrotD/paramtable) also gives BodyParam DamageSpanSecond default0.4; direct retrieval of that page returned403, so no fresh full-page inspection is claimed. The pinned11.3 normal Roller BodyParam omits an override. Continued11.3 applicability is therefore an inference from the available default/table evidence, not direct11.3 footage or a newly extracted scalar. The field is recorded as unbound calibration/derived in numeric-status and the limitation is explicit in profile.calibration.unverified. No false pinned raw binding is added.

Validation: seven new source tests measure Actor and Boss contact branches at30/60/120Hz presentation schedules over fixed60Hz simulation, starting at timestamp0. All produce ticks0/24/48/72/96. The Actor path uses real Projectiles/applyHit with a high-HP target; the Boss test uses a controlled collision result and counts calls to the native Boss-contact branch, not an actual rendered Boss encounter.
