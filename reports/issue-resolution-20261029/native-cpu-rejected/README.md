# Rejected native simulation CPU candidates

These are CPU-only component experiments against source `2b01cd7efbca260a611165b1e3887ff48062ccd5`. Neither candidate was retained. The [receipts](receipts.json) bind the source and frozen oracle Git blobs and every archived file's SHA-256. The older whole-roster profiling identified bomb paint ownership and native footprint queries as costs, but its inputs and results predate this source. These experiments do not establish current whole-match performance, FPS, or completion of #1671 or #1757.

## Settled paint visibility

A tentative per-cell flag attempted to reuse proven visibility during settled native wall-paint replay while retaining ownership, order and grid checks. On the existing unchanged 800-tick replay fixture, both the candidate and its counterfactual matched the frozen `b77b51d` ownership oracle's output and state. The candidate ran **3,314,762** geometry visibility tests versus **3,314,794** without the shortcut: 32 fewer, approximately 0.001%. The [raw workload log](paint-cache-workload.tap.gz) records this result. A more artificial repeatedly repainted scene saved 6,520 of 200,662 checks; its [log](paint-cache-focused.tap.gz) is retained, but does not override the weaker existing-workload result. [Initial regression log](paint-cache-first.tap.gz) records 7/7 tests passing.

The saved logs capture those observations. The transient paint candidate and its modified harness were discarded and are not archived, so those experiment-specific counts cannot be reproduced from this record alone. No runtime change was kept on the basis of them.

## Native footprint source-face UV

A separate candidate deferred source-face UV projection until the native nine-ray footprint selected a support hit, with eager fallback for custom owners and malformed metadata. Its controlled source fixture compared 2,500 varied footprints with the unchanged native implementation, including every returned GroundHit field; all matched. A separate mutation that suppressed the selected UV was detected. The source tests also exercised a dynamic winner, custom callbacks and malformed metadata. The [source test log](native-foot-lazy-negative.tap.gz), [source-scoped test and negative control](native-ground-selected-uv-source.test.mjs.gz), and [candidate diff](native-foot-uv-candidate.diff.gz) are retained as diagnostic material only. No product file contains the candidate. The 9→1 and dynamic-winner 9→0 figures count UV projections, not overall CPU or frame time.

A warm, 12-block interleaved A/B/A comparison then ran the actual source-composed NativePhysics and NativeLevel over the same 2,500 two-triangle floor footprints per block. Per-block digests matched; the full 2,500 GroundHit records were compared before timing. Process CPU means were **14.183 ms / 14.325 ms / 14.476 ms** for baseline A / candidate / baseline B; medians were **13.979 / 14.190 / 14.111 ms**. Mean wall times were **14.179 / 14.311 / 14.206 ms**. All samples, including outliers, are in [timing JSON](native-foot-uv-timing.json.gz). The difference does not demonstrate a net gain and the candidate median was slower than both controls; it was discarded. The [executed harness](compare.mjs.gz), [baseline source](native-physics-before-uv.mjs.gz), and [stderr](native-foot-uv-timing.stderr.gz) are retained. The archived harness uses its original `.ci-scratch/native-uv/` location and reads the baseline at `/workspace/scratch/native-physics-before-uv.mjs`; reproduction requires applying the diagnostic diff only in an isolated source checkout and restoring those paths. The compressed test file was untracked during the experiment and is separate from the diff.

The earlier paint and UV attempts were never published as gameplay fixes. A better-supported next step requires a controlled current native whole-roster workload, rather than extrapolating from these component counts or repeating a long simulation without a hypothesis.
