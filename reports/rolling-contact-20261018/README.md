# ローラー／筆：斜め移動と接地塗り

対象は公開版 INKWAVE。開始点 `e52f1150b`。ゲーム値の参照は既存の Splatoon 3 **11.3.0** 固定データ。今回の校正値は実機パラメータの復元ではない。

## 本家の確認と限界

[任天堂のブキ紹介](https://www.nintendo.com/jp/switch/av5ja/customize/index.html) のローラーの接地画像と、[筆のロビー試し撃ち画像](https://note.com/rbaconv/n/n5f6f4bfb753b) を実際にダウンロードして表示した。画像URLとSHA-256は [参照台帳](references.json)。ローラーは充填された帯の側面に不規則な欠け／突起、筆は細い連続する曲線と細かな縁の凹凸が見える。アルテマの筆GIFも8フレームずつ表示したが、実戦の重なった振り塗りなので孤立した転がし塗りの寸法根拠から除外した。ダイナモの縦振り画像も接地幅の根拠にはしていない。

撮影版、ギア、入力、カメラ投影は未確定。斜め入力とカメラを独立に記録した本家の映像・実機入力計測は未取得。今回の「保持中は照準方向を向く」はユーザーが指摘した意図しない向き変更の修正であり、本家の旋回補間を計測して復元したという意味ではない。画像のピクセル幅からメートル値を逆算せず、接地塗りと既存のドラム／毛先モデルの大きさを校正した。完全一致、Switch/iPadの性能、全ギア・全地形の一致は認定しない。

## 原因と修正

- `movement-physics-adapter.mjs` が基本ローラーの向きを速度方向へ回していた。基本・追加ローラーと筆の転がし中、および追加ブキの保持中の開始遷移は照準yawへ向ける。移動速度／進行方向はスティックで独立に操作できる。塗りの方向とリモートの表示は従来どおりbody yawを使用する。
- 基本ローラーの3本の中心帯＋2本の床専用帯は、最大5.6 WUまで広がり、1.5 WUのドラムと釣り合っていなかった。接地塗りだけ0.3倍で校正。球の中心高0.35を保ったまま、床上の半径を縮小する。球半径そのものに0.3を掛けて床に届かなくする処理ではない。低速から最大速度への幅補間は維持。
- 追加ローラーは接地幅0.3倍、筆は0.25倍。源データとダメージに用いる半径は保持し、飛沫の塗り幅には転用しない。細い筆に合わせて補間間隔を縮め、分割した際に全フレーム分の縦伸びを各スタンプへ重複させない。
- 基本ローラーの滑らかな正弦波の側面を角のある2段の歯形へ変更。CPUとGPUで同じ式を使用。側帯の重なりを増やし、凹凸が内部の塗り抜けを作らないようにした。
- 追加ローラー／筆の `ink-contact` の完全な平行辺を、短い丸端と非対称の小さな欠けを持つ帯へ変更。他の射撃輪郭と通信の形式は維持。基本ローラーの5スタンプは維持し、筆の接地サンプル間隔は狭くした（上限6）。共有帯を使うマニューバーのスライドも、歯形の最大外周に球半径を合わせて従来の塗り幅上限を維持する。

| ブキ | 旧最大幅 WU | 校正後の最大幅 WU |
| --- | ---: | ---: |
| スプラローラー | 5.6 | 1.68 |
| カーボン | 4.4 | 1.32 |
| ダイナモ | 6.8 | 2.04 |
| ヴァリアブル | 5.2 | 1.56 |

これは公表された本家の塗り幅表ではなく、INKWAVEの描画用上限。実際の輪郭は歯形と速度により上限の内側にある。ローラーと筆ではモデルに合わせた校正率を分けた。

## 再現

水平な塗れる床でZR保持後、カメラを動かさず正面→右斜め→横→逆方向へ移動する。ドラムと塗りの横軸が照準方向を保つこと、カメラを90度動かすとドラムも追従することを確認する。追加ブキは最初の振りから保持へ移行する区間も確認する。筆の連続した細い帯、ローラーの中心帯と両側帯の継ぎ目、インク切れ、壁際・段差・非接地も回帰対象。

```sh
node scripts/check-inkwave-patches.mjs --quick
node --experimental-vm-modules --test --test-concurrency=2 patches/splatoon3/tests/roller*.test.mjs patches/splatoon3/tests/issue-*roller*.test.mjs patches/splatoon3/tests/main-ink-footprints.test.mjs patches/splatoon3/tests/issue-batch-1171.test.mjs
node scripts/build-inkwave.mjs inkwave-public _site
node scripts/check-inkwave-rolling-paint-browser.mjs _site reports/rolling-contact-20261018/browser.json
node scripts/check-inkwave-paint-mask.mjs --site _site --executable /usr/bin/chromium --evidence-dir work/roller-gpu --profile-dir work/roller-gpu-profile
```

検証結果は完了後に追記する。ロジック／ブラウザ確認を本家実機の検証に読み替えない。
