# 新世代16メイン / Splatoon 3 Ver.11.3.0

作業開始時に再取得したmainは `9ef63350385bffee71b3afa0a09290a92e9c862b`。対象は公開版 `inkwave-public/` とproductionアダプターの合成出力。通常対戦、ギアなし、固定60Hzを基本条件とする。PR: [#1577](https://github.com/rhgrive3/actions/pull/1577)。最終のテスト・ビルド・統合結果は本書末尾と `verification.json` に記録する。

**完全再現の認定ではない。** 明示原典を実行経路へ接続した箇所、既存実装との整合性修正、原コード未取得の再構築を区別する。Switch実機の同期測定、Nintendoの専用アニメーション・音源・塗りマスク・遅延補償との一致は未立証。

## 原典と対象範囲

[原典監査](source-audit.md) / [機械照合](source-audit-checks.json)。固定Leannyコミットの通常対戦用16ファイルは全件で保持SHA・保持数値群と一致。16ベース＋25別キット＝41プレイ可能IDのサブ・スペシャル・必要SPを照合した。既存Orderレプリカ4種は未登録で、今回も新しいプレイ可能モデルとして追加していない。全派生の完全な外観一致を主張しない。

Nintendo公式11.3.0変更: ケルビンのスライド後ブレ約10%軽減、トライの落下飛沫縮小、トライコラボSP190→200。保持値2.7°・1.39・200は既に最新版であり、今回の修正成果に数え直さない。

## 追加発見した不一致

1. LACTのフルチャージが共通DetonationParamを見て誤爆発 → 全段階非爆発へ修正。
2. Stringer中間段階のFreezeFrameMidCharge未使用 → 明示15Fと次の実射撃受付を検査。段階間の線形補間は再構築。
3. Stringerのkind=catalogが全チャージJumpHeightFullChargeを通らない → 8.4から4.2へ接続。空中240F境界の丸めも修正。
4. ghostのチャージ矢が即退場し、停留・起爆表示なし → 元の45F fuseと一度のcosmetic event、塗り/ダメージ権限ゼロを維持。
5. ローカル弓の独立dampと相手の傾斜情報不足 → 発射tiltと表示を同期。
6. 追加5マニューバーが通信のkindチェックから除外 → 実roll epoch/方向/時間、turretを既存life/順序guardで再現。
7. 移動後の速度が通常減速へ残る → 96F平地比較でDapple9.845→3.6、Douser11.2375→6.7。core+明示slipの距離に限定。
8. 追加スライドがnativeの衝突細分化を通らず薄壁を抜け得る → body半径に応じた有界slice、衝突距離の借越しなし。
9. NoSquid硬直をbusyの早期returnで回避 → 対象系統の明示硬直を保持。他系統の既存キャンセルを維持。
10. SideStepのInkRecoverStop50/60Fを通常射撃20Fに縮退 → 明示値を接続。
11. 立ち止まって射撃を継続してもturretが時計満了で消える → 保持状態と移動/潜伏/弾切れによる解除を分離。
12. ワイパーの左右交互をモデルが使わず、デンタル溜めを縦振り表示 → 実射撃serial/ordinalとブキ固有の横振りへ接続。
13. 相手のワイパーに斬撃poseが伝わらず、弾生成までの待機分も遅れる → 検証済みshot metadataから表示時計へ接続。踏み込み有無/全遅延の復元は未確定。
14. ドライブが3%で弱振り可能なのに3.5%チャージ下限で拒否 → 3%の実支払で1wave、派生にも継承。
15. イカ中に前入力履歴が無期限保持される → 入力ringをクリア。
16. イカ化後も傘が開き、再生・修復時計がkid分岐の外で止まる → 閉傘とelapsed repairを接続。
17. 持ち主が死亡すると放出済み傘も防御候補から除外 → 放出物の寿命/HPを所有者の現在の生死と分離。
18. 盾の判定中心が実表示原点より1radius上、Charger半径が直接/受信で異なる、接触時計がG.time依存 → 共通姿勢・直接/受信半径・固定clockで整合。

19. 統合レビューでスペシャル/ジャンプによる中断後も古いstop硬直が残留 → hard cancelで破棄し、5ブキ×4中断理由を実行経路で検査。資源側のインク回復停止は維持。

## 検証の読み方と残る限界

ロジック試験、productionモジュールの実行、Chromium/WebGL表示、原典数値の照合を別の証拠として扱う。`check-inkwave-new-families-browser.mjs` は実Actor/Character/Physics/CPU Paintを使い、固定60Hzを30/60/120Hzの表示更新へグループ化する。全16ベース＋25キット、通常・保持・空中・潜伏キャンセル・段階charge・jump・slideを対象とし、固定時点の発射/座標/速度/インク/塗りhashを比較する。最初の0.25秒のbase保持射撃では各表示frameをWebGL描画し、他は3時点を描画する。全3秒を全ケースで実表示した検査ではない。乱数は.37固定で、分布の証拠には使用しない。

0.1境界の幾何oracle、散弾分布と距離別hit率、wireの重複/逆順/旧life、不正値、sourceとminified出力は系統別試験を併用する。CPU/GPU共通塗りmaskは既存の専用検査で確認し、本家のmask一致とは区別する。two-browserリレー検査は実WebSocket/production RoomDurableObjectを使用するが、そのfixtureではUI・Character mesh・音を省略する。

省略既定値の復元、弓45F/2の適用規則、傘の布全輪郭と深度、対傘の完全な相互作用、Nintendoのrollback/rewind、Switch実機操作感、専用SE波形とアニメーションは残る。Google Driveで参照資料フォルダを確認したが、未取得の原コードや既定値が入手できたとは主張しない。

Issue #532は現在4+1=5の専用経路を既に持ち、旧2.8継承という記述は現mainに該当しない。#992もnative InkFlight所有であり、generic random blobという旧記述は該当しない。原典不足の塗り位相・高さ合成、世界スケール/曲線の残項目があるため、両Issueを完了closeしていない。
