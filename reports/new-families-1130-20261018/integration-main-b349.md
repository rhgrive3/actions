# 床投影補正と入射方向保持の最新main統合

main `b349a6c3e34e3f4eb8172795b1b9d86188fdea58`（#1585）を統合。床爆発の`ink-blast-rectified`選択と、壁/旧イベントの既存輪郭への写像を保持する。旧9輪郭4608bytes・texture8192bytesは独立に不変を確認。F04のDamageOffsetY中心・LOS・対物、LACT非爆発、ghostの塗り/ダメージ無権限・45F停留表示を保ったまま、矢の入射方向を速度ゼロ前に保存し、塗りへ渡す。

レビューで、incoming変更のnative Blaster壁衝突経路に方向の取り落としを発見した。`beginFidelityWallDrop`が速度を`[0,-4.2,0]`へ変えてから爆発を予約し、新しいqueueは既に失われたXZ方向を保存していた。従来のテストは`_blastBurst`直呼びなので、この前段を通らなかった。

実fire→Physics壁衝突→wall-drop→次tick爆発→実落下を通す失敗テストを追加し、queueのsnapshot後に鉛直速度へ切り替えるよう順序を修正。新field/object/PRNG drawを追加しない。真正面と斜め±.2の3方向で、爆発球と落下塗りが実際の入射水平軸を保持すること、owner、接触直後の鉛直速度、一度だけの各塗りを検査する。

独立実地形probeの真正面条件では、接触frame7、戻り速度`[0,-4.2,0]`、爆発球0.15秒/R1.4、落下0.533333秒/R2.5/着地点`[0,.1,7.6]`は不変。球の方向`[0,0,0]`・落下の方向なしから、双方`[0,0,1]`へ復元した。別責務の壁shock R1.2までを入射軸一致と認定するものではない。

sourceの方向＋Stringer重点13/13、独立Stringer/codec/contour/canonical96/96、独立方向5/5成功。最終production・全キット状態・CPU/GPU・遅延通信・CIとマージ後mainの新しいhash/受領はPR #1577本文に記録する。旧2b360生成物の782/986条件や塗り面積を新生成物の結果へ流用しない。
