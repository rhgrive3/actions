# Native Turf opening: source and emitted evidence

This is a CPU/Node component experiment, not production authority admission, browser/device testing, or retail parity. Two separately loaded production-composed or emitted native realms run real Match, Actor, SquidSpawn, Physics, Character, WeaponRunner and Projectiles. Both use the flat test floor and a simulated WebSocket/relay. The experimental `nc` sibling is constructed by the fixture from locally observed owner input and appended to real owner packets; the current public NetMatch does not emit or consume it. A trusted test scheduler supplies enrollment, epoch and receiver time. No packet witness assigns actor pose, life, clock, ink or projectile state. The fixture's source order is Match.update followed by Projectiles.update, matching the 60 Hz main loop.

The historical negative uses SHA-256-pinned 9d8efc charger input/replay sources and the current native initial-spawn first frame. It fails on the old replay with `Native input requires another action owner`; the new private replay accepts the whole 398-frame trace. The tested source run passed 3/3, including that negative; the emitted run passed 2/2. The historical test is now a separate source-only file and explicitly fails if selected with `INKWAVE_BUILT_SITE`; the two current tests are defined unconditionally in both modes. Missing, stale-epoch, wrong-principal, duplicate and repeated-commit controls remain active. Rematch and socket retirement use real session/transport lifecycle with a simulated relay.

The paired raw traces include all 398 input frames, actual owner packets, fixture-created sibling envelopes, resource/pose fields, and selected real Character bones. Across source and emitted trace, all 398 entries match in tick, dt, source time, spawn phases, Match state, input bits, effective input, resources, position, velocity, grounded, form, aim, aim point, movement, life, ink, charge, selected bone pose and resource body (clock stamps and match epochs are independently generated). The historical private actor uses a different Character name and a private camera; its first native muzzle is 0.0005323015604325976 world units from the source muzzle. The recorded control changes only the trusted constructor name and scoped camera condition: with both equal to the source fixture, every tick's pose array is within 1e-7 and the first muzzle and 14 socket ancestry world matrices are exactly equal. The no-renderer `camera=null` control is not a proof that arbitrary production camera, viewport, LOD, quality, or renderer history yields identical gameplay muzzle positions. Authority must not treat owner-provided pose or camera assertions as trusted state; a camera-independent canonical gameplay pose or a separately justified trusted initialization is still required.

The measurements and raw gzip artifacts below were captured at fixture commit `1bea772e067a9d62ac92e1a2b73d6aa67ade9faf` with the prototype leaf equivalent to `310eb4b1` plus canonical weapon gate. The built site was checked by `verifyRuntimeBuild` against that full commit: input hash `6e370e6ee1c701df3faf306eb31a681510858e41a20847857a6d73364f3f9d2e`, content hash `afe67f0f3d32489bb3f4bcba0202f0ae19692ef2ced7efb8e9132be008886d55`. Gzip files use a zero timestamp (`gzip -n`). These artifacts record that tested revision; they do not attest later commits or connected runtime deployment.

## Trusted initialization follow-up

The stable authority leaf `d81aeaf3b6b8c9bac49093f75ecdf8580c90380a` accepts trusted roster name and controller identity plus an explicit trusted world camera. At test commit `644a576874d6bd9bf3321b2fe1d17a370691eabc`, the current opening test supplies the original Match roster's native name and identity and `camera:null`; it does not consume these fields from an owner command or snapshot. Source passed 3/3 including the separated historical control; generated modules passed 2/2, both with zero skips. Each of 398 frames compares position, velocity, form, life, ink, charge and the position/quaternion of six real native Character bones at 1e-7; observed maximum bone gap was 0 in both runs. The first actual source and private Charger event muzzles also match exactly (gap 0), with the same 1e-7 assertion. This remains a no-renderer camera-null component test and does not establish arbitrary camera/LOD or production networking equivalence.

`d81-source-trace.json.gz`, `d81-emitted-trace.json.gz`, and corresponding test logs are the full new observations. `comparison.json` lists the 22 compared frame fields, verifies every encoded frame and sequence, and records SHA-256 digests for all compressed evidence.
