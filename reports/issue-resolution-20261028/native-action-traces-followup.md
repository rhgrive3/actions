# Native action trace follow-up

The 65 ordinary main-weapon traces run 165 fixed 60 Hz ticks each with a fixed seed. They contain each full input, actor and weapon resources before and after the tick, native `weapon:fire`, projectile allocation and publication, legacy Charger flight jobs, native contact and damage, and actual 20 Hz sender packets admitted by a receiver after the real owner-clock challenge. All 65 produce their native birth path; legacy Charger uses a finite flight queue instead of a projectile-list birth. The traces contain 10,725 input commands, 3,575 accepted snapshots, 847 projectile allocations and publications, one Charger flight job, 538 fire events and 177 native contacts. The immutable compressed trace is `patches/splatoon3/tests/fixtures/native-action-trace-035.json.gz` (SHA-256 `941c7c20adc49911e2a50a9bd9ed89734ede67762536174585911f725239b976`).

The composed source Actor, shooter Character/socket, level, physics, WeaponRunner, Projectiles and NetMatch are real. The receiver's display proxy, paint storage/raster and audio are fixtures; there is no renderer or physical device. The ready actor is explicitly positioned and made grounded after `spawnAt`, rather than recording the entire admission sequence. Its trusted `owner` and `netLife` are assigned before canonical registration. This is a native action regression, not production integration of the new command protocol or proof of exact game balance.

On Node 22 with `--experimental-vm-modules`, source canonical `c53eada7` and the sealed minified `/workspace/scratch/canonical-weapon-actions-final-site` both passed the 65-weapon and Charger-prefix tests (2/2 each). Both produced the exact immutable corpus hash above. The final site's content hash is `abc48a42e77cc42c7594bb798492ffade9a0079c666e4b74ddf69015e328dfdf`, its manifest SHA-256 is `67fb920499292d417d614c1a6d70538af0276848a58f0abbbe65b8310feee968`, and the emitted canonical leaf is `897b424e88685d2b0b073eba23ad4d23ec5491fe7cb478577ab101b6e7b3a0e7`. The manifest includes canonical source; all emitted artifacts were verified by the build owner.

The source representative suite passed 5/5 for L-3 burst, Brella and Slosher units, Splatling burst, Charger squid charge retention and low-ink Roller. A further source and emitted test passed for each of legacy Charger and Splatling: holding 159 ticks then deliberately releasing produces a native fire event, while cancelling at the same release tick produces no fire or birth. It exercises the native cancel hook, not a fabricated projectile. The Charger prefix pair has the same received first packet but distinct subsequent native births; that is prefix ambiguity alone, not a proof that complete packet histories or all possible commit protocols are indistinguishable.

The trace gate now selects the canonical module from `INKWAVE_BUILT_SITE` automatically whenever a site is supplied, verifies that exact artifact against its manifest, and rejects an override from another location. It never silently substitutes the source canonical module for an emitted site. Each all-65 run requires exact equality with the frozen corpus; `INKWAVE_NATIVE_TRACE_OUTPUT` writes a separate receipt only after the comparison succeeds. Dedicated negative controls cover missing and tampered modules, a mismatched override, a missing corpus and changed corpus data. The emitted Charger/Splatling cancel representative also passed with only the built-site environment set, exercising automatic selection.
