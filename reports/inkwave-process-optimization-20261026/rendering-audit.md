## Applied changes

| Path | Process / redundant work | Action and bound |
| --- | --- | --- |
| `src/world/wave-data.js` | Wave texture generation repeats amplitude×kx/ky for every pixel and row division for every x. | Compute both original left-associated amplitude products once per private 44-wave record; hoist y/size per row. Removes 5,767,080 repeated multiplications and 65,280 row divisions for the normal 256² texture. Adds 88 Number values only during the single generation call. All output RGBA bytes match the original oracle at 5 sizes/seeds. |
| `src/world/props-core.js` | `Builder._m` and `push` allocate a temporary local Matrix4 consumed immediately by multiply; final matrices must remain independent. | One private scratch Matrix4 per Builder replaces only temporary composition. Final part/stack/animation matrices stay independent, with identical compose/multiply order. Halyard has over 12,000 retained part records, so a rebuild removes over 12,000 temporary Matrix4 allocations. Geometry/index/collider/live-instance oracle matches. |
| `src/game/lobbySet-geo.js` | `SetBuilder.add` creates color/default arrays per vertex; `boxUV` creates a 2-element array per vertex. | Scalar writes preserve Float32 conversion and signed zero; resolve lit/neon defaults once per geometry. Surface/decal/normal/UV ownership and callback order remain unchanged. Frozen original writers compare every bucket and box/keep/swap/default/custom combination. |
| `patches/local-quality/locker-stage.mjs` | Visible locker frames allocate Vector2 and Color to snapshot renderer state. | Reuse one stage-owned frame scratch; nested invocations use independent, unretained scratch; finally releases the busy marker for all failures. Renderer target/cube-face/mip/clear-color/primary-error transactions stay intact. |
| `patches/native-stages/runtime/native-render.mjs` | Balanced→High PNG loads infer roughness='r' after initial material closures snapshot 'g'. | Material cache entry owns committed channel state. Texture commit refreshes both channels before needsUpdate, preserving existing material and texture ownership. Initial failing test showed `native-channels-r-g` vs direct-high `native-channels-r-r`; upgraded shader and cache key now match direct-high. |
| `patches/native-stages/runtime/native-load.mjs` | Aborting a KTX2 caller decremented the loader's pending count before real worker callbacks completed; renderer replacement could dispose their worker pool. | Count actual parse completion via existing idempotent finished callback; import/setup failures also release. Combined regression failed before fix (old loader disposed with 2 callbacks live), then passes through abort, renderer replacement, late success/disposal, one outstanding callback, late failure and independent replacement completion. |
