## 検証

- 証跡パッケージの20テストと、CI runner契約の122テストが成功。
- bot探索の新規4テストが成功。基準版との境界値、順序、cache、scratch状態の比較を含む。
- 統合先 `fd6435a4` 上でも証跡20件とbot探索4件を同時実行し、24件すべて成功。
- 関連ゲーム回帰の7失敗は基準版でも同じ条件で再現し、6件はnative資産不足でskip。
  完全成功として扱わない。詳細は [gameplay-tests.json](gameplay-tests.json)。
- 別担当の独立レビューでも指摘なし。追加比較では証跡500 inventory/32 package、
  bot探索500有向グラフ/100万件の円境界判定が基準版と一致した。
- 調査基準の通常ビルド・起動予算・Chromium検証が成功。Chromiumは799応答を検証し、
  page errorは0。最終変更の統合ビルド・生成物・ブラウザ検証はPRの検証欄に記録する。

## 採用しなかったもの

描画のpool・dirty upload・非表示時の処理抑制は合成後ソースに既にある。
水面高さの矩形距離除外は6ステージ各1万座標で結果一致したが、速度が不安定で
Tidewaterでは遅くなったため不採用。Beacon選択キーの再利用は古い選択ticketの
検証を損なう可能性があり変更しなかった。native接触と8近傍距離の候補も、
効果が安定しないか遅くなったため不採用（詳細はbot探索の記録）。

移動・射撃・塗りの仕様、品質設定、simulation頻度、botの判断を変更していない。
スプラトゥーン3実機との新たな一致判定は行っておらず、既存の未確認事項は残る。
