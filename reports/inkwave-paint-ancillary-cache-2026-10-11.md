# Ownership-preserving ancillary shape basis cache

Base: adopted main 31703a906b4f19fd5f46dea08d06615113008492. This candidate does not include PR1235 or the unpublished powered-special integration.

The wall-paint A/B workload showed a material CPU/bandwidth increase from adding 23 wall-drop producers. An independent Node CPU profile located repeated ancillary wobble, seed-hash and trigonometry among the growth-evaluation hotspots. VM profile durations identify functions only; they are not game frame-time measurements.

This change caches only time-independent shape coefficients in a WeakMap keyed by the pooled growth record and face. Radius, normalized seed, kind, shape counts/identity, wall flag and stretch direction/amount invalidate it. Pixel density and face-intersection radius remain dynamically computed. New ownership, delayed growth, HLC comparisons, score credit, rendering, stamps and network events are unchanged. No same-team or already-painted event is suppressed.

Validation:
- Frozen main mathematical oracle versus cached implementation: every generated mask field bit-exact across 4,608 native combinations, pooled-record/face mutation and alternate satellite/spatter shape contracts; three tests pass.
- Existing source temporal, score-boundary, hash, hidden 30/60/120 Hz, pooled-reuse and canonical network-order regressions: 37/37.
- Production-built versions of the same regressions: 37/37.
- A pure shape-preparation kernel AB/BA/AB test of 24,000 calls gave baseline 74.6–90.9 ms versus cached 22.8–39.6 ms with equal checksum. This is a local math-kernel benchmark, not a whole-game performance claim.

Next gate: actual software-WebGL masks and paired immutable built workload, including unchanged grid/row/quad/draw counts. GPU throughput and bandwidth are not expected to improve from this CPU-only change. The 23-wall-drop feature remains unadopted pending its combined cost/behavior review.
