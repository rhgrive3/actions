# Splatoon 3 interaction audit — 11 October 2026

This audit checks the installed cross-path behavior for custom subs, native bombs, Point Sensor, specials, deployed devices, attacker gear, and network ownership. The runtime install order in `patches/splatoon3/runtime/install.mjs` is significant: it installs support gameplay, all subs, all specials, then the object-cause network wrapper before catalogue networking. The Storm adapter adds its cloud tick to the same object APIs. Source and runtime references are pinned to Splatoon 3 11.3.0 / Leanny `7280ff9cde8bb1c5dcef46c700c326471584d2e6`.

Detailed per-family numeric behavior and calibration notes remain in [sub parity](subs-parity-20261011.md), [special parity](specials-parity-20261011.md), and [native parity](native-parity-20261011.md). This report focuses on whether those values reach real actor, device, and network paths.

## Object damage rows reach the installed hit paths

The pinned `misc/spl__DamageRateInfoConfig.pp__CombinationDataTableData.json` has 115 attack rows and nine deployed-device target columns: Splash Wall, Sprinkler, Beakon, Torpedo, Wave Breaker, Super Chump, Booyah armor, Crab Tank, and Splashdown fist. Its vendored fixture matches all 1,035 cells. Big Bubbler uses a second source table with 115 rows and two targets (`GreatBarrier_Barrier`, `GreatBarrier_WeakPoint`); that fixture matches all 230 cells. They are separate source tables, rather than one eleven-column table.

`ObjectEffect_Up` is applied once after the attack-row multiplier. Its nine rates are 1.5×, 10×, 10×, 1.3×, 1.25×, 2×, 1.1×, 1.3×, and 1.1× in the target order above. Its two Bubbler rates are each 1.1×. Representative source rates that are now consumed include `Bomb→Splash Wall` 2×, `Bomb_Fizzy→Splash Wall` 3.6×, `Bomb_TorpedoBullet→Splash Wall` 4×, `UltraShot→Splash Wall` 6×, `MicroLaser→Wave Breaker` 2.4×, `Jetpack_Jet→Splash Wall` 2.8×, and `Chariot_Cannon→Splash Wall` 3×. The all-row tests apply the gear factor once.

`sub-resistance.mjs` selects exact authored main-weapon attack rows through the 65 `WeaponInfoMain` selectors. The selector distinguishes phases such as ordinary versus full-charge Charger, blaster direct versus burst, Roller/Brush body contact, Brella shot versus canopy, and Splatana slash versus charge slash. Known variant IDs use their actual source names (for example `Roller_Heavy` splash and `Blaster_Short` shot), and the fallback source family is used only when there is no authored catalogue selector. Tests cover all 65 weapon records and their phase selectors. `kit-big-bubbler.mjs` applies the same phase mapping to both Bubbler target types; its test covers the complete 115×2 source table.

## Sub Resistance, paint, and numeric use

The separate `misc/params.json` Sub Resistance curves are consumed at victim actor paths. The source high/mid/low arrays include `DamageRt_BombH=[0.5,0.75,1]`, `DamageRt_BombL=[0.6,0.75,1]`, `DamageRt_LineMarker=[0.5,0.75,1]`, `DamageRt_Shield=[0.5,0.75,1]`, and `DamageRt_Sprinkler=[0.5,0.75,1]`; the runtime maps them to low/mid/high ability points. Mark duration uses separate `MarkingTimeRt=[0.1,0.43,1]` and `MarkingTimeRt_Trap=[0.1,0.55,1]`. Toxic Mist movement, jump, and ink drain use their separate per-target effect state; the jump value now reaches `Actor._integrateMovementStep`. The actual retail slow and jump magnitudes remain calibrated because the available community measurement does not quantify the jump effect and labels the slow uncertain.

Paint parameters are also connected to real paths. Special projectile descriptors retain source damage/paint tiers; Tenta cross paint uses radius 2 and check length 3; Inkjet splash-around paint uses `.63/.665/.7` radius tiers; Super Chump uses cross-radius/check tiers `2.5/2.75/3` plus 1.116 satellite stamps; and Zipcaster uses a 1.4 cross radius/check length and trail width/depth/span values `1 / 1.5 / 2F`. Focused tests exercise the Chump expiry and Zipcaster impact/trail channels. These values feed the runtime painter, but stamp shapes, terrain projection, and world-unit conversion remain approximations. Reefslider splash-around velocity/radius tiers and `RutPaintRadius=1.2` are still unconsumed. The custom-sub cross-paint pattern also uses a small set of circular stamps rather than reproducing the source footprint exactly.

## Network authority and owner lifecycle

Custom sub events identify the shooter life/event sequence and the deployed object's source life, sequence, and sub ID. Replay rejects stale owner or target lives. Ghost devices do not apply damage. For remote-owned devices, the shooter proposes the already-scaled HP delta; the deployed device's owner validates the device identity/life and applies HP once. Special-object proposals likewise carry owner life, activation/object serial, tick, and the source cause; the owning peer remains the HP authority. The current design trusts the attacker's proposed, already-scaled amount after those identity checks. Receivers must not multiply it again.

Main actor-hit packets carry only an allowlisted source-cause enum. The receiver checks the cause against the attacker's current weapon/special identity before the victim-authoritative armor code consumes it. A cause is not a sender-provided multiplier. Focused network tests cover the Crab phase, retries/duplicates, and rejection of foreign-family causes; the native JSON proposal/replay set passes 32/32.

Point Sensor's compact mark event now carries the sensor `sourceLife` with an explicit `l` discriminator, preserving unambiguous parsing of legacy 7/8-field forms and transport trailers. Replay checks the sensor source life and the target's current life before applying the mark. Its support suite passes 17/17. Point Sensor's 6 m source distance is represented as a 6-unit radius; the Wiki's 1.2 trial-line measurement is the unit mapping, while capsule and collision agreement remain unverified.

Owner death is partly runtime policy rather than a parameter-table fact. Active special state ends when its actor dies; already-deployed special devices and an emitted Wave Breaker annulus can persist. Most custom subs and thrown bombs retain their source-life identity; Sprinkler is explicitly removed on owner death. The Point Sensor's deployed/persistence behavior across death and respawn still needs retail comparison. The pinned tables establish device parameters and lifetimes, not these death transitions.

## Remaining known gaps and unknowns

Known source numbers are distinguished from uncertain gameplay semantics. These are the notable open items across the linked family reports:

- **Custom subs:** Ink Mine shot-targetability has no target column in the damage-rate table, so the table cannot establish whether retail allows shooting a mine. Toxic Mist's 50% slow and jump magnitude remain calibrated. Autobomb target/rotation behavior, Fizzy ground-gravity mapping, Torpedo target/trajectory, sub hit geometry, and world-scale paint footprints still need retail comparison. See the per-sub table for numeric values and named fields.
- **Point Sensor and Tacticooler:** Point Sensor's mark duration, launch tiers, and source radius are consumed, but physical radius/capsule agreement and persistence across owner death are not established. Tacticooler `PutFrameOnYagura=450`, `VanishDistance=1.8`, and `SpecialReduceFrame=600` have no proven consumer/meaning in the current path.
- **Specials:** Tenta's screen-space `TargetInCircleRadius={140,190,240}`, circle distributions, and full 600F lock/depletion window are not represented. Inkjet splash-around velocity tiers are unused. Zipcaster source `SpawnSpeedZSpecUp=3.36` is unused and its hook anchor/pull behavior is approximated. Crab's repeat-frame bias and `ShooterMoveParam.SpawnSpeed=3.36` still need exact mapping. Reefslider splash-around/rut paint fields are unconsumed. Kraken `Dash_InvalidFrame=10` semantics are unproven. Wail lock radius, movement, collision, and world-space geometry remain calibrated even though its object row now applies.
- **Native/world mappings:** Suction Bomb has no source `FlyGravity`; Curling retains several source timing, speed-bias, and paint-bias fields without verified gameplay mappings. Storm's cloud reach/cylinder and rain behavior still need retail comparison; no base rain-particle damage is present in the pinned table. Bubbler placement, radius growth, and optional overlap-field target/unit remain calibrated or unclear. Splashdown fist geometry and paint remain calibrated.
- **Paint and collision generally:** Some source values are now consumed but still feed calibrated circular stamps, cylinders, planes, or aim-point movement. Exact collision order, world scale, floors/walls, and projection need in-game comparison. A consumed number does not prove retail-equivalent geometry.

The extracted-field inventory in `reports/source-parity-coverage-20261011.json` remains `NOT_COMPLETE`. It is not a count of gameplay requirements, and this audit makes no claim that every parameter leaf is consumed. No retail-console comparison was performed.
