# Rainmaker trail scratch reuse: not adopted

The proposed per-effects vector pool was rejected because it changes observable behavior of public physics method accessors. Production retains the original per-step clones from integrated baseline `7c94a8b`.

The rejected implementation captured `Physics.prototype.segment` and `raycast`, checked both identities before every trail step, leased separate scratch records for nested work, and preserved the original signed-zero additions. Independent execution of the actual trail block with fully composed real Physics methods passed32 cases covering canonical queries, custom data-method overrides, mid-loop replacement of either method, nested paint callbacks, exception unwind, missing canonical API, signed zero, paint options and retained custom inputs. A four-step canonical fixture allocated17 vectors before versus7 with pooling. These are isolated allocation counts, not game or device performance measurements.

A public `segment` getter can return the canonical function during the identity check and a custom function when the call reads the property again. That custom function receives pooled inputs which later change. The actual-block reproduction produced:

| Observation | Original clones | Rejected pool |
| --- | ---: | ---: |
| Getter reads across four steps | 4 | 8 |
| Retained argument references | 4 | 8 |
| Distinct retained vectors | 4 | 2 |
| Retained coordinates remain unchanged | Yes | No |

Adding further descriptor/prototype guards would complicate a small allocation optimization and leave proxy ambiguity. Reverting the pool preserves existing callback invocation and ownership semantics. No gameplay, paint, collision or default physics defect was accepted.

Evidence was generated by read-only review of the integrating checkout. The rejected combat source SHA256 is `2bd1d62f29131d92a0706eae57382899e2bf3f9dc848b3844a085cde3430bc4a`. Reproduction scripts and raw logs are retained under `/workspace/queue-work/motion/batch358/`: `rainmaker-review.mjs`, `rainmaker-review-final.log`, `rainmaker-accessor-review.mjs` and `rainmaker-accessor-review.log`. The passing matrix and failing accessor case describe the rejected candidate, not the reverted production source. No rendered, physical-device, FPS, GC or RSS result is claimed.
