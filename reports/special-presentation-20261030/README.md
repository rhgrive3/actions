# スペシャルの持ち方・搭乗姿勢・飛沫の改善

調査開始点は `fd6435a4dd2781928d211537c485c87bc50b3784`。統合時に main の `5d4c27d` を取り込み、既存のローラー・ガチホコ・変身などの修正を保持した。対象は公開版 `inkwave-public/` に適用する `patches/splatoon3/` の表示処理である。

## 修正したこと

| 対象 | 変更前の問題 | 今回の変更 |
| --- | --- | --- |
| カニタンク・サメライド | 通常の歩行・直立の骨格が搭乗中にも残る | カニは座面へ腰を上げ、サメは低く前傾して膝を曲げる。乗り物を地面の座標に保ち、終了時は通常のソースモーションへ戻す |
| ジェットパック・ウルトラハンコ等 | 手首をグリップ中心に置いており、実際の指の穴がずれる。両手が届かない構えもある | 指が囲む位置と手の向きを使って握り、手持ち機器だけを腕の届く位置に合わせる。ジェットパックの見える砲口を現在の照準へ向ける |
| ハンコの投擲構え・ミサイル等 | フレームごとの補間により描画頻度で動きが変わる | 60Hzの反応を基準に経過時間で補間し、停止中は進めない |
| スペシャル弾の着弾演出 | 弾リストから消えただけでも、最後に描画した位置へ飛沫が出る | 実際の終端バーストから着弾位置を受け取る。消去・再利用では着弾を捏造せず、初回描画より早い衝突も扱う |
| 飛沫の飛行 | 同じ噴出でも30/60/120Hzで拡がりと落下が変わる | 既存60Hzの運動を保つ分割ステップ計算へ変更。微小時間の数値例外も防ぐ |

攻撃の威力・塗り・移動速度・通信・ゲーム用乱数は変更対象にしていない。実際のActor、Projectiles、ソースアニメーションを使う比較試験で表示を有効／無効にした状態も検査する。描画プールの容量、描画数、頂点属性の容量は増やしていない。

## 本家との比較

[原典と観察条件](reference-audit.md)に、任天堂のカニタンク画像、Splatoon 3 Directのサメライド画像、既存のスペシャル映像資料と、そのURL・画像ハッシュを記録した。カニの座った上体とサメの低い前傾姿勢を観察した上で、INKWAVEの骨格とモデルに合わせて校正した。

プロファイルの数値参照はVer.11.3.0だが、姿勢を参照した公式画像・映像には発売前のものも含む。原典の正確なビルド、ギア、入力、関節曲線は未確認であり、今回の座標や0.18秒の姿勢移行を任天堂の抽出値とは扱わない。Switch実機との同条件比較や完全な見た目の一致は認定していない。

ナイスダマの頭上姿勢全体と、壁の法線に沿う汎用着弾飛沫は残る課題。頭上の球を無理に腕へ寄せると髪へめり込むため、その自動位置補正は適用しない。汎用飛沫の呼び出しには確実な接触法線がないため、推測した壁方向も使わない。

```sh
node scripts/build-inkwave.mjs inkwave-public _site
node scripts/check-inkwave-startup-budget.mjs _site
node scripts/render-inkwave-special-trajectory.mjs --site _site --out .ci-scratch/specials-60 --hz 60
```

30Hzと120Hzは `--hz` を変更する。ソフトウェアWebGLの実行結果は、SwitchやiPadでの性能測定の代わりではない。各担当の単独検証と統合後の検証を区別し、合格数を重複加算しない。


## 統合検証の結果

最終の製品コードは `bc11846475824b2d8fe3350b1f3fe0f17bfd73b6`、通常ビルドの内容ハッシュは `2d63aa0e01a04c07166825cb7859d603f47562dc5a99301fb1fd853a96bd3368`。以降のコミットは検証記録であり、5個の変更runtimeの入力ハッシュを生成物と照合した。

- 18ファイルの初回統合試験は300件中296成功。残る4件は、比較用の旧関数抽出が新しい隣接関数まで消す1件と、サメの旧姿勢を前提にした3件だった。抽出範囲を直して厳密比較3/3、姿勢と実グリップ到達を補正して最終重点13/13が成功した。失敗記録は削除せず保存した。
- 最終配信物の着弾試験は、ソースの観測部品38件と配信された実処理111件が成功。消去、再利用、壁・敵・近距離接触、複製弾、30/60/120Hzを含む。
- Chromium 154／SwiftShaderで、同じ順序・条件の60Hz比較画像と30/120Hzの補助検査を保存。通常アプリの `--exact-source` 検査も成功し、803応答を検証、JavaScript・console・request errorは0。起動、装備、移動、射撃・床塗り、通常画面の検査を含む。
- 入力互換性、通常ビルド、起動サイズ予算、移行監査が成功。カニの薄壁越しヒットに関する別のゲームプレイ試験1件は、変更前でも同じ失敗を確認し、未解消として持ち方の記録に残した。

コマンド・件数・ビルド識別子・圧縮した生ログは [validation.json](validation.json) に保存している。これは本家実機の完全一致や全CI成功の主張ではない。
