# Weapon and special queue completion — 2026-10-24

Baseline: `7f863ea2d65671abd1453fdae1b61de00f1d10e2`. Scope: 76 assigned queue records; 72 implemented, 3 query-cache proposals not adopted after executable counterexamples, and 1 Fizzy behavior gap still needs source evidence. Raw `inkwave-public` snapshots remain unchanged; native changes are composed by `weapon-queue-20261024-adapter.mjs`.

## Behavior comparison and decisions

The reference remains the repository's pinned Splatoon 3 **11.3.0** source parameter tables and its existing calibrated behavior. Validation uses native Shooter/Dualies/Splatling/Slosher/Blaster/Roller/ghost lanes, additional catalog families, low-ink Roller/Brush variants, retained specials, Screen/Wave AP 0 and AP 57, fixed 60 Hz logic and the existing 30/60/120 Hz checks. This work does not establish new Nintendo retail measurements or alter unresolved source provenance.

Projectile coordinates, paint order, damage authority, seeds, source clocks, accepted packet shapes and presentation ownership stay with their existing owners. Mutable source data is checked before reusing a depletion template. Reentrant snapshots and paint options use separate leases and release actor references in `finally`. Broadphase filters are negative-only; near candidates still use the original exact solver. Booyah tile assembly is cached only after the original fresh contact query. Raw beam lifecycle records remain owned by their pooled meshes.

Three implementations deliberately use a safer variant of the proposal. Crab legs cache **both original sine expressions** only when their phase is unchanged, since `sin(angle + PI)` is not bit-identical to `-sin(angle)`. Slosher sweep configuration is fetched once per pellet, preserving changes between published projectiles. Slosher intermediate-drop caching retains live source selection and only reuses its checked immutable static plan.

Remote world-device admission now binds permitted kind to special ID and applies the local producers' numeric envelopes before a replay identity or mesh is created. Screen dimensions remain 15 by 9 and lifetime is bounded by the existing 680-frame source clock, allowing its existing wire rounding. Remote live-object budgets of 64 per actor and 512 total are explicit protocol safeguards, not claimed Nintendo constants. An invalid or budget-rejected birth does not consume its replay key, and the existing sender/life/owner and object-hit adjudication checks are preserved.

- 32 targeted existing runtime suites pass, including native Charger trajectories, catalog depletion/falling paint, all subs, Torpedo, Bubbler/Vac, Trizooka, VFX recipes/pools, projectile geometry, presentation, slope paint, Screen contact and sparse/reordered device replay.
- The full `all-specials.test.mjs` gate passes **83/83** with `node --max-old-space-size=4096 --experimental-vm-modules`. The candidate failed at approximately **1,991 MiB live / 97.4 seconds**. The resource limit is present on the original runtime; the full source-fixture suite requires the stated 4 GiB heap setting in this environment. No CI workflow parallelism or heap setting was silently changed.

The recipe-extraction test fixture now uses the production lexical class name, and triangle budgeting supports both indexed and nonindexed geometry. The corresponding assertions remain in place. New Safari/iPad measurements, real GPU screenshots/timings, full multi-client transport replay and retail-device comparison remain unmeasured.
