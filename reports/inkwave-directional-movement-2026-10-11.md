# 全方向・射撃中・ローラーの移動速度

比較元: main `ffb9ec9884d853e25b2948209c7049bb03f17ebc`。参照: スプラトゥーン3 Ver.11.3.0、ギア0/10/57 AP、ヒト状態の平地。ロックされた公開版と本番アダプターを通した出力を対象とする。

## 原典

[公式11.3.0更新履歴](https://support.nintendo.com/jp/switch/software_support/av5ja/1130.html) と [Leannyの一次抽出](https://github.com/Leanny/splat3/tree/7280ff9cde8bb1c5dcef46c700c326471584d2e6/data/parameter/1130) を確認。抽出資料は任天堂が公開した仕様書と区別する。カーボンローラーの更新をスプラローラーに混ぜない。

GitHubから固定コミットのJSON本文を再取得し、SHA-256を既存の `curated-numbers.json` と照合した。

- `WeaponShooterNormal`: `dfca9f45fd0df3b6afab8f6ec0e47034912f3a6fc411936b9fd7257fe85c4cb9`
- `WeaponRollerNormal`: `5b423eb35d4cac268a1e4085ec8321d27639ddbfc8f3775bb65696af5c2449c7`

|---|---:|---:|
| 通常歩行・中量級・0 AP | 0.096 | 5.76 |
| スプラシューター射撃中 | 0.072 | 4.32 |
| マニューバー射撃中 | 0.080 | 4.80 |
| ホットブラスター射撃中 | 0.045 | 2.70 |
| バレルスピナー射撃 / チャージ | 0.070 / 0.062 | 4.20 / 3.72 |
| スプラチャージャーフルチャージ | 0.020 | 1.20 |

値は変更せず、値を選ぶ状態を修正する。この換算がNintendo実機とステージの縮尺・加減速曲線まで完全一致する証拠ではない。

## 差分と修正

| 再現操作 | 修正前 | 修正後 / 実装 |
|---|---|---|
| スプラシューターでZRを押し続けて移動 | 6Fの弾間隔中に4Fタイマーが切れ、通常速度・通常ギア曲線・通常敵インク曲線に戻る | 発射済みの継続射撃は弾間隔も射撃速度を保持。解除後は既存4Fの末尾を保持。`runtime/shooter-movement.mjs`, `runtime/weapons.mjs`, `runtime/gear.mjs` |
| 初弾が出るtick | Actor移動がRunnerより先なので初弾の移動だけ通常速度になる | 呼び出し中のdtで同じtickに実際に許可される発射を判定。未発射のstartup・インク不足・キャンセル中は除外 |
| ローラーを振った直後に移動 | 古い`.18`秒回復期間で`1.728→5.76`に補間し、その後`2.88`に戻る | 既存回復期間も振り速度を保持し、射撃用ギア曲線を適用。期間やアニメーションは変更しない。`adapter.mjs`, `runtime/gear.mjs` |
| 振りから押し続けて塗り進む | 転がしが許可済みでも見た目の回復タイマーが残ると転がし速度が選ばれない | 実際に許可された転がしを優先。6.48→90F後7.92、ヒト速による増速なし。`runtime/movement-physics.mjs` |
| スロッシャーの振り上げ中にヒト速装着 | 姿勢タイマーだけを見ると通常用曲線を選ぶ可能性 | 実攻撃`slosh`状態を射撃用ギア曲線に含める |

斜め入力自体には、平地で速度が√2倍になる差分は再現しなかった。入力は円形に正規化され、全方向の最高速度が等しい。根拠のない方向別倍率を追加せず、全方向の回帰試験を追加した。

## 検証

- 実PlayerController: キーボード8方向、パッド・タッチ各24方向×3入力強度×4カメラ方位。
- 実Actor: 7ブキ×0/10/57 AP×各攻撃状態×72方向×0.1/0.5/1.0入力。溜め、ローラー振り・回復・転がし・疾走を含む。
- 実Projectilesの連射速度、インク不足、解除。実Runnerの振り→転がしの境界。
- 実Level/Physics: 歩行・射撃・通常転がし・疾走の各24方向の移動距離。方向間の許容誤差1e-8。
- 30/60/120/144 Hzから180回の固定60 Hz更新を作り、速度・インク・発射数・ローラー時間を比較。
- `scripts/check-inkwave-movement-speed.mjs`: 実ブラウザの本番インストーラーとキャラクターを含む出力で歩行・連射・振り→転がし→疾走の72条件。速度・移動距離を検証し、ビルドハッシュ付きJSONを保存。CIのactive browserジョブにも追加。
- 比較元の独立checkoutへ新テストを移して負例を確認。連射、振り回復の補間、転がし開始の速度所有の差分を検出し、通常の方向間距離は比較元でも等しいことを区別する。
