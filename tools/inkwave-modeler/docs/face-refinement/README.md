## 2. 分かったこと（計測結果）

### 2.1 位置はほぼ合っていた（似ない原因は「形」と「質感」）
- 正面キャリブレーション画像での MediaPipe 比較では、目・鼻・口の位置は参照と **数 mm 以内**（ランドマーク残差は IOD の 3〜4%）。`img/10`
- つまり「似ていない」主因は位置ではなく、次の形状と質感の差だった。

### 2.2 形の差（主因）
1. **耳の下側がフランジ状に顎まで伸びていた。** 耳の根元の下幅が 4.75 cm あり、顎ラインと一体化して下顔面が楔形に見えていた（`img/15`, `img/05`）。参照の耳は丸い耳たぶで終わり、顎とは離れている。
2. **目が平らなドームだった。** 瞼の厚み・上瞼の影・眼球の丸みがなく、3/4 や横から見ると顔に貼った絵のように見えていた（`img/03`）。
3. **上まつ毛の帯が細い。** 参照は約 6〜7 mm（正面 5〜6 px）の黒い帯＋外側の房。モデルは半分ほど（`img/12`）。
4. **眉。** 参照の方が約 1.5 px 太く、右眉の外側の端が 4 px ほど高い（`img/13`）。
5. **顎。** 参照は幅の広い U 字、モデルは V 字。正面の輪郭半幅（参照 → モデル）: y=−0.091 m で 43 mm → 44 mm、y=−0.097 m で 29 mm → 34 mm、あご先は参照の方が平らで広い（`img/11`）。
6. **Sapiens 法線での比較（`img/08`）。** 参照の方が頬の丸み、目の周りのくぼみ、鼻筋の立ち上がりがはっきりしている。ただし Sapiens の深度は凹凸を平らにする傾向がある。モデル自身の Sapiens 深度と真の深度の差は RMS 7 mm なので、ここは相対比較にだけ使った。

### 2.3 参照シートのカメラ（モデル側の軸）

- **横シート**: az ≈ −0.95 rad。真横ではなく、顔が約 40° カメラ側を向いている。
- **正面シート**: 既存のキャリブレーション（842 px/m）に一致。頭のロール（傾き）は約 6.6°。

### 2.4 耳の向き

## 6. Blender マスターでの修正（2026-09-27）

### 6.1 方法
- スクリプト: `../../scripts/inkwave_face_refine.py`。頭の座標系（ランタイムの頭の中心・向き。x = キャラの左、y = 上、z = 前）でなめらかな変位の場を定義し、`HEAD` の肌（`HEAD_face`）と、その上のデカール（チーク、鼻、唇、口の線 = `HEAD_skin*`）に同じ場をかける。耳（`HEAD_face_02/03`）、目、眉、髪、服は動かさない。
- メッシュは普通のメッシュのまま（リメッシュなし、頂点数・面・UV は同じ）。Blender でそのままスカルプトでき、どのエクスポーターでも修正後の形が出る。ランタイムの形は点属性 `inkwave_runtime_position`（glTF には出ない）に残してあり、スクリプトを再実行すると同じ結果になる（GLB がバイト単位で一致）。`--only ''` でランタイムの顔に戻る（229 メッシュの形が修正前の GLB と一致）。パラメーターは `.blend` のテキスト `INKWAVE_FACE_REFINE.json` にもある。
- 計測: `../../scripts/inkwave_face_views.py`（Blender で正面・3/4・横を参照シートと同じ構図で描画: 普通の絵、クレイ、法線、部品別マスク）と `../../scripts/inkwave_face_metrics.py`（参照シートの顔の輪郭と MediaPipe の特徴点）。
  - 正面は較正済み（842 px/m、1 px = 1.19 mm）。3/4 と横は、修正前の描画で求めた相似変換を固定して使う（修正で枠が動かないように）。
  - 参照の輪郭は「肌らしさ」（R が G・B より十分大きいか）の境目。髪に隠れる所（正面の右の頬、横の眉間）は数えない。あごと首の境目（肌どうし）だけは 10〜12 倍の拡大図で手で取った（±1.5 px）。
  - 正面のシートでは、頭がモデルより 4〜8° 多く左を向いている（鼻先の x: モデル 567.8、参照 573.4）。このため左右の差は向きのせいで、形の比較には左右の和（幅）を使う。

  - `--edited '^HEAD_(face|skin(_0[2-9])?)$' --edit-budget-mm 5` で source / master / game / 再オープン後の再書き出しの 4 つとも **ROUNDTRIP PASS**（229 メッシュ、366,476 三角形、129 材料、画像 107、extras 230/230、編集したメッシュの最大 3.74 mm、UV の差 0）。
  - 予算なし（今までの厳密な検査）では、差が出るのは `HEAD_face` と `HEAD_skin*` だけ。

### 6.6 頬と顎の折り込み線を弱めた状態（ユーザー指定の保存点）

- 原因は `HEAD_face` 本体の形状。顔本体だけのクレイ描画でも、口の横から耳の下へ走る暗い折れが残った。目の下には別のリング状の継ぎ目もあった。頬の色パーツの縁は、頭全体のクレイ描画でさらに細い曲線として見える。
- `../../scripts/inkwave_face_fold_refine.py` は顔の 157×177 頂点格子の該当帯だけを列ごとに 3 次 Hermite 曲線へ置き換える。鼻、口、目、顎先は動かさず、頬のデカールを追従させた。リメッシュや UV 変更はない。
- 折れの帯（輪 52–70）の法線曲率: 最大 **96.0 → 52.3 1/m**、95 パーセンタイル **67.4 → 41.3 1/m**。目の下の継ぎ目（輪 74–80）の 95 パーセンタイルは **138.6 → 65.9 1/m**。顔本体で動いた頂点 2,346、最大 2.42 mm。
- 顔本体だけのクレイで、折れを横切る最も急な明るさの変化は正面 **1.93 → 1.31**、3/4 **1.59 → 1.10**、横 **1.75 → 1.07** 階調/px。顔の輪郭マスクの修正前後の IoU は正面 0.9993、3/4 0.9989、横 0.9997。測定の詳細は永続作業領域の `evidence/inkwave-postmigration-refinement/fold/result.md` にある。
- 比較画像: `img/19_fold_face_only_before_after.jpg`（顔本体だけ）、`img/20_fold_all_head_before_after.jpg`（デカール等を含む頭）。各画像は正面・3/4・横の修正前後。
- **残差:** 3/4 では頬の下面に柔らかい影の帯が残る。頬パーツの細い境界線も残る。完全に線が消えたとは主張しない。追加の広い平滑化、顎の押し出し、デカールの深さ変更を別のコピーで試したが、下顎の帯が悪化するか目の下に影響したため、マスターには採用していない。
