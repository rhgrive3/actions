## 2. 分かったこと（計測結果）

### 2.1 位置はほぼ合っていた（似ない原因は「形」と「質感」）
- 正面キャリブレーション画像での MediaPipe 比較では、目・鼻・口の位置は参照と **数 mm 以内**（ランドマーク残差は IOD の 3〜4%）。`img/10`
- つまり「似ていない」主因は位置ではなく、次の形状と質感の差だった。

### 2.2 形の差（主因）
1. **耳の下側がフランジ状に顎まで伸びていた。** 耳の根元の下幅が 4.75 cm あり、顎ラインと一体化して下顔面が楔形に見えていた（`img/15`, `img/05`）。参照の耳は丸い耳たぶで終わり、顎とは離れている。
2. **目が平らなドームだった。** 瞼の厚み・上瞼の影・眼球の丸みがなく、3/4 や横から見ると顔に貼った絵のように見えていた（`img/03`）。
3. **上まつ毛の帯が細い。** 参照は約 6〜7 mm（正面 5〜6 px）の黒い帯＋外側の房。モデルは半分ほど（`img/12`）。
4. **眉。** 参照の方が約 1.5 px 太く、右眉の外側の端が 4 px ほど高い（`img/13`）。
5. **顎。** 参照は幅の広い U 字、モデルは V 字。正面の輪郭半幅（参照 → モデル）: y=−0.091 m で 43 mm → 44 mm、y=−0.097 m で 29 mm → 34 mm、あご先は参照の方が平らで広い（`img/11`）。
6. **Sapiens 法線での比較（`img/08`）。** 参照の方が頬の丸み、目の周りのくぼみ、鼻筋の立ち上がりがはっきりしている。ただし Sapiens の深度は凹凸を平らにする傾向がある。モデル自身の Sapiens 深度と真の深度の差は RMS 7 mm なので、ここは相対比較にだけ使った。

### 2.3 参照シートのカメラ（モデル側の軸）
- **3/4 シート**: az ≈ −0.35 rad（約 20° 右）、el ≈ −0.28 rad（下から見上げ）。ランドマーク残差は IOD の 2.9%。
- **横シート**: az ≈ −0.95 rad。真横ではなく、顔が約 40° カメラ側を向いている。
- **正面シート**: 既存のキャリブレーション（842 px/m）に一致。頭のロール（傾き）は約 6.6°。

### 2.4 耳の向き
3 視点で耳先の位置を最小二乗フィットし、耳先の向きを (0.080, −0.010, −0.050)×耳の長さ に決めた。以前より横向きで、やや下を向く。

## 5. 残り（次にやること）
1. **顎と頬**: U 字の顎（上記の半幅表を目標値にする）、頬の丸み、下顎の稜線をなくして柔らかくする。3/4 で楔形に見える主因はこれ。
2. **鼻**: 丸いボタン鼻、鼻筋を弱く、小鼻をはっきり。
3. **口**: 唇を約 3 mm 前へ、下唇をふっくら、口角のくぼみ（スマーク）。
4. **ライナーの一部が瞼のメッシュに隠れる**: デカールの深度の問題（`img/16`：左が参照、中央が目の部品だけ、右が全体）。帯はデカール単体では太いのに、全体表示では細く見える。
5. **眉**: 約 1.5 倍に太くし、眉頭を四角く、外側の端を上げる。
6. **肌色とチーク**: 参照の方が明るく、彩度が低い。頬の実測は 参照 (216,134,106) に対しモデル (193,114,81)。頬と鼻先の赤み、頭部の頂点カラーで AO（耳甲介、鼻孔、口角）を入れる。
7. **下瞼**: ハイライトの帯が少し強いので弱める。
