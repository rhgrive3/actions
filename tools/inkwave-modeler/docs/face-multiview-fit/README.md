# INKWAVE 顔の多視点フィット（半自動）

対象: `blender/INKWAVE_CHARACTER_MASTER.blend` の顔（`HEAD_face` と、その上の貼り物 `HEAD_skin*`）。
参照: `refs/sheet_5view.png`（5 方向のシート: 正面、3/4 左向き、横 左向き、3/4 右向き、横 右向き）。
結果: `blender/INKWAVE_CHARACTER_MASTER.blend` と `INKWAVE_CHARACTER_MASTER.glb` / `INKWAVE_GAME.glb` に反映済み（2026-09-28）。元の状態はマスターの中に保持している（7 章）。途中の確認用ファイル `INKWAVE_FACE_FIT.blend` は、マスターに入れたので削除した。

方針: モデルを作り直さない。目・眉・耳・髪・服は動かさない。5 方向の誤差を**同時に**小さくする、なめらかで左右対称な変形を 1 つだけかける。
数値は目安で、最後は見た目で決めた（4 章）。

## 1. 手順（まとめ）

| 段階 | 何をするか | 自動 / 手 | ファイル |
|---|---|---|---|
| 0 | マスターから頭の形を numpy に書き出す | 自動 | `analysis/multiview/export_geom.py` |
| 1 | 参照シートを 5 ビューに分け、目印（ランドマーク）を付ける。正面と 3/4 は MediaPipe で下書き、全ビューを目で確かめて直した。横顔は手で付けた | 半自動 | `ref_landmarks.json`、`gridcrop.py`（目盛り付き拡大）、`mp_try.py` |
| 2 | 参照の顔の輪郭を肌の色のマスクから行ごとに取る（耳・首・前髪がかかる行は除く） | 自動 | `contours.py`（`SPEC` に行の範囲） |
| 3 | モデル側の目印を形から自動で決める（中心線の鼻先・唇・顎、瞳、眉の端、耳の先、口角、鼻の穴） | 自動 | `model_lm.py` → `model_lm.json` |
| 4 | 5 台のカメラを合わせる（向き・上下・傾き・大きさ・位置、距離は共通）。目印＋輪郭で、変形なしのモデルに対して解く | 自動 | `fit.py` の `rigid_fit`、`camfit.py` → `cams_rigid.json` |
| 5 | カメラを固定し、変形を解く（下の 2 節） | 自動 | `fit.py` → `field.json` |
| 6 | 検証: 前後の数値、1 ビューを外した検査、形の指標、画像 | 自動 | `report.py`、`loo.py`、`shape_metrics.py`、`compose.py`、`heatmap.py`、`triangle.py` |
| 7 | Blender に適用して新しいファイルに保存（元の状態も中に保持） | 自動 | `scripts/inkwave_face_multiview_fit.py` |
| 8 | 目頭〜頬のならし（Blender の Corrective Smooth、Shrinkwrap、Data Transfer。5 章） | 自動 | 同じスクリプト（`--no-smooth` で外す） |
| 9 | 上唇（6 章） | 自動 | 同じスクリプト（`--no-lip` で外す） |
| 10 | 下まつ毛（6 章） | 自動 | 同じスクリプト（`--no-lashes` で外す） |

### 再現コマンド

```bash
cd tools/inkwave-modeler
blender --background blender/INKWAVE_CHARACTER_MASTER.blend --python analysis/multiview/export_geom.py -- analysis/multiview/geom_before.npz
cd analysis/multiview
python3 model_lm.py geom_before.npz                      # model_lm.json
python3 -c "import json,fit,camfit,mvcore as M; g=M.load('geom_before.npz'); x=fit.rigid_fit(g,json.load(open('ref_landmarks.json')),camfit.VIEWS); json.dump({'x':list(map(float,x))},open('cams_rigid.json','w'))"
python3 fit.py geom_before.npz --out field.json --set lam_bend=20000 sigma=0.015 spacing=0.015
python3 report.py geom_before.npz field.json final        # 数値（final_report.json）と重ね画像
for v in front q34L sideL q34R sideR; do python3 loo.py $v; done
cd ../..
blender --background blender/INKWAVE_CHARACTER_MASTER.blend --python scripts/inkwave_face_multiview_fit.py -- \
  --field analysis/multiview/field.json --save blender/INKWAVE_CHARACTER_MASTER.blend \
  --export blender/INKWAVE_CHARACTER_MASTER.glb --game blender/INKWAVE_GAME.glb
# 試すだけなら --save に別のファイル名を渡す。スクリプトは最初に前の結果を元に戻してからかけ直す
```
Python の依存: numpy 1.26、scipy、opencv、pillow（MediaPipe は段階 1 の下書きだけ。入れると numpy 2 に上がって scipy が壊れるので、そのあと `pip install numpy==1.26.4` に戻す）。

## 2. 変形のしくみ

- **変形**: 顔の表面に 15 mm 間隔で置いたハンドル（ガウス、σ 15 mm）の和。x > 0 のハンドルは左右の鏡像と対になる（左右対称）。中心線のハンドルは横に動かない。
- **守る所（重み 0）**: 目の全部品（眼球、まぶたの線、まつ毛）から 3〜15 mm、眉から 3〜12 mm、耳から 5〜20 mm、刈り上げの層（`HAIR_scalp`）から 3〜15 mm、頭の後ろ、生え際（高さ 40〜70 mm）で、なめらかに 0 へ落ちる。
- **動かすもの**: `HEAD_face` と、同じ場所にある貼り物（チーク、三角のペイント、口、鼻の穴、鼻の下の影）を同じ場で動かす（貼り物は肌から離れない）。
- **合わせる量**（すべて画素。シートでは 1 px ≈ 1 mm）:
  - 目印の誤差（横顔の唇・顎の点は輪郭に沿ってすべるので重みを下げた）
  - 輪郭: 参照の輪郭の各点と、モデルの外側の輪郭の一番近い点との、輪郭に直角な距離
  - 罰（ペナルティ）: 表面の移動量の 2 乗平均（`lam_disp` 15）、表面の曲がり方の変化（格子のラプラシアン、`lam_bend` 20000。新しい山やへこみを作らない）、となりのハンドルの差
- **解き方**: ガウス・ニュートン法を 8 回（Huber で外れ値に強く）。カメラは段階 4 の値に固定。ハンドルは 62 個。カメラと変形を交互に解くと、顔全体が動いてカメラが追いかけ、20 mm の変形になったため（4 章）。

## 4. 途中で分かったこと、変えたこと

1. **最初の差の多くはカメラだった。** 目印だけでカメラを合わせると正面の輪郭の差は 7.1 px。輪郭も使ってカメラを合わせると 1.3 px。形の差として残ったのは主に 3/4 左向き（奥の頬の下）と横 右向き（鼻の付け根）。
2. **カメラと変形を交互に解くと逃げ合う。** 顔全体が 10〜20 mm 動き、カメラがそれを追いかけた。カメラを固定し、罰を「ハンドルの値」ではなく「表面の移動量」にかけて直した。
3. **目の穴のふちを輪郭と取り違えていた。** 顔メッシュの穴（目の開口）を埋めてから外側の輪郭を取るように直した。
4. **数値は良いが見た目が悪い版を捨てた。** 曲がりの罰なし（σ 11 mm）では、口を下げた分が口の下のふくらみになった。曲がりの罰と σ 15 mm で、新しい山やへこみ（ラプラシアンの変化の 95%点）が 0.199 → 0.083 mm に減り、口の下のふくらみが消えた。誤差の減りは少し小さくなったが、こちらを採用した。

## 5. 目頭〜頬のならし（2026-09-28）

指摘: 目頭のはしから頬にかけて、なめらかでない。

原因（部品を 1 つずつ外して描画して特定）:
1. **チークの貼り物**（`HEAD_skin` = 左、`HEAD_skin_04` = 右）。位置は肌の 0.30 mm 上でそろっているが、描画の法線（面の向き）が 5% の点で肌と 80〜90° ずれていた。これが目の下のうろこ模様。フィットの前からあった（`inkwave_face_look.py` で細かく分けたときのもの）。
2. **顔のメッシュ**: 目頭から斜め下へ、ゆるい溝と段。

直し方（すべて Blender の機能。スクリプトの `smooth_eye_cheek`、`relay_blush`）:
1. `HEAD_face` に頂点グループ `FACE_FIT_SMOOTH` を作る。重みは目頭 (|x| 26, y -26 mm) から頬 (44, -50) への線から 7 mm 以内で 1、16 mm で 0。目の部品から 1.5 mm 以内は 0、5 mm で 1（まぶたのふちと眼球は動かない）。
2. **Corrective Smooth**（Only Smooth、Length Weight、30 回、係数 0.5）をこのグループにかけて適用。最大 2.0 mm、1,197 頂点。Laplacian Smooth はこのメッシュ（メートル単位で小さい）ではほとんど動かなかったので使っていない。上の貼り物は肌と同じだけ動かす。
3. チークの貼り物の、目の部品から 4〜7 mm 以内だけに Corrective Smooth（ふち固定、10 回）をかける。目のふちの急な所で、貼り物の小さな三角形が折れていたため。全体にかけると穴が開いたので、範囲を限った。
4. **Shrinkwrap**（Nearest Surface Point、0.3 mm 上）でチークを肌に置き直し、**Data Transfer**（Custom Normals）で肌の法線を写す。
5. 顔の法線を作り直す（中心線の継ぎ目は平均）。

結果: うろこ模様と目頭の溝が消えた（`img/07`）。フィットの数値はほぼ同じ（3/4 右向きの輪郭 1.15 → 1.17 px、横 右向き 2.46 → 2.43 px）。
残り: 目頭の下の短い茶色の線は形ではない（部品の色分けの描画には出ない）。肌か貼り物の絵に描かれた線で、フィットの前からある。消すなら絵を直す。
チークの折れは目のふちでごく少し残る（クレイの拡大でだけ見える）。

オプション: `--no-smooth`（この段階を外す）、`--smooth-iters`（30）、`--smooth-factor`（0.5）。`--restore` と再実行はこの段階も含めて完全に元に戻る・同じになる（確認済み）。

## 6. 上唇と下まつ毛（2026-09-28）

### 6.1 上唇（`upper_lip`）

参照: 口の線の上に薄いピンクの帯があり、中央に小さな山（キューピッドボウ）がある。横から見ると上唇が少し前に出る。モデルは口の線の上がふつうの肌だった。

- 口の線の貼り物（`HEAD_skin_09`）の上のふちを 4 次式（左右対称）で近似し、その上に帯の形を決めた: 中央の高さ 3.0 mm（山のくぼみ 0.6 mm を引いて 2.4 mm）、口角（|x| 23.5 mm）へ細くなる。頂点の並びそのままでは線がぎざぎざだったので、式にした。
- 帯の下の肌を、肌の法線の方向へ最大 0.5 mm 前に出した（口の線で 0、帯の中ほどで最大。唇が線へ巻き込む形）。上の貼り物も同じだけ動かす。
- 帯は肌の上に置いた格子（95 × 7 点）で、肌から 0.22 mm 上（口の線の貼り物 0.37 mm の下）。下唇の貼り物 `HEAD_skin_08` に足したので、材料は下唇と同じ。部品の数と材料は変わらない。

### 6.2 下まつ毛（`lower_lashes`）

参照: 下まぶたの目じり側 1/3 に、短く太い黒い毛が 5〜6 本、外下へ向く。モデルの下まつ毛（`HEAD_eyes_13` / `_30`、4 本）は目じりの外で後ろへ伸び、正面からは見えなかった。

- 片目 6 本。根元は下まぶたの線（`inkwave_face_look.py` の `lid_lower`）の 0.45 mm 下、頭の座標の |x| 56〜72.5 mm。
- 向きは真下から外へ 15°（内側）〜 45°（外側）。長さ 4.0〜5.5 mm、根元の半径 0.4 mm で先へ細くなる 6 角の管。
- 目の下の肌は上を向いた「棚」になっている（目がくぼんでいるため。根元の法線は上向き成分 0.6〜0.8）。真下へ出すと肌にもぐり、肌から浮かせると正面へ倒れて短く見えた。そのため肌に沿わせ、少しだけ浮かせた（法線方向 0.12、先を 0.1 反らせる）。
- 今の下まつ毛の部品に足したので、材料（黒）は同じ。
- 途中の版: 黒目の下まで 8 本の細い毛を並べた版は、参照（目じり側に太い毛）と場所も太さも違った（ユーザーの指摘）。`img/09` で同じカメラで比べて直した。

### 6.3 元に戻す仕組み

形（頂点数）が変わる部品 `HEAD_skin_08`、`HEAD_eyes_13`、`HEAD_eyes_30` は、何かを変える前にメッシュ全体を `<部品名>__prefit_topo`（フェイクユーザー、書き出されない）として残す。`--restore` はこれに入れ替える。ほかの部品は 7 章の属性で戻す。

## 7. Blender での使い方（元の状態の保持）

`blender/INKWAVE_CHARACTER_MASTER.blend` の中:

- `FACE_FIT / FACE_FIT_ORIGINAL`: 変える前のコピー（`HEAD_face__prefit` など 12 個）。レンダーと書き出しから外してある。目のアイコンで今の顔と切り替えて比べる。
- `FACE_FIT / FACE_FIT_CAMERAS`: 合わせた 5 台のカメラ（`FACE_FIT_CAM_front` など）。背景に参照の画像が半透明で出る。カメラを選んで Numpad 0 で重ねて見る。
- 変えたメッシュは点の属性 `inkwave_prefit_position` に元の位置、角の属性 `inkwave_prefit_custom_normal` に元の法線（圧縮前の生データ）を持つ（glTF には出ない）。
- テキスト `INKWAVE_FACE_MULTIVIEW_FIT.json` に、使った値と部品ごとの最大移動がある。

操作:
- 元に戻す: `--restore`（この作業の前のマスターと、位置・法線・頂点数とも完全に一致することを確認済み）。
- 半分だけかける: `--amount 0.5`。
- 再実行しても積み重ならない（前の結果に戻してからかけ直す。差 0 を確認済み）。
- 顔の他の手順との順番は `inkwave_face_refine.py` → `inkwave_face_look.py` → このスクリプト。前の 2 つをかけ直すときは、先にこのスクリプトの `--restore` をかける。

## 9. 残り（今後の微調整）

1. **鼻の付け根をもっと深く**: 参照の横顔は付け根が 2 px 深い（三角形の赤線 47.3° / 参照 51.7°）。目のまわりを守る範囲（3〜15 mm）が付け根のくぼみを止めている（`../face-refinement/README.md` 12 章と同じ理由）。目頭のまわりの固定を少しゆるめる判断が要る。
2. **目**（`img/09`）: 参照の上まつ毛は太いアイライン＋まばらな太い毛 5 本ほど。モデルは細い毛がくし状に密に並ぶ。参照の黒目は濃いティールで瞳が大きく、モデルは明るくつやが強い。目の形も参照は目頭が低いつり目。目は固定の約束なので、下まつ毛以外は変えていない。目印の誤差の残り（4〜7 px）の多くはここ。
3. **鼻**: 参照の鼻は小さく丸い。輪郭では合うが、正面の鼻の穴の見え方は形ではなく貼り物と材料の差。
4. **耳**: 参照の耳は後ろへ長く寝ている。モデルの耳は横へ立っている。固定の約束なので変えていない。耳の目印は重みを下げてカメラ合わせだけに使った。
5. **首と襟**: 横から見ると参照の首は顎の下が長い。体の部品なので対象外。
6. 横 右向きの参照の輪郭は、眉の端が輪郭にかかる 3〜4 行で肌のマスクが欠ける（`img/06` の白線の段）。Huber で影響は小さいが、行を除くとさらに正確になる。
7. `--amount` を 0.7〜1.2 で振って、見た目で最終の量を決めてよい。
