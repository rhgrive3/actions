# まつ毛とライナーの作り直し（候補 L33。まだマージしない）

- 目の開き（眼裂）と目玉は変えない。髪、頬、口、鼻、あごも触らない。
- ライナー、上まつ毛 4 本、下まつ毛 6 本、下の線は、それぞれ別パーツ。
- 古い下まつ毛の塗りは、顔の材料スロットを戻して消した。`HEAD_face` の形は同じ。
- 基準（マスター）と比べて変わった部品: 19（目のライナー・まつ毛・下の線と、`HEAD_face` の材料スロット）。ほかの 205 は同じ。

## 作り方

```bash
cd tools/inkwave-modeler
blender -b <マスターのコピー.blend> --python scripts/inkwave_lash_rebuild.py -- --save <out.blend>
```

設計: `analysis/lash_rebuild/design_3d.json`（正面の形 + 立体の情報）。元の正面の形は `design.json`。
立体の情報の作り方は `analysis/lash_rebuild/fit/`（`triang2.py` → `tri_lashes.json`、`make_rel_design.py`）。

## 形の決め方

1. **正面**: 参照の正面から、ライナーの上の線・羽・まつ毛の位置を取る。
   ライナーの下の線は、参照の黒の下のふち。ただし、モデルの目の開きの上のふち（+0.3 px）より上には上げない（肌のすき間を作らない）。
2. **目じり**: 羽の下のふちは、目じりの角までまっすぐ下り、下の線とつながる。角の肌は白目のふちまで黒で埋める。
3. **立体（まつ毛は顔に貼らない）**: 参照の正面・3/4 右・横右で、同じ点（羽の先、まつ毛の根元と先）を拡大して読み、三角測量した（誤差 2.6 px 以内）。
   - まつ毛は、参照の立体の向きと長さ（上・外・少し後ろ、4〜6 mm）を、モデルのまぶたの上の根元に付けた。先は肌から離れる。
   - 羽は根元 1 との位置関係を保つ。肌からの浮きは先で約 1.5 mm。
   - 下まつ毛も先が肌から 1.5 mm 立ち上がる。
4. ライナーは肌にそって置く（浮きは最大 1.2 mm）。こめかみの髪の膜 `HAIR_hair` が肌から 5 mm 以内にある所では、その前に置く。左目は右目の鏡。髪は左右で形がちがうので、左目で膜の下に入った点は前に出す。

## 残っている差（ライナーでは直せないもの）

- 3/4 と横では、ライナーの帯が参照より少し太く、前に出て見える。三角測量では、参照の目じりのまわりのまぶたが、モデルより約 5 mm 前にある。まぶたの奥行きの差。
- 下まぶたの線は、目じり側で参照より約 2 px 低い（目の開きの形）。
- 正面の参照は、3/4・横と比べて約 2 px 上にずれている（カメラ合わせの誤差）。正面は参照どおりにした。
