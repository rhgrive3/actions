# 顔の立体感（頬・目の下・鼻筋・あご・鼻・口）候補 V68（まだマージしない）

横から見た輪郭（口・鼻・あごの高さ）は参照と合っているので変えない。横から見えない面のふくらみを直す。
目、まつ毛、髪は変えない（まつ毛とライナーは新しい肌の上で作り直すだけ）。

| 目から頬へのカーブが短く急 | 合っていた。目の下 20 mm がほぼ垂直で、その下 13 mm で急に 14 mm ふくらむ |

| 正面のあごの輪郭が直線的 | 合っていた。参照は輪郭の傾きがだんだん変わる丸いカーブ、モデルは一定 |

## やり方（`scripts/inkwave_face_volume.py`、設定 `analysis/face_volume/params.json`）

すべて Blender の標準機能（Warp / Displace / Smooth を、なめらかな重みの頂点グループにかけて適用。重みは Weight Smooth でならす）。
肌の層・貼り物・眉・まぶたの溝の帯は Surface Deform で顔についていく。目玉から 3〜8 mm は動かさない（鼻筋は 0.8〜2.5 mm）。唇は守る。

1. 下の顔をならす（口の横の段と小鼻から頬の溝を消す）。
2. 頬を前へ出す（最大 4.5 mm）。3/4 の参照の輪郭を越えない所まで、左右同じ量で止める。
3. 目の下: 目のすぐ下から頬の山までを、ふくらんだ弧でうめる（最大 2.5 mm）。
4. 鼻筋: 中央はそのまま、横を目頭へ向けて下げる（最大 3 mm）。断面が中央 99 → 目頭の横 95 mm のなだらかな山になる。
5. 鼻: 鼻先の横に 1.8 mm、小鼻を 1.2 mm 外へ（横向きの面だけ。横から見た形は変わらない）。
6. あご: 下あごの横をならし、途中を少しふくらませて、正面の輪郭を丸いカーブにする。

7. 最後に、足した量だけを Blender の Corrective Smooth でならす（変形の前の形を bind しておく。40 回）。元の顔の細かい形は残り、足した分のこぶ・波（カクカク）だけが消える。目のふちと唇は動かさない。

顔のメッシュは真ん中で左右が別々（同じ位置に点が 2 つ、つながっていない）。ならし処理は真ん中のふちを片側だけで計算するので、真ん中に折れ目ができる。
そのため、真ん中の近く（1〜6 mm）ではならしを使わず、式で決めたなめらかな形だけにする。各処理のあとで組の点を同じ位置にそろえ、最後に真ん中の法線を左右で平均する。

順番（まつ毛はこの肌の上で作り直す）:

```bash
cd tools/inkwave-modeler
M=blender/INKWAVE_CHARACTER_MASTER.blend
blender -b $M --python scripts/inkwave_lash_rebuild.py -- --restore --save $M
blender -b $M --python scripts/inkwave_face_volume.py -- --save $M
blender -b $M --python scripts/inkwave_lash_rebuild.py -- --save $M \
  --export blender/INKWAVE_CHARACTER_MASTER.glb --game blender/INKWAVE_GAME.glb
```

### 参照の正面を貼る（`paint_nose`、`paint_mouth`）

鼻の下の影の貼り物（`HEAD_skin_07`）と唇の色の貼り物（`HEAD_skin_08`）を、顔の肌そのものの写し（肌の 0.12 / 0.2 mm 上）に作り直す。
UV は正面のカメラから見たまま（projection painting）。絵は参照シートの正面から作る:

1. 参照の「まわりの肌の色」に対する比（陰・唇の色・口の線）を取る。
2. 同じ場所の、モデルの貼り物なしの正面レンダー（`analysis/face_volume/bare_front.png`）で、形がすでに暗い所を調べる。暗い所では残りの分だけを貼る（二重に暗くしない）。形が明るい所（ふくらみ）は、暗くしない。
3. その比を、モデルの肌の色にかけた色と、不透明度にする。鼻は、陰の色みを 7 割おさえる（参照の陰は肌より赤く、そのまま貼ると鼻が赤く見えた）。

鼻は、鼻の穴と鼻先の下の V だけを貼る（小鼻の上のふちの陰も貼ると、いつもの光で鼻のまわりに茶色い輪が出た。小鼻と鼻先の形は、形そのもので出す）。

貼り物は影を落とさない設定にした（半透明の貼り物が肌に影を落とすと、2 倍暗くなる）。前の鼻の穴の貼り物（`HEAD_skin_03` / `_06`）は透明にした（`--restore` で戻る）。

手順（`analysis/face_volume/tools/build.sh <master.blend> <out.blend>`）: まつ毛を戻す → 貼らずに形だけ作る（`--no-paint`）→ 素の肌を正面から描く（`tools/bake_front.py`）→ 全部作る → まつ毛を作り直す。
鼻か口の形を変えたら、`bare_front.png` を作り直す（build.sh が毎回作る）。
