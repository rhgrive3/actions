# 耳の貫通と正面左の余分な毛束の修正

統合済みの顔・髪を持つマスターを基準に修正。revision: `20260927-v6-detail`。

- 耳を横切っていた `HAIR_strand_40_Lock_right_nape_curl` を耳の後方へ移し、上の髪へ根元をつないだ。両耳と全ての毛束の三角形交差は0。修正前はこの毛束と右耳に650組の交差があった。
- 正面左の小さな独立毛束 `strand_41` を削除。
- 板状に重なっていた20枚の頭皮用毛束を整理し、頭皮に沿う一枚の既存ベース面を使用。生え際を修正し、細い流れはパック済みの法線マップで表現。前髪の主な束とツインテールを保持。
- 長いテール4本の頂点は、統合済みマスターと完全一致。

**統合にはユーザー指定の `scripts/inkwave_hair_apply.py` を使用。** 顔など髪以外の199オブジェクト・86材料を保存後に検査し、変化なし。GLBでも髪以外179メッシュの位置・法線・UVなど全属性とインデックスが完全一致。

髪の削除はライブラリ内の `HAIR.hairRemovedObjects` に明記し、適用時に検証する。リストのない欠落はエラーとして拒否。再適用後のGLBもバイト単位で一致することを検査した。

モデルは208メッシュ（髪29、髪以外179）、375,456三角形。既存の剃り込みを表す薄い `HAIR_hair` 表面は耳の付け根に重なる構造を保持している。上記の交差0は独立した毛束についての結果。

参照との毛筋・光沢などの差は残る。今回確認したのは、指摘された毛束の貫通・不要な毛束の解消、および根元の整理。
