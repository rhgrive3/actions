## 構造（参照の理解）
- **黒いもの = 尻尾の留め具（ヘアカフ）2 個。** カチューシャではない。頭の横に沿って曲がった平たい袖。
  平たく集めた髪の束が、袖の中を前から後ろへ通る。外側の面に銀のバックル 2 個。
  前・横・後ろ・斜めのどの参照でも、この形で説明できる（横で縦長の帯、後ろで細長い輪、正面でこめかみから上への帯）。
- **なでつけた層**: 頭の上と横の上部。横はカフの前の口へ流れ込む。ひし形のうすい線。
- **剃った部分**: 耳の上と後頭部の下。境目の高さは横の参照から測った（正面 1.47 → こめかみ 1.45 → 耳の上 1.43〜1.41 → カフ 1.39）。
- **尻尾**: カフの後ろから出て上へ回り、頂点（z≈1.55）を通って外へ落ちる。z≈1.28 で太い触手とライムの先の細い束に分かれる。先は水玉のあるふっくらしたヒレ（z≈1.0）。
- **頭頂と前髪**: つむじから太い平たい束が画面右（キャラの左）へ流れる。1 本は眉間へ。先はライム。

## 作り方（Blender 標準の機能）
- 毛束: Bezier 曲線（点ごとの太さ）→ Geometry Nodes `V4_clump`（法線 = 頭の中心から外、平たい楕円の断面で Curve to Mesh、
  Spline Parameter を `hair_t` として保存）。マテリアルは `hair_t` で青緑 → ライム。
- 殻: `HEAD_face` の形を写した別物体（HEAD_face は変えない）→ 縁だけ Smooth（頂点グループ）→ Shrinkwrap → Displace → Solidify（clamp あり）→ Subsurf。
- カフ: 測った外側の線 + 内側の線で輪 → 押し出し → Solidify + Bevel。バックルは bmesh の箱。
- 水玉: Voronoi（ヒレの `hair_t` 0.12 以上だけ）。

## 測り方
- カメラ: シート 5 方向は顔合わせのカメラ（`analysis/hair-rebuild/sheetcam.py`）。全身の正面・後ろ・横は検証済みの正投影カメラ（`scripts/inkwave_ref_calibration.py`）。
- カフの外側の線: 横の帯の中心線の光線 × 正面の帯マスク（ステレオ）。`tools/measure/stereo.py`, `band11.py`。
- 尻尾の道すじ: 全身の正面・後ろ・横に実寸の目盛りを描いて読んだ（`img/wg_*.png`）。
- 前髪: 正面シートの中心線 × 各点の前後位置 → 3D（`tools/build/bangs_pts.py`）。
- 剃った部分の境目: 横シートの点を 3D に戻した（`img/side_grid.png`）。

## 失敗と学び
- 最初、黒いものを頭を回るカチューシャ 1 本として作った。後ろの参照を見れば 2 個の留め具と分かる。前の記録を信じず、全部の参照を先に見る。
- 5 方向の空間削り出し（visual hull）は、カメラが前と横に偏っていて使えなかった。
- シートの q34L は他の 4 方向と帯の位置が食い違う（AI 絵）。他の 4 方向に合わせた。
