# Epic Battle Simulator

React / Vite / Three.js による商用クオリティ3D戦争シミュレーター。全5勢力・34兵種・4つの戦場・全21ステージ・戦術陣形・追従カメラ・殊勲部隊（MVP）表彰を備えたWebゲームです。

## 遊び方

- **ストーリー**: 全4章・20ステージ＋エクストラ1面の戦役モード。配置画面に敵の編成（兵種と数）が表示されるので、それを見て予算内で対抗できる部隊を組みます。予算は常に敵軍の 9 割。どのステージも単一兵種を並べるだけでは勝てず、勝利すると次のステージと新しい兵種が解放されます（戦闘中の資金回復や増援はありません）。
- **カスタム戦**: 全34兵種を使用可能。「味方配置 / 敵配置」で両軍を自由に編成でき、「全消去」でゼロから組めます（予算は各軍3000、各軍上限50体）。「戦場」ボタンで4つの戦場マップ（障害物付き）を自由に切り替えられます。
- **兵種図鑑**: 全34兵種が正面を向いて整列し、ドラッグで回り込んで造形やサイズ感を観察できます。

### 戦い方の基本 — 同じ兵種を並べても勝てない

TABS と同じく、相性表や隠し補正は一切ありません。勝敗を決めるのは下の 7 つの物理ルールだけで、兵種ごとの役割はすべてここから生まれます。兵種カードの黄色いタグが、その兵種に関係するルールです。

| ルール | 中身 | 何が起きるか |
| --- | --- | --- |
| **盾** | 正面からの矢と斬撃を割合で止める（盾兵は 65%）。爆発・背後・転倒中は防げない | 盾壁は矢に強く、爆弾・魔法・回り込みに弱い |
| **装甲** | 被ダメージから毎回一定値を引く（最低でも 3 割は通る） | 重装甲には弓や短剣の手数が効かず、弩・銃・戟の重い一撃が要る |
| **爆発・薙ぎ払い** | 範囲内の全員に当たる。爆発は中心ほど強い | 密集と安い群れに強く、散開した敵や単体の大物には無駄が多い |
| **張り付き** | 射手・術師は 6m 以内に敵が迫ると撃てず、短剣（3 ダメージ）でしか戦えない（戦車とゼウスは例外） | 弓だけの軍は斬り込まれた瞬間に崩れる。前衛で守って初めて火力になる |
| **槍衾** | 槍・戟は走ってくる敵ほど深く刺さり、突撃を止める | 騎兵・刺客・狂戦士の速さが弱点になる |
| **突撃** | 騎兵は助走した初撃が最大 1.5 倍、隊列ごと吹き飛ばす | 射手や軽歩兵の列を一撃で崩すが、再突撃には助走し直しが要る |
| **側背** | 側面・背後からの攻撃は 1.3 倍、盾も効かない | 数で囲む・足の速い兵で回り込む価値がある |

加えて、両軍は**最初の一撃が入るまで一番遅い兵に歩調を合わせて行進**します（どちらかが傷を負うか、12m まで近づくと全員が自分の速さで動き出す）。配置した陣形がそのまま接敵時の形になるので、どこに誰を置くかがそのまま戦術になります。

その結果、たとえば次のような三すくみが自然に起きます。

- 弓兵の列 → 盾のない歩兵・巨人を削り倒す → しかし盾壁には通らず、斬り込まれると全滅する
- 盾壁 → 矢を止める → しかし爆弾兵・魔術師にまとめて焼かれ、自分では敵を倒せない
- 重騎兵 → 射手と軽歩兵を蹂躙する → しかし槍衾に突っ込むと止められて死ぬ
- 巨人・トロール → 歩兵を薙ぎ払う → しかし足が遅く、弩や銃の的になる
- ロボット → 軽い攻撃を弾く → しかし投槍・弩・銃・戟には普通に倒される

### 5勢力・全34兵種

| 勢力 | 兵種 | 主な特徴 |
| --- | --- | --- |
| **王国軍 (9種)** | 槍兵 / 盾兵 / 弓兵 / 弩兵 / 剣士 / 戟兵 / 重騎兵 / 聖騎士 / 王 | 盾兵は正面 65% の壁だが攻撃力はほぼ無い。槍兵・戟兵は槍衾で突撃を止める。弩兵は装甲を貫く重い一発。重騎兵は助走つきの初撃で隊列を崩し後衛を狩る。聖騎士は周囲を回復、王は周囲 11m の味方を 30% 強化 |
| **蛮族 (9種)** | オーク戦士 / 狂戦士 / 投槍兵 / 爆弾兵 / 呪術師 / トロール / 巨人 / 海賊 / 樽爆兵 | オークはタフな力押し。狂戦士は速攻、傷つくほど加速。投槍は装甲に通り盾兵を転ばせる。爆弾は盾を無視。呪術師は範囲鈍足。トロールは再生、巨人は薙ぎ払い。海賊は装甲貫通の一発。樽爆兵は火薬樽を抱えて走り込み自爆する（倒されても爆発） |
| **神秘 (7種)** | エルフ狩人 / 修道武僧 / 影の刺客 / 魔術師 / 氷の術師 / 僧侶 / ゼウス | エルフは最長射程。武僧は手数。刺客は後衛を優先して狩る。魔術師は追尾する範囲魔法、氷の術師は範囲鈍足。僧侶は回復。ゼウスは連鎖する雷 |
| **不死 (5種)** | ゾンビ / スケルトン / 骨弓兵 / 吸血鬼 / 死霊術師 | 安く数が出る。重い単発を無駄撃ちさせる肉の壁と、斬るたびに回復する吸血鬼。死霊術師は戦闘中スケルトンを呼び続ける |
| **機械 (4種)** | 戦闘ロボット / 蒸気戦車 / 電磁砲兵 / 投石機 | 重装甲のロボットと戦車、列ごと貫く電磁砲。投石機は超長射程の大岩で隊列を吹き飛ばすが 12m 以内には撃てない |

### その他の戦闘要素

- **王の鼓舞オーラ**: 王の周囲 11m 以内の味方は与ダメージ **+30%**。
- **戦術陣形**: 移動命令時に **方陣 / 横陣 / 楔陣 / 散開** を切り替え可能。自動編成はありません。敵の編成を見て自分で組みます。
- **追従カメラとスロー再生**: 任意のユニットを選択して `V` キーまたは「追従」ボタンで英雄視点カメラにロック可能。`0.5×` から `4×` まで。
- **ノックバックと吹っ飛び物理**: 衝撃の強い攻撃（騎兵の突撃、巨人、爆弾、投槍）を受けると吹き飛び、着地後しばらく行動不能になります。転倒中は盾も効きません。
- **戦場の地形障害物**: 各章の戦場には石碑や岩柱があり、部隊は自動で迂回します。

### 操作方法

| 操作 | 動作 |
| --- | --- |
| 左クリック / ドラッグ | 配置モード時は連続配置 / 選択時は味方の選択・範囲選択 |
| 右クリック | 移動命令（陣形適用）・敵を指定して集中攻撃 / 配置モード解除 |
| 右ドラッグ / WASD・矢印 | カメラ回転 / カメラ平行移動 |
| カメラモード (C) | 左半分のドラッグで平行移動 / 右半分のドラッグで回転 |
| ホイール | カーソル位置を中心に拡大縮小 |
| ミニマップをクリック・ドラッグ | 指定地点へカメラ移動・連続追従 |
| 「範囲選択」ボタン | 1タップ/クリックで範囲選択モードに切替 |
| 1〜9 / Q・E | 兵種の選択 / 勢力タブの切り替え |
| Shift+クリック / B | 最大5体をまとめて配置（×5モード） |
| T / V | 陣形切替（方陣・横陣・楔陣・散開） / 選択部隊の追従カメラ切替 |
| Ctrl+A / ダブルクリック | 味方を全選択 |
| G / H / F / Home | 総攻撃 / 待機 / 選択部隊へ寄る / カメラリセット |
| Space / Esc / M | 戦闘開始・一時停止 / 解除・再開 / 消音切替 |

## 設計構成

- `src/game/simulation.ts`: 固定時間刻み（1/60秒）の戦闘ロジック。方向別ダメージ、正面盾軽減、王の鼓舞オーラ（+30%）、突撃ボーナス、範囲回復、実ダメージ比例の吸血、鈍足、陣形移動、個体別戦果（撃破数・与ダメージ・MVP選出）、障害物迂回ステアリング、吹っ飛び物理を管理。
- `src/game/terrain.ts` & `src/game/stages3d.ts`: 4章それぞれの地形障害物データと、空・霧・地面テクスチャ・3D障害物・装飾を含む戦場環境生成。
- `src/game/units.ts` & `src/game/rigs.ts` & `src/game/unit-renderer.ts`: 全34兵種の定義、ボーンベイク方式のキャラクター造形、および `InstancedMesh` による高速バッチ描画。
- `src/game/effects.ts`: 戦闘エフェクト。ヒットは面法線に沿って火花が飛び、血は飛沫として散って地面に染み、盾受けは白い金属片が跳ね、爆発は閃光・衝撃波・火球・煙・熾・焦げ跡が層になって広がります。武器の軌跡は刃先を追うリボンとして描かれます。
- `src/game/engine.ts` & `src/game/audio.ts`: 3Dシーン管理、専用3D弾体（矢・弩・投槍・魔弾・爆弾・火縄銃弾・重砲弾・レールガン電磁弾）と飛行トレイル、スプリング式プロシージャルモーション、戦場環境パーティクル、追従カメラ、プロシージャル戦場ドラム＆効果音。
