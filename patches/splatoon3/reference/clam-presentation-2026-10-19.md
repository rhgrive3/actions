## Current staged scope: barrier/event repair; ball and arms deferred

The candidate keeps the existing main small/power ball sizes, inventory offsets, ground/flight half-height lift and clock-driven rotation. The experimental 1.4×/1.2× scales, velocity-axis flight/drilling pose and flight-lift removal are **not connected to production RankedWorld**. Their unused helper remains as preserved calibration work and a negative test only, not an accepted runtime feature. The old main flight lift is retained explicitly as baseline behavior, not introduced as a new corrective offset or asserted physically correct. No projectile position, collision radius or launch velocity is changed.

The eight-instance barrier shell splits only on an observed closed→open edge. Late joining an already open goal does not invent a break. Its .55-second fade is a local readability duration; the authoritative 1.2-second pending break and scoring remain unchanged. Ordinary ball expiry still disappears; it is not represented as an unsupported ball fracture. Reusable field markers are bounded to 48 under lifecycle churn.

Clam-specific arm presentation is deferred for all families. Successful events do not trigger a throw action, advance pose clocks, evaluate an extra pose, solve an extra limb or change either wrist. The rejected arm prototype had a new .297–.349 world-unit event-frame hand jump compared with main. The current stage removes its event/owner integration rather than relaxing the contact gate. Main weapon muzzles, ordinary bomb paths and source-pose history retain the main behavior. Preparatory hand raising, right-upper release and hold/release timing remain unfinished. No speculative physical delay, shot lock, ball offset, muzzle getter override or body/hair edit is used.

### Why the ball calibration is also held

The exact native `8a9036623038f051fbdeef1f5057a5b3950ccee6` rear-input receipts show head-center containment in the calibrated faceted power shell at release and +16.7 ms, with minimum interior plane distances .13258 and .08039 world units. This is not merely projected occlusion. At +33.3 ms the head center is outside; this alone does not prove the entire head is disjoint.

A read-only factorial reconstruction uses the same recorded head/ball positions, the exact existing 216 shell triangles, the committed pose functions and deterministic harness clock (4.67 s at release). Signed shell-plane distance at release is +.04348 for the old main transform (head center outside), −.00540 for only the scale increase, −.08955 for only removing the flight lift, −.14112 for only changing the rotation, and −.13258 for all three changes. Each new factor can therefore cause added center containment; reverting scale alone is insufficient. This calculation does not measure retail dimensions or certify the old main head surface as intersection-free. Correct preparation and release placement require further evidence and a separate design, so all ball display changes are held together rather than making carry/flight scales disagree.

## Event contract repair (separate from visuals)

Previously `_event('clam-throw', {kind:'power', ...})` reached `RankedEngine.event` as `{kind, ...data}`, so payload `kind` replaced the event discriminator. All clam calls now name that payload `clamKind`; canonical event names remain intact. This restores canonical throw event delivery and the existing `clam-score` UI notification; no new arm consumer is installed. Entity/snapshot `kind` remains unchanged. Consumer audit includes install, UI, combat, bots, minimap and network. Only `clam-paint` paints; score presentation does not score again. Wire admission/sequence checks and authoritative snapshots are unchanged. Old autonomy test counters are updated to canonical event names.

Release measurements now use the closest point on 216 world-transformed shell triangles and the minimum shell world Y; the earlier `rule.pos − halfHeight` proxy is retired because it was not a rotated mesh boundary, especially with the legacy flight lift. These unsigned measurements do not accept a grip. Before means five main3839 runtime modules overlaid on the same emitted build, **not** a full historical application build.
- A field marker cache retains at most 48 inactive/reusable markers under tested lifecycle churn; Each barrier uses eight instances and fixed geometry/material. Transparent DoubleSide explicitly requests forceSinglePass; actual hidden/visible/forced-two-pass draw counts (0/1/2) and front/oblique/back transparency remain native QA gates, rather than being inferred solely from mesh count; effects allocate no event particle systems.

Local native-browser execution is not available in this environment. Shared GitHub native QA is the visual acceptance route. CPU success alone does not certify visual equivalence, exact retail timing, size, motion, full online play or native-browser performance.
