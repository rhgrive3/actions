## Defensible correction and limits

The earliest implementation divergence is `_buildPose` passing `danceT + danceOfs` into `_poseDance` for a selected action. `setDance` resets the action's native elapsed clock, but seed-based `danceOfs` (up to 2.3 s) defeats that onset. The three result routines also wrap their action time. The patch removes the offset **from the victory pose argument only** and caps that argument at an existing ending pose. It does not reset, replace or advance the native clock. Durations and ending choices are explicitly visual calibration. The source clip motivates this sequence lifecycle; it does not verify these custom curves, repeated side hops, weapon spins, result-screen behavior or a named Nintendo emote.

When a victory fades out, native `setDance(null)` zeroes `danceT`, which otherwise restarts the outgoing pose during the fade. When changing into a new dance, the native crossfade otherwise uses the new dance's seed-selected variant. The patch remembers only the outgoing presentation selection/time, evaluates the existing native routine, and restores the current selection immediately. It preserves explicit `danceT=t0` and does not create another animation clock.

Gameplay interruptions cancel supported presentation dances and their outgoing blend before native form/fire/sub/weapon/action poses apply. Reset/death use actual Actor hooks. `jump`, `land`, `admire`, `hairflip` and `wink` do not cancel, because the native showcase uses them during presentation. This cancellation is an **engine correctness fix**, not an experimentally verified Nintendo cancel window. No actor input, position, velocity, ink, HP, runner state, collision, projectile, fuse, gameplay clock or resource balance is written by this module. Clearing native presentation uses native `setDance(null)` and clears only stale visual blend selection/weight. An opt-out `s3EmotesMotionEnabled=false` retains the pre-patch presentation for comparison.

No additional GPU resources, replacement rigs, synthetic target bones or new art are allocated. Native facial life, breathing, hair physics, IK and weapons still execute. Exact Nintendo joint trajectories, species/weapon/gear/emote variants, loss-screen composition and networking synchronization remain unverified. Indefinite endpoint hold is an INKWAVE policy beyond the finite observed official hold interval. Parent browser rendering and console comparisons must remain separately labelled.
