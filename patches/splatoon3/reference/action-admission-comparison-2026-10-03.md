## Shared connection contract

`runtime/action-admission.mjs` exports `specialMotionAllowsAction`, `bombMotionAllowsAction`, `dualiesMotionLock`, and `dualiesMotionAllowsFootPlant`. It imports only the Special module's public helpers, which have no engine imports. Prototype `Symbol.for` registries expose the original installed states across realms. Helpers neither create state nor call native owner discovery, move the world, query Physics, or advance clocks. Disabled, disposed, detached and incomplete-state calls retain the supplied native decision.

Special action admission excludes the actual mapped Storm deployment/recovery. The already integrated `specialMotionAllowsFootPlant` keeps its existing Storm-permitted foot policy. A general action gate must not substitute the foot-only rule alone.

No new installer or native export is needed. Existing `installDualiesMotion` prepares and publishes its state before calling the earlier/native `_updateStates`, then refreshes it after those hooks. Parent must add the exact unique Character import and three substitutions in `review-admission/integration-handoff.json`: wrap native lock RHS before damping; wrap only the native Dodge foot conjunction; wrap only Walk's Dodge conjunction. Preserve all other foot/gait criteria and native IK/contact equations.

Until parent integrates, `tests/action-admission.test.mjs` explicitly applies those exact substitutions in memory over the actual production adapter and complete installer. It fails on missing/duplicate anchors. Its optional legacy mode reproduced the original pipeline gap. This supplemental test does **not** certify the current production adapter/Walk activation. The other three owned tests run the current production adapter unchanged.
