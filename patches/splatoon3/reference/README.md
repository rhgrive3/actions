# 参照数値と確認状態

参照版はスプラトゥーン3 Ver.11.3.0。公式情報は [任天堂の更新履歴](https://support.nintendo.com/jp/switch/software_support/av5ja/1130.html)、機能は [イカロール・イカノボリの説明](https://www.nintendo.com/jp/topics/article/af825de6-16d5-4653-ba00-a7e775cc54b9)、[ブキの説明](https://www.nintendo.com/jp/character/splatoon/en/fashion/index.html)、[フローの公式説明](https://www.nintendo.com/jp/switch/av5ja/report/index.html) と比較した。

詳細なパラメーターは、抽出を公開している本人の [Leanny/splat3](https://github.com/Leanny/splat3/tree/7280ff9cde8bb1c5dcef46c700c326471584d2e6/data/parameter/1130) と [ギア効果計算](https://leanny.github.io/splat3/ability.html) を用いた。抽出資料は任天堂が公布した仕様書とは区別する。

`curated-numbers.json` に一次資料のファイル URL、SHA-256、JSON ポインター、抽出値を記録した。欠けている既定値は未知として記録し、別のバージョン・攻略サイトの値で穴埋めしていない。

| 項目 | 抽出値・公式値 | このパッチの扱い |
| --- | --- | --- |
| 通常ヒト速度、通常イカ速度の 0 AP 値 | 0.096、0.192 | 60 倍して 5.76、11.52。距離単位の実機校正は未実施 |
| シューターの威力 | 360→180、8→40 F | HP を 10 分の 1 とする換算で 36→18。弾齢で減衰 |
| シューターのインク | 0.0092 | 100 ポイントのタンクで 0.92 |
| マニューバー射撃 | 5 F、スライド後 4 F | 60 Hz 換算。後隙を終えた静止射撃も維持する |
| チャージャー保持 | 75 F | 1.25 秒。保持中の発射と期限切れを試験する |
| チャージャー威力 | 400、800、1600 | 部分 40→80、フル 160。フルは壁まで敵を貫通する |
| ローラー振り出し | 横 21 F、縦 26 F | 入力開始時に選択し、着地しても選択を保持する |
| スピナー | 第1段階 48 F・射撃 80 F、第2段階 72 F・射撃 160 F、最大消費 0.225 | 第2段階を累積時間と解釈する。部分チャージと時間の解釈は要実機確認 |
| イカノボリのギア別溜め時間 | 0 AP 45 F、中間 18 F、最大 5 F | 効果曲線の基点。射出速度・防御は暫定値 |
| インク回復基点 | イカ 180 F、ヒト 600 F | 空から満タンまで 3 秒、10 秒。射撃後待ち時間の既定値は別途未確認 |
| フローの継続 | 30 秒 | 公式値。発動ポイント、延長秒数、倍率は暫定値 |

ギアの抽出配列は **High, Mid, Low** の順であり、設定では 0 AP、中間、最大の順に並べ替えている。計算は `p = min(100, 3.3 AP − 0.027 AP²) / 100` と、抽出した中間値を通るべき乗曲線を使う。装備は各部位のメイン 10 AP、追加 3 AP×3、合計最大 57 AP。

時間は F÷60、毎フレーム速度は×60、毎フレーム重力は×3600、タンク比率は×100 と換算する。ただし、この換算が INKWAVE のキャラクターと地形の縮尺を本家に一致させる証拠にはならない。射程の UI 値も弾の制動や当たり判定の測定値と同一視しない。

各設定の対応は `profile.json.bindings`、全数値の状態は `numeric-status.json`、ロジックに関する残課題は `profile.json.calibration.unverified` を参照する。原フィールド `OpInk_ArmorHP` は意味を確定できていないため、HP や猶予フレームとして実装することは保留した。

[非ローラー・ギア・Flow の調査記録](weapons-gear-flow-audit-2026-10-02.md) に、担当項目ごとの出典、修正、実コード回帰、残課題と次の実機測定を記載した。バレルスピナーの射撃移動ギア専用曲線とブラスターのアク強専用曲線を接続した。Flowは [公式11.0.0の説明](https://support.nintendo.com/jp/switch/software_support/av5ja/1100.html) に合わせ、相手を倒す時に発動判定し、足元塗りは発動/延長時だけにした。発動ポイント・延長量・強化AP・倍率は確認できておらず、数値一致の主張はしない。
