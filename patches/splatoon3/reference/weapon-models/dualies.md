# ダブルリール系（dualies）の武器モデル: 参照 Splatoon 3 Ver.11.3.0

実装: `patches/splatoon3/runtime/weapon-models/dualies.mjs`

## 方法と制約

- 参照は公式の 3D レンダー（`<id>.3d.png`、透過、銃口は右）。IoU はこの画像のアルファ輪郭と、`iterate.sh` の側面描画の輪郭を比べる。
- 参照画像は 2 丁を斜めに重ねた 3/4 像で、モデルは仕様どおり 1 丁のみ。そのため IoU には構造上の上限があり、縦横比（参照の幅/高さ 0.92〜1.47）も 1 丁では完全には合わない。
- スケールは実寸を計測していない。グリップは `pistolGrip`（柄 0.11 m、原点中心）を基準に、本体は画像から見た比率で m 単位に配置した。
- 色は `<id>.3d.png` を基準にした。回転映像（`rotsheets/`）が別キット（alt-kits）の武器は形状のみ参照した。
- グリップ: `gripR` / `gripL` は `GRIP_PISTOL` のまま変更していない。ホールド（`hold`）と回避動作は変更していない。
- 可動部: `slide`、`slideInk`、`led` は native チャンネルとして残した（実物に前後に動く上部スライドは見当たらないため非表示）。`trigger` は表示。銃口 `muzzle` は各ノズルの先端に置いた。
- 2026-10-11 第2段: 6種すべてを Opus で作り直した（押し出し板1枚ではなく、旋盤体・箱・管・複数の殻の組み合わせ）。回転映像で team ink 色に変わる部位を ink に割り当てた。

## Dapple Dualies / スパッタリー（第3段、2026-10-11 作り直し）

- 内部モデル名 `Wmn_Maneuver_Short`。出典: Inkipedia「S3 Dapple Dualies model rotating.mp4」（2丁の回転映像、12 秒で1周）、「S3 Dapple Dualies Promotional 3D Render.jpg」（左側面の2丁）、`s3-maneuver-short.3d.png`。主参照は回転映像 t=6.0 s の左の1丁（右側面）、t=0 の右の1丁（歯ブラシ手前）、t≈9.0（前右 3/4）、t≈10.5（正面）、t≈4.5（背面）。
- 旧版（薄い C 形の押し出し板＋スキッド）は削除し、全部品を立体で作り直した。主な構成:
  - フレーム: グリップ上の窓2つのブロック、前下がりに太く弧を描いてノズルに届く上部、ノズル下に垂れる顎の突起を1つの立体にした（独自の丸縁押し出し `dappleRoundSlab`: 側面は平ら、全周の縁は半径 7.5 mm の四分円、窓は貫通穴で縁も丸い）。厚みは 39 mm、ノズル周り 43 mm、顎 34 mm（正面・背面映像のノズル径との比から推定）。トリガー前の C 形の開口は指の入る空間として残した。
  - 両側面: 暗い台座に載った ink のカプセル帯（映像でティール＝team ink）、白い三角ロゴと文字帯（print）、後上部の銀ねじ、顎の穴2つ。
  - ノズル: 黒いゴムのノブ（8 本の溝山）、銀の座金、奥行き 13 mm の内向きの銃口穴。中心 y = 0.0155 m（トリガーの高さ）。
  - グリップ: 側面輪郭からの丸断面の立体（幅 30 mm、前後 約 60 mm）、フレーム後ろに立ち上がる黒いビーバーテール、灰色の側面パッド、ねじ、底の座。トリガーは曲がった黒い板（`trigger` 部品、`TRIGGER_PIVOT`）。
  - 上面: 前に 24° 傾いた黒いバルブ軸、黒いカラー、溝付きの銀キャップ。
  - 後方: 上部から後ろ外側へ上がる暗い鋼の弓腕（根元のクランプ、先端の鉤）、先端から歯ブラシの頭へ白い糸。
  - 足: グリップ下の台（前に下向きの突起）、後ろ外側へ曲がって歯ブラシを受ける太い腕（上面の溝、受け口のブロック）。
  - 歯ブラシ: 後ろへ約 45° 傾いた白い柄（水色の背筋、青い滑り止め 5 本）、幅広の頭、後ろ下向きの毛束 7 列（ink）。
- スケール: フレーム下面から足の上面までの見えるグリップ長を 0.09 m とし、回転映像 t=6.0 の側面で 1 mm/px。全長 約 0.43 m（歯ブラシ込み）、高さ 0.27 m、幅 0.15 m（歯ブラシの横ずれ込み）。
- 歯ブラシの横位置: 2丁は鏡像の組（片方は +X、片方は −X に歯ブラシ）。INKWAVE は両手に同じ形状を持たせ、左手用を鏡像にできないため、右手用（持ち手の外側 = −X）を採用した。左手の1丁では歯ブラシが内側（胸の前）に来て、射撃姿勢で胴体に近づく。横ずれ量 0.09 m は正面映像（約 0.06 m）と背面映像（約 0.12 m）の中間（遠近の影響があり画像から推定）。
- 銃口ソケット: 旧 (0, 0.066, 0.13) → 新 (0, 0.0155, 0.201)（ノズル穴の出口）。
- 色: プロモ画像から採色（フレーム #86184d、グリップ #26262a、パッド #505053、銀 #b9bab6、歯ブラシ 白 #e8e8e6／青 #2f62c4／水色 #5c9ae0）。
- 可動部: `trigger` のみ表示して動かす。`slide` / `slideInk` / `led` は native チャンネルとして残し非表示（実物に前後に動く部品は映像で見えない）。`d.dual = true`、`gripR = gripL = GRIP_PISTOL`、`hold` は変更なし。
- 三角形数 約 11,200（body 約 10,200、ink 約 800）。
- 輪郭 IoU: 2丁重ね像（3d.png）との比較は 0.415 → 0.336（構図が違うため参考値）。回転映像 t=6.0 の1丁の側面と、同じ 1 mm/px のモデル空間で比べた IoU は 0.376 → 0.663。

| 歯ブラシの横ずれ量（0.09 m）とフレームの厚み | 画像から推定（正面・背面映像の遠近差あり） |
| 実寸（見えるグリップ長 0.09 m の仮定） | 未確認（実機計測が必要） |
| 側面の文字・ロゴは単純な形の print で、文字そのものは再現していない | 画像から推定 |
| 窓の奥のフレーム内部、フレームの細かな段差（ロゴ面の縁、窓まわりの面取り）は省略 | 画像から推定 |

## Glooga Dualies / ケルビン525（第3段、2026-10-12 作り直し）

- 内部モデル名 `Wmn_Maneuver_Gallon`。出典: Inkipedia「S3 Glooga Dualies Deco model rotating.mp4」（Deco キットの2丁の回転映像、12 秒で1周。形状は同じで色だけ違う）、「S3 Glooga Dualies Deco Promotional 3D Render.png」（前左 3/4 の2丁）、`s3-maneuver-gallon.3d.png`（本体キットの色）、「S2 Weapon Main Glooga Dualies 3D.png」（S2 の回転連番、色の補助）。主参照は回転映像 t≈3.3 s の左側面（1丁だけが見える。左右反転して右側面として使用）、t≈9.3（右側面）、t=0（正面）、t=6（背面）、t≈1.5 / 4.5 / 7.5 / 10.5（3/4）。
- 旧版（側面輪郭の押し出し板、点線、針金の輪2つ）は削除し、全部品を立体で作り直した。主な構成:
  - 本体: 角を丸めた箱（側面輪郭から作る丸縁の押し出し `dappleRoundSlab` を流用し、輪郭は角だけを丸める `gloogaPoly` で作る）。幅 65 mm、長さ 160 mm、高さ 87 mm。後下部はグリップ上へ下がり、前下部は 1.5 mm 張り出す段。側面に斜めのスロット 6 本（貫通）。後ろ 3 本からは内部のインクタンク（ink）、前 3 本からは赤い内部が見える。
  - 本体側面の印刷と浮き彫り: 横スリットのグリル 8 本×2 列、浮き彫りの文字板、警告三角。
  - 本体下の赤い帯（トリガーの付け根、前脚の受け）。トリガーは帯から下がる赤い鉤形の板（`trigger` 部品、ヒンジはトリガー上端 (0, 0.044, 0.047)）。
  - 脚: 青いグリップ脚（後ろへ約 7° 傾く）と前脚（約 23° 傾く）。脚の下を赤い足ブロックがつなぎ、両側面に白いラベル。手はグリップ脚を握り、指は2本の脚の間に入る。
  - 前方: ローレットの銀リング、穴 8 個の銀のドーム形ノズル、中心は ink。ノズルの左右から下へ回る針金ハンガー（下端の鉤は帯の下に掛かり、上は M 字にノズルの上で曲がる）。
  - 後方: ガラスのキャニスター（ink）、ゴムのパッキン、銀の円盤 3 枚（後端はローレットの外周と後面のリング、中心のボス）、後面から上に出る暗色のタブ。下には板 2 枚のクランプ、本体へ届くねじ棒、8 本溝の黒いつまみ（+X 側）。
  - ホース: 本体側面の後下部から上がり、キャニスターの上を回ってタブに入る（−X 側）。
- ink 部位: 回転映像で桃色（この映像の team 色）、3d.png で白（S3 の 3D レンダーでは ink 部位が白く出る。Dapple Dualies の帯・毛束と同じ）になる部位、つまりキャニスターのガラス・スロット奥のタンク・ノズル中心を ink にした。第2段では本体と脚を ink にしていたが、黄色は Deco キットの塗装（青い山形模様・警告表示付き）で、3d.png の青も本体キットの色と判断して改めた（画像から推定）。
- 2丁の組: 回転映像の2丁はホースが互いに外側に来る鏡像の組。INKWAVE は両手に同じ形状を持たせるため、右手用（ホースが持ち手の外側 = −X、クランプのねじ棒が +X）を採用した。左手の1丁ではホースが内側（2丁の間）に来る。
- スケール: 帯の下面から足の上面までの見えるグリップ脚 0.09 m（t≈3.3 の側面で 115 px → 0.00078 m/px）。全長 0.31 m（つまみ〜針金の先）、高さ 0.27 m（足〜針金の頂点）、幅 0.089 m（ホース込み）。
- 銃口ソケット: 旧 (0, 0.07, 0.162) → 新 (0, 0.098, 0.1652)（ノズル面の中心）。
- 色: 3d.png から採色（本体・脚 #2a3cb4、帯・トリガー・足 #a81e18、銀 #c4c6c8、ホース #dcc8b6、つまみ #2c2c2e）。
- 可動部: `trigger` のみ表示して動かす。`slide` / `slideInk` / `led` は native チャンネルとして残し非表示。`d.dual = true`、`gripR = gripL = GRIP_PISTOL`、`hold` は変更なし。
- 三角形数 約 10,600（body 約 9,800、ink 約 370、トリガー 約 440）。
- 輪郭 IoU: 2丁重ね像（3d.png）との比較は 0.421 → 0.529（参考値）。回転映像 t≈3.3 の1丁の側面（左右反転）と同じ 0.00078 m/px のモデル空間で比べた IoU は 0.477 → 0.712。

## 未確認（実機計測または原典確認が必要）

1. 持ち方: 両手に同じモデルを `GRIP_PISTOL` で持たせ、実 Actor で保持・射撃を確認した（ロジック単独とブラウザ描画）。本家実機の手の位置・回避中の持ち替えとの比較は未実施。
2. 寸法: 実機の寸法は未計測。モデル寸法は画像比率からの推定。
3. ink 部位: どの部位が実機で team ink か（回転映像の黄/桃の色が team ink か別キットかの区別を含む）は未確認。
4. 可動部: 第2段では上部の slide 反動を非表示にし、トリガーのみ動かす。実機で射撃時に動く部品があるかは未確認。
5. IoU の上限: 参照は 2 丁の重なり像、モデルは 1 丁。縦横比の差は構造上の限界で、実機比較の代用にはならない。
6. ファイル名: Inkipedia の正確なファイル名は作業ログに残っていない。
