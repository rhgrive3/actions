# フデ系モデル・持ち方・モーション（参照 Ver.11.3.0）

対象: `runtime/weapon-models/brushes.mjs`。カタログではフデの見た目系統が `roller` のため、従来はスプラローラーとして描画されていた。公式 3D レンダー、回転動画 `S3 Inkbrush / Octobrush / Painbrush model rotating.mp4`、`S3 Octobrush promo image.jpg`、`S3 Painbrush promo JP.jpg`・`S3 Painbrush flinging ink.png`、`S3 Painbrush demonstration.mp4`（Inkipedia）を参照した。Wii U ソースバンクの `Attack_Brush00` / `Attack_Brush01`（各 30F）を手・weapon ボーンでサンプリングし、左右交互に約 8F で横断→約 10F 保持→戻り、という形をスイングの形の参考にした（値の移植ではない）。

## 共通

- 座標: 柄 +Z、ヘッドの広い面は X–Z 平面（幅 X）。ドラムは無いので `drop:['drum']`、中折れも無いので `d.fold = null`。roller.mjs の床合わせは `d.drum` が null だと境界が非有限になり自然に無効（確認済み）。
- ヘッド幅: `BodyParam.PaintParam.WidthHalfMax`（0.6 / 0.9 / 1.3）を 1.2/2.8 m で換算（手持ちグリップ ≈ 0.11 m/手 の規則と整合）。**塗り幅を代理値とした推定**。
- インク部: 毛先（チーム色）。パブロはボトル、ホクサイは彫刻のガラス玉と細管もインク。
- 可動部: 毛（`head` / `headInk` 独自チャンネル）がスイング中は振りの逆へしなり、ドラッグ中は後ろへ寝る（`animate`）。
- モーション（`FAMILY_TRIGGER` + `FAMILY_POSE`）: `shoot` を消費してローラーのフリックを止める。カタログ Runner の `swingCount` の増加ごとに 1 回の横スイング（前方を右→左、次は左→右と交互、0.7 s 空くと右から）。スイング時間 6/9/12F（連打間隔 7/11/14F 内）、端で 0.16 s 保持、0.22 s で構えへ戻る。フィンセントの初回 23F は右肩の上へ振りかぶる。長押しの転がし（Runner.rolling）は両手で前方の床にヘッドを当てて押す。床との接触は前フレームの実描画の毛先高さで柄ピッチを補正。待機は片手で体の右下に提げる。
