# スピナー モデル記録 — Splatoon 3 Ver.11.3.0

実装: `patches/splatoon3/runtime/weapon-models/splatlings.mjs`（手続き的ジオメトリ。本家メッシュは含まない）。2026-10-11 に Opus で全6種を作り直し。

- 原典: Inkipedia「S3 Weapon Main <名前>.png」（本家3Dレンダー）と回転動画の12方向シート（別キットは `alt-kits.json`）。内部モデル名は Leanny/splat3（7280ff9）`ActorInfo`。
- 回転動画でチーム色に写る部分をインク（`ink`）にした（バレルスピナーのタンク、スプラスピナーの球形タンク、クーゲル・イグザミナーのスリーブ内部、ノーチラスの窓）。透明部材は描けないため、スリーブはリングと桟の骨組みで表し中のインクを見せている。
- ネイティブのチャンネルを保持: `trigger`、`barrels`（局所Z軸で回転する銃身群）、充電コイル `d.glow`（チャージ中の様子を他プレイヤーに見せるため）。グリップはネイティブ（右手ピストル、左手 (0, 0, 0.1515) の縦フォアグリップ）。銃口は銃身群の前端。
- 金属色の大きな面は艶あり塗装（satin）で描画（metal 指定は比較環境で黒く写るため）。
