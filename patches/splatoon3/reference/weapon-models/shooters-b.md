## 2026-10-12 作り直し: プライムシューター / ジェットスイーパー

初版（参照3Dレンダーの輪郭を押し出し板でなぞったもの）を破棄し、立体（lathe・面取りロフト・管・角丸押し出し）で一から作成した。寸法はメートル直書き。

- **原典**: 形状比率は公式回転動画「S3 Splattershot Pro FRZ-N model rotating.mp4」「S3 Jet Squelcher COB-R model rotating.mp4」（同形状の別キット）の真横フレーム（t=1.0 s。銃身／竿が水平になるよう 13.5°／14° 回転補正）から読んだ。配色とインク部位は「S3 Weapon Main Splattershot Pro.png」「S3 Weapon Main Jet Squelcher.png」。持ち方は Inkipedia の S2 プロモ画像（S2 Splattershot Pro promo 1、S2 Custom Jet Squelcher promo 1/2）と S3 Forge Splattershot Pro / Custom Jet Squelcher の 3D プロモ。
- **縮尺**: 全長はグリップ基準の旧縮尺を引き継ぎ、プライム ≈ 0.75 m、ジェット ≈ 0.83 m（画像からの推定。本家実寸は未確認）。
- **インク部位**: プライムはタンク（本家3Dレンダーで淡灰、S3 Forge プロモで緑＝チーム色、S2 で紫）を `can`（インク、射撃ごとに脈動）。ジェットはノズルスリーブ（3Dレンダーで淡いミント、S3 Custom プロモで黄色）を静的インク。どちらも画像からの推定。
