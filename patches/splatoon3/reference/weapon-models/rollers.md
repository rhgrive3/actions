# ローラー系モデル・持ち方・モーション（参照 Ver.11.3.0）

対象: `runtime/weapon-models/rollers.mjs`。形状は Inkipedia の公式 3D レンダー（`S3 Weapon Main <Name> 3D` 相当の 400px 画像）、回転動画 `S3 <Name> model rotating.mp4`（カーボンは `S3 Carbon Roller Deco model rotating.mp4`、ヴァリアブルは `S3 Foil Flingza Roller model rotating.mp4`）、スプラローラーは `S3 Splat Roller Promotional 3D Render.jpg` と `S3 Splat Roller promo image.jpg`（ゲーム画面）から読み取った。内部モデル名は Leanny/splat3 ActorInfo。

## 共通の決め方

- 座標: 柄は右手から +Z、ドラム軸は X、フレームは X–Z 平面（公式レンダーは柄・フレーム・ドラムが同一平面にあり、その面を +Y 側から見た図。上面ビューで比較した）。持ち手の右 = −X。
- ドラム幅: 11.3.0 パラメータ `BodyParam.PaintParam.WidthHalfMax` を代理値に使い、スプラローラー 2.8 → 1.5 m の比で換算（`drumWidth()`）。1.5 m は既存 `roller.test` の比率帯（ドラム長 > 背丈×0.8、直径 0.22〜0.32×背丈）に入る値。直径・柄などはレンダー上の比から。**ドラム幅の代理値は塗り幅であり、本家のメッシュ寸法ではない（画像から推定）**。
- 右手グリップはネイティブ（roller.mjs の姿勢校正の基準）を維持。左手は各柄の上に置き、実 Actor/Runner/Character で握り誤差を確認して決めた。
- 中折れ（roller-fold.mjs）の支点は各モデルのヒンジ位置へ移した。回転軸は roller-fold.mjs が X 固定。
- カタログ版ローラー（カーボン・ダイナモ・ヴァリアブル・ワイド）はカタログ Runner が振りを担当し、Character 側の攻撃記録 `s3RollerFlick` が作られないため振りモーションが一切出ていなかった。`FAMILY_POSE` が Runner の時計（`swingCount`・`cooldown`・`pending`）を読むだけで同形式の記録を作り、スプラローラーの校正済み横振り／縦振り・中折れ・ドラム放出回転を各ブキの `WeaponWideSwingParam / WeaponVerticalSwingParam.SwingFrame` で再生する（カーボン 10F、ダイナモ 45F、ヴァリアブル 19F、ワイド 18F）。転がしは柄のピッチを各ドラムの到達距離と半径から補正し、腕を縮めずに接地させる。リモート側は `shoot` 受信時点（放出時）から再生。

## 未確認・残る差

- 柄とドラムの長さ比（公式より柄が短い）。ドラム比率帯（既存テスト）と手の校正を優先した。
- 中折れの回転軸: 公式モデルのヒンジボルトは柄平面の法線（Y）方向に見えるが、roller-fold.mjs は X 軸固定。ヴァリアブルの縦振りの伸び量 0.16 m は画像から推定（未確認：実機計測が必要）。
- ブキ別の持ち方（ダイナモの重さ、カーボンの軽さ）は公開映像で確認できず、姿勢はスプラローラー校正を共用。カーボンは柄が短いため両手とも D グリップを握る。
- ギャラリー（歩行後すぐ転がし）で左手誤差がカタログ版で 0.014〜0.027 m 出る過渡がある（テストの 150 フレーム条件では 0.008 未満）。
- 回転・振り・転がしの本家フレーム値との一致は未確認（実機計測が必要）。
