- 対象: スプラシューター / ボールドマーカー / わかばシューター / シャープマーカー / プロモデラーMG / .52ガロン / N-ZAP85
  （残り7種のシューターは `shooters-b.md`）
- 実装: `patches/splatoon3/runtime/weapon-models/shooters.mjs`（`MODELS` の7エントリ）
- 内部モデル名: Leanny/splat3 ActorInfo（commit 7280ff9）の Fmdb 名
- 画像・動画は参照のみで、リポジトリには含めない。形状はすべて手続き的ジオメトリ。

## 武器ごとの記録

### スプラシューター（`shooter`, Wmn_Shooter_Normal / NormalT / NormalB）
- 構造: 紫のピストルフレーム、上に横置きのインクタンク（カプセル、インク）、後端に青い円錐キャップ
  （縦リブ、後ろ上がり）、黄色の平たいストラップ（タンク後部の襟、後ろ向きに立つキャリーループ、
  両側面のS字バンド）、黄色のフォアエンド（指溝4本、黒いリンク）、黄色の前板、黄色のラッパ型ノズルと青い先端。
- 変更（見本からの改良）:
  - ストラップを丸パイプから平たい帯（幅約 1.05 cm、厚さ 2.6 mm）に変更。S字は「後部下 → 35% で上面 →
    65% で下面 → 下側面をフォアエンドへ」（動画 t=8 秒の真横）。
  - キャリーループを側面向き（X法線）から後ろ向き（Z法線）の縦長の輪に修正（動画 t=5 秒の真後ろで正面に見える）。
  - トリガーを紫から黄色に修正（動画 t=8 秒）。キャップを縦リブ付きの円錐にし、後ろ上がりを 0.22 rad に。
  - フォアエンドの腹を丸め、リンクを2本の棒で表現。
- 可動部: `can`（タンク、在来の1発ごとの膨らみ）、`trigger`（在来）。
- 持ち方: 在来シューターの持ち方のまま。左手はフォアエンド下（S3 プロモ画像で左手のひらがフォアエンドの下）。
- 銃口: ノズル先端 (0, 0.074, 0.250)。
- IoU: 0.541（改修前の汎用モデル）→ 0.814（見本）→ 0.825。

### ボールドマーカー（`s3-shooter-short`, Wmn_Shooter_Short）
- 構造: 黒い後部チューブ（インク色の3本ストライプ、丸い端）、上ブロック付きの襟、透明インクチューブ（`can`）、
  黒い前スリーブ、ねじ山付きネック、上下に金色の重りが付いた縦のクロスバー、ゲージを抱える金色のC型ブラケット、
  グレーの平たいレバー（後端ヒンジから上を弧で越える）、黒いグリップとリング状トリガーガード、大きな鋼製ファネル。
- 縮尺: レンダーのグリップ 78 px = 0.085 m。前方（グリップより前）はレンダーで短縮されているため、
  動画の真横（ゲージ／クロスバー／ファネル縁がグリップ長の 1.58 / 2.5 / 3.7 倍前方、レンダーでは 1.09 / 1.9 / 2.97 倍）
  に合わせて z を 1.2 倍にした。全長 0.42 m、ファネル直径 0.196 m。
- インク: チューブとストライプ（レンダーで白、Neo の動画で水色）。グレーのレバーは無印のレンダーで銀なので本体色。
- 可動部: `can`（インクチューブ）、`trigger`、`needle`（ゲージの針。射撃中は振れ、1発ごとに跳ねて戻る。独自 `animate`）。
- 持ち方: 在来。左手は金色ブラケットの下側（S2 プロモで左手がブラケット下）。
- 銃口: ファネルの口 (0, 0.070, 0.304)。
- IoU: 0.347 → 0.604。

### シャープマーカー（`s3-shooter-precision`, Wmn_Shooter_Precision）
- ボールドと共通のフレーム（ボールドの動画を共通部の真横の根拠にし、同じ 1.2 倍を適用）。前端は金色のカラー、
  黒い円錐、細い鋼の針状ノズル。
- 参照: 無印の動画はないが、`File:S3 Splash-o-Matic Neo model rotating.mp4` があった。カメラが近く透視が強いため、
  形の確認だけに使った。
- 可動部・インク・持ち方はボールドと同じ。銃口: 針の先 (0, 0.079, 0.337)。
- IoU: 0.396 → 0.669。

### わかばシューター（`s3-shooter-first`, Wmn_Shooter_First）
- 構造: 箱型のシェル全体が半透明のインクタンク（動画でチームカラー）。後部（2段）から前方の四角いブロックへ
  縦横とも広がる。側面に浮き出たレール、フレア部に縦リブ、はしご状の溝があるグリップ。
  紫の給水キャップ（細長いレバー付き）、照門の間の紫の玉、前面の白いリングと紫のドーム型ノズル、紫のトリガー。
- 縮尺: グリップ 86 px = 0.085 m。前面ブロックは約 0.15 m 角。
- 可動部: `can` = シェル全体。在来の膨らみ（7%）は全体に掛かると大きすぎるため、`animate` で 22% に縮めた（約 1.5%）。
  `trigger`（紫）。
- 持ち方: 在来。左手は前方ブロックの下（S2 プロモで左手が前方下）。
- 銃口: ドームの先端 (0, 0.085, 0.239)。
- IoU: 0.511 → 0.858。

### プロモデラーMG（`s3-shooter-blaze`, Wmn_Shooter_Blaze）
- 構造: 重力式エアブラシ。銀のボディ管、後部のローレット付きホイール、ホースニップル、前方のローレットリング
  と大きなエアキャップ、円錐の先端と穴。上に前へ少し傾いた開口カップ（ローレット付きの縁）、
  ボディ下のエア継手（ナット、レギュレーター、下端ニップル）が握り部。黒いホースが後端からループして継手の下端へ。
  カップ脇のピボットから下がる湾曲トリガー、その下を前へ通るバー、前方下のスプーン形パドル。
- 縮尺: エア継手（握り部）の見えている長さ 92 px = 0.085 m。継手の軸は在来ピストル軸とほぼ同じ傾き。
- インク: 外側にインク色の部分は見えない（RG の動画は全体が金色のキット色）。カップ内の塗料面をインクにして `can`
  （1発ごとに脈動）にした。上からのみ見える。
- 可動部: `trigger`（カップ脇のピボットで回転）、`can`。カップやホースの揺れは未実装。
- 持ち方: 右手はエア継手（S2 / S1 プロモ）。左手は前方パドル（`supportGrip` を 0.5 rad 前傾）。
  左手の位置は画像から推定。
- 銃口: エアキャップ先端 (0, 0.040, 0.220)。
- IoU: 0.339 → 0.627。

### .52ガロン（`s3-shooter-gravity`, Wmn_Shooter_Gravity）
- 構造: くびれた2段のインクジャグ（インク、`can`）を暗色のフレーム（前後の板、下のレール、上のレール）で保持。
  上のレールにピンクのクリップ2つとキャリーフック、前板に横方向のはしご状照準（銃口方向を向く。
  真横からは細い柱）、ジャグと同軸の穴あきバレルシュラウド（内側ピンク）、前方下の斜めの脚板、
  後部の肩当てストック（上部ブロックと下のフック）、ジャグ後面から約41°後傾した長いピンクのグリップ（グレーの底板）。
- 縮尺: 3Dレンダーは近距離の透視図で、グリップが大きく、バレルがジャグ軸より上に見える。動画 t=8 秒の真横
  （600×440 を 400 px に縮小）で測った。グリップ（底板まで）140 px = 0.11 m、ジャグ直径 0.11 m、全長 0.33 m。
- 握り: グリップ軸が在来（14°）より大きく傾くため、`gripR` をグリップ軸に沿った `rakedGrip(0.71)` にした。
  武器の向きは変えず、手首の角度だけを変える。
- 可動部: `can`（ジャグ。大きいため在来の膨らみを 50% に縮めた）、`trigger`。
- 持ち方: `hold.aim.p = [-0.05, -0.035, 0.215]`（在来は [-0.04, -0.075, 0.27]）。
  `File:S3 .52 Gal firing.gif`（背面視点）で照準が頭の横まで上がり、右手が肩の高さにあるため、高く手前に構えて
  ストックを右胸・肩へ寄せた。左手はジャグ前側の下のレール。
  キャリーと走りは在来のまま（S2 プロモ2で片手持ち）。
- 銃口: シュラウド先端 (0, -0.009, 0.237)。
- IoU: 0.350 → 0.659。真横の動画に合わせたため、透視レンダーとの縦横比（1.26 対 1.58）が一致しない。

### N-ZAP85（`s3-shooter-quickmiddle`, Wmn_Shooter_QuickMiddle）
- 構造: 光線銃形。明るいグレーのレシーバー（後部のくさび形、前部はバレル下のハウジング）、上のリブ窓、
  暗色の上部突起、赤い印刷帯（文字は再現しない）、ねじ、長い暗色バレル（巻いた銃口、前照星）、
  約34°後傾したバナナ形の暗色グリップ（リブ）、赤いトリガー。
- インク: 外から見えるインク部分はない（'89 の赤はキット色）。`can` は使わない。
- 握り: `gripR = rakedGrip(0.59)`。
- 持ち方: 在来（両手で撃つ）。左手はレシーバー前部ハウジングの下。S2 プロモ2では片手撃ちだが、S3 の画像は
  見つからなかったため、在来の両手のままにした（未確認）。
- 銃口: バレル先端 (0, 0.045, 0.190)。動画の真横に合わせて、レンダーよりバレルを少し延長。
- IoU: 0.236 → 0.746。

## 確認方法
- `node --experimental-vm-modules --test patches/splatoon3/tests/weapon-models-all.test.mjs`
  （有限なジオメトリ、グリップ、銃口、在来チャンネル、実 Actor による保持）は合格。
- シューター関連の既存テスト11本（射撃・塗り・移動・精度）と `weapon-catalog-adapter` / `weapon-reference-models` も合格。
- 見た目の確認: ギャラリーの描画と、カタログ武器の射撃を擬似的に再現した構え。
  ロジック単独とブラウザ描画の確認であり、本家実機との比較ではない。
