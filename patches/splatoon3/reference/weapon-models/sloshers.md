# スロッシャー モデル記録 — Splatoon 3 Ver.11.3.0

実装: `patches/splatoon3/runtime/weapon-models/sloshers.mjs`（手続き的ジオメトリ。本家メッシュは含まない）。
2026-10-11 に Opus で作り直し（旧版は側面輪郭を押し出した板で立体感がなかった）。

- 原典: Inkipedia「S3 Weapon Main <名前>.png」（本家3Dレンダー）と「S3 <名前> model rotating.mp4」（12方向シート。別キット動画は `alt-kits.json`）。内部モデル名は Leanny/splat3（7280ff9）`ActorInfo`。
- 共通の枠: ネイティブのスロッシャー座標（右手の縦グリップ＝原点、容器中心 (0, 0.012, 0.148)、左手は容器下前方の native gripL）を保持。各容器の背面に縦の取っ手を付けて右手グリップと一致させた。
- 銃口（弾の発生位置）はネイティブ値のまま（ゲーム挙動は不変）。`surface`（水平に保たれるインク面）は各容器の開口に合わせて配置、`lever` は非表示チャンネルとして保持。
- 寸法は画像からの推定（容器の高さ約 0.2 m をネイティブのバケツに合わせた）。

## オーバーフロッシャー（s3-slosher-bathtub / Wmn_Slosher_Bathtub）— 2026-10-11 再作成

旧モデル（黒い半球の上に白い蓋と平らなインク円盤）を全廃し、専用ビルダー `bloblobber()` で作り直した。

- 原典: Inkipedia「S3 Weapon Main Bloblobber 3D.png」（通常版の色）、「S3 Bloblobber Deco model rotating.mp4」（形状。12 秒で 1 回転、t=2.0/8.0 が真横、t=5.0 が背面、t=11.0 が浴槽正面）、
  「S2 Weapon Main Bloblobber 3D.png」（S2 の 108 方向ターンテーブル。直立姿勢の形状確認）、持ち方は「S2 Bloblobber promo screenshot.jpg」「S2 Bloblobber Promo Video1.mp4」「S2 Bloblobber Datamined video.mp4」と、
  Splatoon 3 の対戦動画サムネイル（gamepedia.jp のオーバーフロッシャー記事に掲載の YouTube サムネイル。画像はリポジトリに含めない）。
- 寸法: 公開寸法なし。動画（同一カメラ）の画素比から、浴槽幅 0.20 m を基準に縮尺 0.000615 m/px と置いた（縁長 0.30 m、外殻の最大深さ 0.16 m、蛇口バー 0.17 m）。蛇口バーは手が閉じるよう径 3.2 cm（画像では約 3.7 cm）。画像から推定。
- 構造（すべて立体）: 超楕円の平面形に断面プロファイルを一周させた「浴槽ロフト」で、白い陶器（厚い丸縁、外側の帯、内側の壁と床）と黒い船体を別々に作り、
  浴槽の深さを長さ方向に変化させた（後端は背もたれの斜面、中央が最深 10.5 cm、前端は縁へ上がる傾斜）。内部にオーバーフロー口、左右の壁の凹みと握りバー、排水口、噴流穴、
  前端の滑り止めシェブロン（インク色。デコ動画で黄色）。外側に、船体に沿う黒いストラップ（前の留め具→上側→後ろ回り→反対側→下側→底を一周、印刷「>>> HILKO」と赤いロゴを両側）、
  クロームの支柱と留め具、前端下のクロームU字レールと後ろのU字レール、前端下の茶色のブロック、底の段。後端に蛇口（クロームのバー、赤青リングのつまみ、混合ブロック、支柱2本、ラベル）。三角形 12 744。
- インク: `surface` は浴槽内の縁から 6 cm 下（浴槽が上を向く投げの最中に見える水平面）。吊り下げ時は開口が横を向くため、前端に溜まる水平な `pool`（新チャンネル、`animate` で開口の向きにより切替）を表示。
  なお S3 のサムネイルでは持ち歩き中の浴槽内は白く、液体のインクは見えない（画像から推定）。インク面はユーザー要望と slosher ファミリーの規約で残した。
- 持ち方: 右手で後端の蛇口バーの内側寄りを握り、浴槽を体の右横に吊り下げ、開口は前（やや右上）を向く（S2 プロモ・S2 データ映像・S3 サムネイルで一致、画像から推定）。
  `gripR` はバー軸（+X）、`twoAim/twoCarry = 0`（片手）、`nativeCarry`（Wii U のバケツ用クリップを使わない）。ホールドのオイラー角は yaw π・roll π を含み、ネイティブの振りのピッチ方向を反転させている。
- 振り: カタログのスロッシャーはキャラクターの `slosh` 一発動作を発火しないため、`pose`（`bathtubPose`）で runner の `catalogState.pending`（SwingLiftFrame 6F）から
  後ろへ引く→前上へすくい上げる（開口が上を向き水平）→戻す（約 0.56 s、RepeatFrame 32F 内）を再生。S3 サムネイルの投げ中の水平な浴槽と一致（画像から推定）。照準ピッチは吊り下げを後ろへ振らないよう相殺。
- 銃口: 旧 (0, 0.112, 0.178)（ネイティブ値）→ 新 (−0.036, −0.035, 0.158)（浴槽開口の中心、縁の高さ）。
- `lever`: 本体にレバーはないため、蛇口の赤青リングのつまみをこのチャンネルに割り当て（バー軸回り。現在は回転 0 に固定される）。
- 輪郭IoU: 0.6471 → 0.7317（参考値。3D レンダーは斜め視点）。

残差・確認状態:
- 実寸、バーの太さ、浴槽深さの絶対値: 未確認（実機計測が必要）。
- S3 での持ち歩き姿勢・振りの角度とタイミング: S3 は動画サムネイルのみで確認（画像から推定）。振り上げの高さと腕の軌道は 未確認（実機計測が必要）。
- 弾の発生位置（銃口）: 開口中心とした。本家の発生点は 未確認（実機計測が必要）。
- ストラップの経路・印刷、底面のパネル形状、船体の後壁の傾き: 画像から推定（簡略化あり）。
- 持ち歩き中に浴槽内へ液体インクを表示する点は本家と異なる可能性（S3 サムネイルでは白い浴槽）。画像から推定。

## スクリュースロッシャー（s3-slosher-launcher / Wmn_Slosher_Launcher）— 2026-10-12 再作成

旧モデル（濃灰の角丸箱＋クリーム色の箱＋持ち手＋脚。ポートは浅い円盤）を全廃し、専用ビルダー `sloshingMachine()` で作り直した。

- 原典: Inkipedia「S3 Weapon Main Sloshing Machine 3D.png」（通常版の色。約40°傾いた構図）、「S3 Weapon Main Sloshing Machine Neo.png」（ネオの公式レンダー: 本体外装が明灰色＝インク部）、
  「S3 Sloshing Machine Neo model rotating.mp4」（形状。12 秒で 1 回転、t=1.45/7.55 が真横、t=4.5 が背面、t=10.5 が正面。外装・持ち手・ハブのレンズが青＝この動画のチーム色）、
  持ち方は「S3 art 3D Inkling Sloshing Machine (shadow).png」（右手が前の天井バー、左手が後部クリーム色のバー）、「S3 first twitter preview - Sloshing Machine 2.jpg」、「S2 Sloshing Machine promo 1/2.jpg」。
  発射パラメータ（カタログ、WeaponSlosherLauncher 11.3.0）: SwingLiftFrame 12F、RepeatFrame 38F（原典データ確認）。
- 寸法: 公開寸法なし。動画の真横フレーム（中心面）から 0.00066 m/px と置いた（全長 0.29 m、本体高 0.28 m＋脚 1.85 cm、最大幅 0.23 m、前部天井バー内幅約 0.16 m・断面 1.9×4 cm）。
  S2 リザルト画面の「腰掛けた子の膝下≒本体高」とも整合。画像から推定。
- 構造（すべて立体、三角形 11 958）:
  - 前部ハウジング（インク色の枠）: 真横フレームからなぞった凸の前面曲線を持つ側面輪郭を、高さで幅が変わる樽形断面（正面幅 0.19→0.226→0.17 m）で左右に押し出し、全周の角を半径 12 mm で丸めた立体。
    前面は曲面のまま、ポート周りだけ別の曲面パネル（円形開口）に置き換え。側面に濃灰のはめ込みパネル（通常版の色。枠が前面曲線に沿って縁取る）。
  - 天井の持ち手: 両側の柱と天井バー、その下を前後に貫く開口（正面から細いスリット、背面から斜めの内床が見える）。
  - ポート: 厚い銀のベゼルリング（外径 0.2 m、内側は円錐）を 4 本のスタンドオフとねじで前面から 8 mm 浮かせ、奥行き 7 cm の円筒ドラム（内壁・黒い底板）、
    内壁に沿う 30 枚の静翼（放射から 57° 傾け、奥行き方向に 0.45 rad ねじった「スクリュー」）、中央に 3 枚羽根のインペラと黒いハブ、軸上にインク色のレンズ。正面・斜め・上から深い開口として見える。
  - 上部前面の暗色ブラケット板（溝付き丸ボス、ピン、ねじ2）、前面のねじ4、側面のねじ。
  - 灰色金属の仕切り帯、濃灰の中間部（ラベル窓、後端上面のトリム棒）。
  - 後部（クリーム色）: 背面が凸に丸い本体、V 字に切れた側壁の上縁と後端の耳、背面板が立ち上がった後部持ち手（四角い穴）、側面の縦溝 2 本、背面の丸い横スリットグリル（縦桟2）、背面ねじ4。
  - 真鍮のフランジと六角ナット＋黒いローレットパッドの脚 4 本。
- インク: 外装の枠・持ち手・ハブのレンズは `frame` パーツ（mat 'ink'、静止）。スロッシャーの描画量低下（`lowerFill` による ink メッシュの縦縮み）が外装に及ばないよう静止 ink とは分けた。
  `surface` はドラム底のインク溜まり（ポート軸の 4.2 cm 下、開口から見える位置。ネイティブ処理で水平維持・減量）。本家の静止画でドラム内に液面は見えないため、この表示は 画像から推定（ユーザー要望とファミリー規約による）。
- 可動部: `rotor`（新チャンネル。`catalogState.pending`・`firingT` の間に回転が立ち上がり、その後減速。毎フレーム割り当てなし）、`surface`、`lever`（非表示チャンネルとして保持）。
- 持ち方: `gripR` は天井バー中央（親指 +X、手首は上後方）。`gripL` は後部持ち手のバー（親指 −X）。持ち歩きは右手で天井バーを持って体の右に下げ、ポートは前（やや下）（`nativeCarry`、twoCarry 0）。
  構え・攻撃は両手で、腰の右前にポートを前へ向けて保持（twoAim 1）。S3 キーアート・S2 プロモと一致（画像から推定）。
- 振り: カタログのスロッシャーは `slosh` 一発動作を発火しないため、`pose`（`machinePose`）で `catalogState.pending`（SwingLiftFrame 0.2 s）から
  後ろ下へ引く（0.1 s）→前上へ振り上げポートを上向きに（0.2 s＝弾の発生時刻）→保持→戻す（0.6 s、RepeatFrame 0.63 s 内）を再生。振りの角度・高さは 画像から推定。
- 銃口: 旧 (0, 0.112, 0.178)（ネイティブ値）→ 新 (0, −0.157, 0.102)（ベゼルリング前面の中心＝ポート出口。原点は天井バーの右手位置）。
- 輪郭IoU: 傾いた参照レンダーとの比較 0.64→0.66（参考値）。動画の真横フレーム（脚・床を除外）との比較 0.71→0.85。

未確認・残差:
- 実寸、バーの太さ: 未確認（実機計測が必要）。
- 弾の発生位置（銃口）: ポート出口とした。本家の発生点は 未確認（実機計測が必要）。
- S3 での持ち歩き姿勢・振りの角度とタイミング、インペラが実際に回るか: 未確認（実機計測が必要）。
- 側面パネル・中間部を濃灰（非インク）とした点: 通常版レンダーでは濃灰だが、S3 のスクリーンショットではチーム色に暗く染まって見える。画像から推定。
- ネオのロゴ・刻印、背面の小さな印刷、静翼の正確な枚数と曲率: 省略または近似（画像から推定）。
