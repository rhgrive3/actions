# スロッシャー系モデル（Splatoon 3 Ver.11.3.0 参照）

対象: `patches/splatoon3/runtime/weapon-models/sloshers.mjs`（6 種）。参照版は Ver.11.3.0。

## 方法と前提
- 形状: 公式 3D レンダー（`refs/<id>.3d.png`、400 px。取得時のファイル名は未記録）の α チャンネルから側面輪郭を抽出し（輪郭追跡と Douglas-Peucker 簡略化、誤差 2〜5 px）、X 方向に押し出した板を本体にした。奥行きと内部形状は推定。回転シートは今回確認していない。
- IoU の意味: 輪郭を同じレンダーから取ったため、IoU は側面の一致の検証ではなく、スケール・押し出し・位置の写像が正しいことを見る指標に留まる。3D 形状の一致の根拠にはならない。
- スケール: 公式寸法は未確認。レンダーは斜め視点なので、本体の大きさを推定値（バケット級 約 0.2 m）に合わせた。
- ホールド: ネイティブのスロッシャー取っ手（原点、右手 `gripR`）と `gripL` をそのまま使用。
- 動き: ネイティブの `surface`（インク面、水平を保つ）と `lever` チャンネルを残した。インク面は各モデルの開口上縁に置いた円盤（`mat: 'ink'`）。
- 射出口（muzzle）はネイティブ値のまま。`main-weapon-catalog.mjs` の `origin()` が `_muzzle` 経由で弾の発生位置に使うため、変えるとゲームプレイ値が変わる。実際の射出口位置は未確認なので変更しなかった。

## 未確認
- 回転シート（turntable）は確認していない。前後・上面の形は未確認（3D レンダーからの推定のみ）。
- ホールド: 目視確認したのは Bloblobber の held 画像 1 種のみ。他 5 種の持ち方は未確認（実機の持ち方の画像との比較が必要）。
- インク面の水位低下（ネイティブの `surface` 駆動）と実機の挙動との比較は未確認（実機計測が必要）。
- 射出口（muzzle）はネイティブ値のまま。新しい開口位置との差は未確認。
- 省略した部品: Bloblobber の水栓と基部、Explosher の銀フープ、Dread Wringer のローラー、Sloshing Machine のタンク。
- `weapon-reference-models.mjs` の旧 `slosher()` が今も使われるかは未確認（`slosher` ID の登録がこのモジュールに移った件の確認が必要）。
