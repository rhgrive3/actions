# INKWAVE 入力・対戦進行の修正

取得元の `inkwave-public/` を編集せず、ゲーム挙動・配置編集の後に `adapter.mjs` をビルド出力へ適用する。数値・画面デザインの調整ではなく、再現できた入力消失と古い非同期処理の干渉を修正する。

- 通常の視点ドラッグは画面右半分で開始した指だけに割り当て、中央を越えても役割を維持する。移動スティックと明示的なボタンを優先する。
- FIRE/SQUID/SUB は既存の射撃しながらの照準操作と `fireAim` 設定を維持する。ボタンを左へ再配置しても、明示的な照準ボタンのドラッグは使える。
- ジャンプ・変身・射撃・サブ・スペシャルの短いタップを次のシミュレーション更新まで保持し、更新後に一度だけ消費する。描画だけのフレームでは捨てない。
- 取り消し・フォーカス喪失・回転・端末切替で、古い入力、視点差分、ジャンプ先を取り消す。正しく終了した短いタップと有効なマップ選択を区別する。
- タッチの `pointercancel`、早すぎる `lostpointercapture`、入力のリセット、マウスからタッチへの切替で終わった FIRE/SUB の長押しは、指を離した操作と区別して 1 回の更新だけ「取り消し」として渡す。チャージャー・スピナーのチャージとサブの構えは、射撃・発射・投擲せずに破棄する。通常の指離し、マウス離し、キーボード、ゲームパッドの解放は変えない。
- PAUSE とマップ（ボタン・ミニマップ）はタッチの終了時に確定する。`pointercancel` や指のずれでは開かない。マップ上のピンも、同じ指の `pointerup` で確定するまでスーパージャンプを開始しない（マウス・パッドの経路は変更なし）。
- 切断した接続のタイマー・コールバックが新しい部屋へ干渉するのを防ぐ。退出した試合の結果・音楽・部屋終了・イントロ通知を新しい試合へ反映しない。
- 試合開始・メニュー帰還・ステージ読み込みを開始時の所有者に結び付け、取り消した読み込みが新しい試合やステージを置き換えるのを防ぐ。
- メニュー背景の自動リセットが開始した試合を破棄するのを防ぐ。退出した判定の表示・音・待機処理を取り消し、新しい判定には干渉しない。
- ジャイロ許可の結果を最新のON／OFF操作に結び付け、古い許可・拒否や破棄後の通知で設定・動作を上書きしない。
- メニューのゲームパッド押下を1回だけ処理し、メニュー操作の保持を解放までゲーム入力へ流さない。オンラインのポーズは自分の操作を止め、試合時間と他のプレイヤーの更新を続ける。

各接続は一意のソース位置を要求し、取得元の変更や重複適用を検出したらビルドを停止する。アダプター全体は `inkwave-build.json` の `reliability/` 入力ハッシュに含める。`--exact-source` は実際の Git コミットと照合し、未コミットの入力を認定しない。

回帰試験は既存の `node --experimental-vm-modules scripts/check-inkwave-patches.mjs` がすべての `tests/*.test.mjs` を発見する。生成されたモジュールのタッチ・通信確認は `scripts/check-inkwave-reliability.mjs --site <生成先> --evidence-dir <永続証跡先> --profile-dir <永続プロファイル先>`。

ブラウザの確認は Chromium/WebKit の端末設定を使う。実 iPad、稼働中の配信、実リレー、本家の同条件実機・ブキ・ギアとの一致は別途未確認。物理感度や本家の未取得フレーム値をこの修正で一致したとは扱わない。
